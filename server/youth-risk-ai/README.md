# GPT / Gemini 연결 준비

현재 공개 사이트의 기본 리뷰는 브라우저에서 실행되는 문항 해석 규칙입니다. GPT/Gemini를 호출하는 것처럼 표시하지 않습니다. 외부 AI는 아직 연결·실제 호출·품질 검증되지 않았습니다.

## 준비된 기능

- Node.js 22 이상, 추가 라이브러리 없이 실행하는 `/analyze` 서버
- OpenAI Responses API 또는 Google Gemini generateContent 선택
- 서버 환경변수에만 제공자 API 키 보관
- 이름·자유서술 제외: 25개 정수 응답, 4개 안전 체크, 척도 버전만 허용
- 서버에서 원문 문항을 결합해 짧은 상황 해석을 요청
- 허용 출처 확인, 기관용 접속 코드, 요청 크기·횟수·동시 실행 제한
- 서버 코드 자체는 평가내용·결과를 기록·저장하지 않음. 호스팅·제공자의 처리·보관 정책은 별도이며 무저장을 보장하지 않음
- 모의 응답을 이용한 연결 로직 검사. 실제 모델의 출력 품질·정확도를 검증한 것은 아님

## 관리자가 설정할 항목

서비스 제공자 대시보드/기관 서버의 비밀 환경변수로 설정합니다. 키를 저장소나 공개 웹 파일에 넣거나 채팅에 붙이지 않습니다.

| 변수 | 값 |
|---|---|
| `AI_PROVIDER` | `openai` 또는 `gemini` |
| `AI_MODEL` | 해당 계정에서 사용할 수 있는 고정 모델 ID. 자동 선택하지 않음 |
| `AI_API_KEY` | 선택한 제공자의 API 키(비밀) |
| `AI_ACCESS_TOKEN` | 24자 이상 충분히 무작위인 기관 접속 코드(비밀). API 키와 다른 값 |
| `ALLOWED_ORIGIN` | `https://daily-jh.github.io` |
| `HOST`, `PORT` | 기본 `127.0.0.1`, `8787`. 호스팅 실행 방식에 맞춰 지정 |

저장소 루트에서 `node server/youth-risk-ai/server.mjs`로 실행합니다. 외부 연결은 HTTPS 역방향 프록시/호스팅을 통해 노출하고 인증·접근권한·비용 한도를 기관 운영 정책에 맞게 설정해야 합니다. 현재 공용 공유 접속 코드는 최소 보호 수단이며 다수 사용자의 정식 운영에는 개인별 인증과 중앙 요청 제한을 추가하는 것이 적절합니다.

## 홈페이지 연결

서버 배포와 실제 가상 응답 검증 후 `docs/youth-risk/ai-config.js`의 공개 설정만 변경합니다.

```js
window.YOUTH_RISK_AI = Object.freeze({
  enabled: true,
  endpoint: 'https://기관이-운영하는-서버/analyze',
  providerLabel: 'OpenAI GPT' // 또는 Google Gemini
});
```

서비스 이름과 실제 서버 제공자를 일치시키세요. 브라우저의 사용자는 기관 접속 코드를 입력하고 전송 범위를 확인한 뒤 AI 분석을 실행합니다. 이름은 payload에 포함되지 않습니다. 서버와 AI 제공자는 점수만으로도 민감한 사정을 처리하게 되므로 적법한 처리근거·동의·계약·보관/삭제·국외이전 등 필요한 사항을 기관 담당자가 확인해야 합니다. 이 문서나 화면의 확인란만으로 법적 요건이 충족되었다고 간주하지 않습니다.

## 사례관리 분석 원칙

현재 상황 → 생활에 미칠 영향 → 학생이 원하는 변화와 우선 지원 순으로 짧게 서술합니다. 사실(평가자 응답), 해석(가능성), 미확인 정보를 구분합니다. 강점·보호요인을 창작하지 않고 면담으로 확인합니다. 이 원칙은 사용자가 지정한 2026 오산세교 사례관리 스킬의 일반 사정·문체 원칙만 참고했으며, 내부 실제 사례·서식 원문을 공개하거나 기관의 별도 16문항·32점 척도를 청소년 25문항에 적용한 것이 아닙니다.

사례관리 스킬의 외부 연결 제한은 자동으로 해제되지 않습니다. 실제 사례 응답의 외부 AI 전송은 사용자가 별도로 명시한 범위와 기관의 처리 요건을 확인한 뒤에만 운영해야 합니다. 현재는 연결 준비만 승인된 상태입니다.

## 공식 API 근거 (2026-10-20 확인)

- [OpenAI 텍스트 생성](https://developers.openai.com/api/docs/guides/text)
- [Gemini API 키](https://ai.google.dev/gemini-api/docs/api-key)

GitHub Pages는 이 Node 서버를 실행하지 않습니다. Pages에는 기존 평가 화면만 배포하며 분석 서버는 기관이 별도로 운영할 HTTPS 호스팅이 필요합니다.
