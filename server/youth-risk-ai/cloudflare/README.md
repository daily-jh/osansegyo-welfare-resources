# 청소년 위기징후 시스템: 선택형 웹 AI 사례검토

## 기존 기능 보존
- `docs/youth-risk/assessment.html`, `app.js`의 **기존 AI 요청문·평가자료 복사**는 수정하지 않음
- 평가 결과·규칙 판정·학맞통 및 서비스계획·기존 인쇄 기능을 그대로 제공
- 3단계 사례보고서 화면에 `direct-ai.js`로 별도 AI 초안 영역만 추가
- 서버 설정 전에는 AI 호출이 비활성화되며 어떠한 평가자료도 전송하지 않음

## 배포 순서
1. Cloudflare 계정에서 Workers AI 사용 및 처리 정책, 보호체계를 확인한다.
2. 이 디렉터리에서 `npx wrangler secret put AI_ACCESS_TOKEN` 명령으로 32자 이상의 무작위 기관 접속 코드를 **서버 Secret**으로 등록한다. GitHub 저장소·프런트엔드에 절대 기록하지 않는다.
3. `npx wrangler deploy`로 Worker를 배포하고 `https://....workers.dev/analyze` HTTPS 주소를 확인한다.
4. 사이트의 `docs/youth-risk/direct-ai-config.js`에서 enabled를 true로 바꾸고 endpoint를 해당 주소로 지정한다. 서버 설정과 허가 후에만 활성화한다.
5. 가상 학생 데이터로 미상/안전 신호, 허용 출처, 잘못된 토큰, 사용량 초과, 실패 시 기존 결과 보존을 검증한다.

## 전송 데이터
AI를 명시적으로 선택하여 기관 방침 및 외부 전송 범위를 확인한 뒤 실행했을 때에만 25개 응답(0~4/미상), 별도 안전확인 여부, 현재 추가확인 상태, 교사/복지사 모드만 전송한다. 이름, 상담 메모, 기관 자원 DB, 문서 내용, 연락처, 입력한 이름은 전송하지 않는다. 점수도 재식별 가능성이 있으므로 실제 청소년 데이터 사용 전에 적법성·동의·위탁·국외이전 여부를 담당자가 판단한다.

## 보안·운영 유의
- 기관 접속 코드는 별도 입력하며 브라우저 영구 저장 안 함
- Cloudflare Rate Limiting binding 필요. 값은 근사 한도이므로 예산 한도·사용자별 인증·WAF 추가 권장
- Origin 검사는 인증을 대신하지 않음. 공유 코드 유출 시 코드 교체 필요
- Worker는 본문과 응답을 직접 로그·DB에 저장하지 않지만 Cloudflare의 네트워크/모델 로그 정책은 별도
- AI 생성 문장은 독립적인 검토 초안으로만 표시. 점수·안전 신호·기존 자동 사례보고서·서비스계획서를 덮어쓰지 않음
- 출력물은 Word/HWP 직접 생성이 아닌 화면에서 복사하거나 기존 인쇄 기능으로 PDF 저장. 한글 파일은 별도 변환 필요
- 실사용 전 반드시 청소년 개인정보와 외부 AI 제공 서비스에 대한 기관 검토 및 모의 평가 테스트 실시
