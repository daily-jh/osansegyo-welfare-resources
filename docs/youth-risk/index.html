채점 전 확인

최근 1개월의 관찰·학생 진술·기존 기록을 함께 확인하되 정서 문항은 최근 2주를 중심으로 봅니다. 안전신호는 시점과 관계없이 현재 안전을 확인하세요. 0점은 충분히 확인했으나 해당 어려움이 없는 경우입니다. 1점 경미·일시 / 2점 반복·지원 필요 / 3점 빈번·기능 저하 / 4점 심한 기능 제한. 이 공통 기준은 미검증 초안이며 안전신호의 빈도 기준이 아닙니다. 미상은 평가 보류이며 총점을 확정하지 않습니다.

같은 사건·증상만으로 여러 문항을 자동 가산하지 마세요. 서로 다른 피해·기능 제한이 확인될 때만 각각 채점합니다. 문항별 안내를 참고하고 근거는 소속기관의 적법한 기록체계에서 관리하세요.
