## 1. 계산·위기판정 구조
1. 원점수: 확인된 문항 합계. 문항 25개가 모두 확인되었을 때 0~100점. 미상 포함 시 부분합계만 유지하고 전체 판정은 보류.
2. 지원수준: `criteria.js`에서 10개 영역 중 중증문항(3·4점) 또는 복수의 2점 문항이 있는 영역 수, 전체 중증문항 수에 따라 `observedLevel=0~3` 결정. 합계점수와 가중계수로 단계가 직접 결정되지는 않음.
3. 긴급확인: 1·2·7·25번 점수 >0, 별도 긴급 신호, 또는 4·5·12·13번의 해당 추가확인에서 `yes`인 경우 총점과 무관하게 우선 확인.
4. 가중치: `review-model.js`의 25개 가정 계수(0.96~1.35)는 `(문항점수 / 4) × 계수` 등 서술·정렬 보조값으로 활용. **안전 게이트·100점 원점수·0~3 지원수준을 대체하지 않음.** 가중 위험확률, 임상적 절단점, 문항변별도 추정으로 해석 금지.

## 3. 80개 가상 청소년 시나리오
- 10개 중심영역(학대·방임 / 또래 피해 / 정서 / 학습·출결 / 행동·건강 / 교육 접근 / 가족돌봄 / 경제·주거 / 관계·지지 / 디지털) × 8개 난이도·교차 조건 = 80건.
- 각 영역별 패턴: 초기 1점, 반복 2점, 단일 고위기 4점, 복합 생활영역, 돌봄·교육권 중첩, 주거·고립 중첩, 자해 관련 신규 안전신호, 핵심 안전문항 미상.
- 응답 벡터를 기계적으로 설계한 **합성 사례**이며 실제 상담 서사나 제3자 전문가 합의가 있는 자료가 아님.
- 기대 긴급 안전분류 일치 **80/80**, 미상 여부 일치 **80/80**, 중심영역이 분석 대상에 포함 **79/80**.
- 예외 **08번**: 학대 관련 1번이 미상이고 23번이 1점인 사례. 최종 판정은 보류되며 **확인된 학대 사실이 없으므로 학대 개입계획이 자동 생성되지 않음**. 이를 단순 오류로 해석하면 오히려 근거 없는 피해확정을 유도할 수 있음. 안전 미상에 대한 현장 확인 안내는 유지되어야 함.
- **중요한 한계:** 위 일치는 개발 시나리오의 규칙적 기대값에 대한 **기능적 일치**일 뿐, 독립 전문가가 판정한 80명의 실제 청소년과 비교한 정확도가 아니다.
