# OY-RALS 3차 모델 패치·연구 검수 요약 (2026-10-24)

- 웹: https://daily-jh.github.io/osansegyo-welfare-resources/youth-risk/
- 원칙: **기존 25문항 평가·안전 게이트·원점수·v2.2 가중 정렬은 유지**, 독립적인 v3 해석 및 사례관리 계획초안만 보완.
- 운영: `criteria.js`, `weight-model.js` v2.2.0.
- 보조 모델: `interpretation-v3.js` v3.0.1, `casework-v3.js` v3.0.0, 기존 한국어 해석 v2.1.0 병행.
- 지식자산: 개발원고 700쪽, 연구문항쌍 300개, 현재 교차규칙 24개, 심층 응답카드 600개, 추가 실무카드 104개. 서로 중복되는 가설·판본 수를 합쳐 독립 사례 수로 표현하지 않음.
- 전면적 임상 타당도 및 독립적 예측 정확도: **미검증**.

## 실제 패치
1. **P0 원문 버전 동기화**: 최신 `app.js`의 25번 문항 원문과 안내 문장을 `research-v1/items.jsonl`, `pairs-1/2/3.jsonl`에 동기화. 과거 CI 오류 `current item B mismatch` 해소 및 해당 GitHub Actions 성공.
2. **설명 가능한 3차 사례해석**: `interpretation-v3.js`가 사실 확인 필요·미상·부정·가정·전언에 근거한 분류를 별도로 제공. 기존 공식 점수·안전·법정 판단을 변경하지 않음.
3. **3차 목표·역할·성과 초안**: `casework-v3.js`는 학생 희망·강점·기존지원 확인, 단기/장기 목표, 역할 협의, 기준선·기한 확인 및 진행상태를 제안하되 승인된 서비스계획을 생성했다고 주장하지 않음.
4. **v3.0.1 서술 해석 수정**: 같은 문장에 '자해는 없고 결석이 반복된다' 같은 대조표현이 있을 때 주제별 절을 분리하여 부정된 발언과 미확정 긍정 언급을 구분. `tests/youth-interpretation-v3.cjs`에 합성 반례 10건 추가.
5. **표시 버전 정합성**: `model-manifest-v3.json`, `system-method.html`을 한국어 해석 v3.0.1과 동기화.

## 자동검사 이해의 한계
- 2026-10-24의 v2.2 합성 입력 500,000건에서 기술 불변조건 실패 0건; **실제 학생 50만 명 검증이 아님**.
- 동일 합성 입력의 v2.1→v2.2 우선순위 배열 변경 86,189건, 상위 3개 지원영역 구성 변경 19,664건은 가중 모델의 동작 차이이지 실제 서비스 효과 향상을 증명하지 않음.
- 개발자 코딩 공개사례 20건, 합성 검증자료 80건, 가정적 20,000회 점수변화는 독립 외부 준거가 아니며 실제 사례판정 일치율로 오인 금지.
- 현재 v3 테스트 `tests/youth-interpretation-v3.cjs` 및 `tests/youth-casework-v3.cjs`는 인공 예시·난수 입력의 회귀검사임.

## 3차 해석의 핵심 규칙
1. 평가문항의 점수·미상·보호 신호를 원본 그대로 보존한다.
2. 문항의 동시 보고는 **교차확인 가설**이며 원인·진단·상관계수·위험확률을 확정하지 않는다.
3. 서술형 내용은 학생 진술, 교사 관찰, 제3자 전언, 추정, 부정, 미확인, 가정·예시와 구분한다. 규칙형 언어 파서는 복잡한 이중부정·시제·인용 주체를 완전하게 해석할 수 없다.
4. 1·2·7·25번의 양성 신호, 4·5·12·13번의 현 위험 추가확인은 다른 가중값으로 낮추지 않는다.
5. 서비스 후보를 실제 제공 시작 또는 법적 지원자격 확정으로 표현하지 않는다.
6. 학교·사회복지관 담당자의 확인 및 학생이 희망하는 생활변화를 개입계획의 핵심 증거로 설정한다.
