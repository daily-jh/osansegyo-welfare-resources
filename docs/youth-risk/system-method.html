학생의 희망과 실제 사정·사례회의를 통해 목표와 역할을 정합니다.

한국어 사례해석모델 v2.0

응답을 어떻게 이해할까요?

실제로 함께 보고된 문항의 조합을 찾아 해석 가설·면담 질문·역할·점검 문구를 제공합니다. 교사와 사회복지사의 업무 관점도 반영합니다.

  • 2차 연구원고 700쪽 검토 반영
  • 300개 문항쌍과 104개 추가 실무 카드
  • 기존 단일문항·교차 해석카드 600건 병행
  • 브라우저에서 실행하는 규칙·근거검색 방식

연구 자료의 문구를 선택·조합합니다. 생성형 대규모 언어모델을 자체 학습한 기능은 아닙니다.

평가에서 변화 점검까지

  1. 생활과 안전 확인
    관찰·상담 근거로 점수 또는 미상을 선택합니다.
  2. 결과와 자원 연결
    현재 안전·생활 영향·지원 방향을 보고 행정동과 복지관 권역에 맞는 후보를 확인합니다.
  3. 사례 이해와 지원계획
    응답에 근거한 어려움과 해석 가설을 구분하고, 학생에게 물을 질문과 계획을 살펴봅니다.
  4. 실행 기록과 변화 점검
    학생과 합의한 목표·담당·확인일을 기록하고, 실제 제공 상태와 생활변화를 확인해 계획을 조정합니다.

어떤 자료가 얼마나 들어 있나요?

자료확인한 규모사용하는 곳
청소년 평가25문항 · 10영역 · 최대 100점결과·안전확인·지원 방향
기존 교차규칙24개복합 욕구와 추가 사정 주제
2차 연구원고기존 596쪽 + 보완 104쪽 = 700쪽개발 원칙·문항 해석·업무 흐름 검토
문항쌍 자료25문항의 두 문항 조합 300개 · 공통 해석틀 55종양성 응답이 함께 있는 조합을 검색해 최대 3개 주제 제시
추가 실무 카드104개: 영역 10 · 문항 25 · 교차규칙 24 · 업무흐름 15 · 합성검사 20 · 관리정책 10학교와 복지관의 욕구 연결, 질문·실행·점검 안내

문항별 설명 요소25문항 × 5요소 = 125개추가 확인·역할·질문·생활변화·유의점
공통 복지자원 목록같은 자원 원본에서 확인 중현재 기관명·연락처·주소·관할을 평가와 공유

쪽수는 편집된 개발 원고의 분량입니다. 문항쌍·카드 수는 실제 학생 사례 수나 검증 논문 수를 뜻하지 않습니다. 기존 300개 문항쌍을 v2로 개정한 것이므로 두 판본을 600개 고유 조합으로 합산하지 않습니다.

모델이 판단하는 범위

안전·점수는 기존 평가 규칙에서 계산하며, 언어 해석은 그 결과를 설명하는 보조 자료입니다. 미상은 0점으로 바꾸지 않습니다. 동시 응답은 원인이나 진단을 확정하지 않습니다. 실제 지원 선정·의뢰 수락·서비스 시작·목표 달성은 담당자가 확인한 기록으로 구분합니다.

현재 자료는 개발가설과 일반화한 실무 규칙입니다. 실제 학생 자료로 임상적·통계적 타당도를 검증한 상태는 아닙니다.

입력 정보와 AI 이용

기본 평가·해석은 브라우저에서 계산합니다. 이름은 후속 분석에 전달하지 않습니다. 직접 적은 기록은 자동 저장되지 않으므로 필요한 내용은 기관 기준에 맞게 보관하세요. ‘AI로 보완’에서 외부 AI를 사용하는 경우 전달 자료를 먼저 확인합니다.
