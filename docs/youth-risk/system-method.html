한국어 사례해석모델 v2.1

응답을 어떻게 이해할까요?

실제로 함께 보고된 문항의 조합을 찾아 보고된 사실, 생활 영향, 추가 확인 질문, 지원 제안과 점검 방법을 사례검토 문장으로 설명합니다. 교사와 사회복지사의 업무 관점도 반영합니다.

  • 2차 연구원고 700쪽 검토 반영
  • 300개 문항쌍과 104개 추가 실무 카드
  • 기존 단일문항·교차 해석카드 600건 병행
  • 브라우저에서 실행하는 규칙·근거검색 방식

문항별 서술 규칙과 연구 자료를 바탕으로 문장을 구성합니다. 생성형 대규모 언어모델을 자체 학습한 기능은 아닙니다.

3차 해석·사례관리 보완 · v3.0.1

2026년 10월 24일 보완된 한국어 사례해석 v3.0.1과 사례관리 계획초안 v3.0은 기존 통합사례관리 운영모델·25문항 원점수 및 안전판정(v2.2)을 바꾸지 않는 추가 설명·검토 계층입니다.

  1. 확인된 척도 응답과 미상·추가 안전확인 사항을 별도로 표시합니다.
  2. 서술 기록의 언급·부정·미확인·가정을 보수적으로 분류하고 실제 사건의 발생을 단정하지 않습니다.
  3. 교차해석은 검증되지 않은 추가사정 가설로 설명하며 학생 면담·기존 강점·지원 여부를 확인합니다.
  4. 단·장기 목표 및 담당자·성과 지표는 합의 전 초안으로 제시하며 실제 서비스 개시와 구분합니다.

v2.2 가중치·맥락판정 업데이트 검수

가중치 계산 방식과 한계

문항 보조 가중치 = 기본 계수 × 확인된 동시응답 가정계수(기본값의 최대 1.12배). 이 값은 사정 질문과 개입계획 표시 우선순위를 조정하는 보조지표이며, 학대 신고·자해 위험·임상진단 또는 위험 확률을 산출하지 않습니다. 미상은 0점으로 계산하지 않고, 최종 판정은 보류합니다.

모델과 시스템의 연결 구조

같은 응답을 두 경로로 처리합니다. 통합사례관리 모델은 지원의 순서와 실행 상태를, 언어 모델은 학생의 상황을 설명하는 문장을 정리합니다.

구조도를 글로 읽기 · 선택형 AI의 위치

① 25문항·안전·행정동 입력 → ② 점수·안전·자원·계획 정리와 ③ 응답·생활영향·확인질문 서술 → ④ 결과·리뷰·사례 이해·지원계획 출력 → ⑤ 학생과 실무자 확인·합의 → ⑥ 실행과 변화 점검입니다.

언어 해석은 공통 평가 규칙이 계산한 점수나 안전 판정을 바꾸지 않습니다. 외부 AI 보완은 이 기본 흐름과 별도로 사용자가 선택하며, 현재 입력을 자동 전송하지 않습니다.

평가에서 변화 점검까지

  1. 생활과 안전 확인
    관찰·상담 근거로 점수 또는 미상을 선택합니다.
  2. 결과와 자원 연결
    현재 안전·생활 영향·지원 방향을 보고 행정동과 복지관 권역에 맞는 후보를 확인합니다.
  3. 사례 이해와 지원계획
    응답에 근거한 어려움과 해석 가설을 구분하고, 학생에게 물을 질문과 계획을 살펴봅니다.
  4. 실행 기록과 변화 점검
    학생과 합의한 목표·담당·확인일을 기록하고, 실제 제공 상태와 생활변화를 확인해 계획을 조정합니다.

모델이 판단하는 범위

안전·점수는 기존 평가 규칙에서 계산하며, 언어 해석은 그 결과를 설명하는 보조 자료입니다. 미상은 0점으로 바꾸지 않습니다. 동시 응답은 원인이나 진단을 확정하지 않습니다. 실제 지원 선정·의뢰 수락·서비스 시작·목표 달성은 담당자가 확인한 기록으로 구분합니다.

현재 자료는 개발가설과 일반화한 실무 규칙입니다. 실제 학생 자료로 임상적·통계적 타당도를 검증한 상태는 아닙니다.
