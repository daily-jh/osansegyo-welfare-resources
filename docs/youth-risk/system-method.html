01 / HOW TO USE

학생 지원을 잇는 5단계

평가 결과는 정량·서술·종합의견으로 나뉘며, 이후 자원연계·사례사정·AI 심화해석·기록과 점검을 연결합니다.

STEP 01

척도 평가

25문항(총 100점)·미상·안전판정, 10영역 레이더, 교차분석, 서술기록·종합의견을 독립 확인

STEP 02

자원연계 지도

영역별 기관과 사업 후보 조회. 접수요건·관할·기존 지원·최종 확인일 검토

STEP 03

사례 톺아보기

사례사정 및 판정·서비스계획 추천·통합사례 진행. 가계도·생태도 연결

STEP 04

AI 연구 작업실

현재 사례자료를 선택하여 OY-CIE 규칙·검색 기반 심화질문과 근거 확인

STEP 05

기록 및 점검

초기상담·회의·서비스 수행·재사정·종결 관련 기록과 인쇄·PDF

안전 문제가 의심된다면 평가 완료를 기다리지 않습니다.

학대·자해·성착취·현재 위해 등의 신호가 있다면 소속기관의 보호·신고·긴급 대응 절차를 우선 수행해야 합니다. 자동 결과는 이를 대신하지 않습니다.

02 / CONNECTED ARCHITECTURE

실제 홈페이지의 모델·화면 연결 구조도

화면은 다섯 단계로 구분하지만, CORE 25문항과 별도 안전판정은 모든 단계에서 동일한 원자료를 사용합니다. 단말기 내 사례자료를 모델 게이트웨이가 분석하고 결과 화면·보고서로 전달합니다.

안정성 검수와 장애 복구 경로

평가 결과가 열리지 않음25개 문항이 모두 선택됐는지 확인 → 완료 버튼 → 상위 화면의 결과 탭. 입력을 변경했다면 다시 완료해야 합니다. 지속되면 비식별 JSON을 내려받고 다시 열어 복원합니다.
지도가 비거나 기관이 없음평가 회차와 지도 iframe 연결 확인 → 관할·사업 조건 조회. 비어 있어도 CORE 결과와 안전조치는 유지됩니다.
AI 연구 결과 지연·오류질문/선택자료 범위를 확인하고 다시 분석합니다. CIE를 사용할 수 없어도 CORE·사정·자원연계 기능은 독립 작동합니다.
PDF 미출력·표 잘림인쇄 미리보기에서 A4/배율/배경 그래픽을 확인합니다. 가능한 경우 전체 자료 ZIP의 HTML 파일을 열어 브라우저에서 PDF로 인쇄합니다.
새로고침·종료 위험자동 영구 저장이 없습니다. 평가 JSON 및 필요한 보고서를 먼저 저장하고, 외부 AI·공유 전 개인정보를 직접 검수합니다.
검증 현황CORE/모델 계약·합성 사례·브라우저 E2E·복지자원 회귀 검사를 분리해 실행하며 실증 타당도를 의미하지 않습니다. 최신 자동검사 보기
02 / READ THE RESULT

점수를 읽을 때 지켜야 할 네 가지

  1. 1
    100점은 문항 응답의 합계입니다.

    25문항 × 0~4점으로 산정하지만, 총점이 개인의 미래 위험을 예측하거나 지원자격을 결정하는 점수는 아닙니다.

  2. 2
    ‘미상’과 ‘0점’은 다릅니다.

    미상은 판단 보류이며 0점으로 대체하지 않습니다. 0점도 이번 응답에서 해당 어려움이 보고되지 않았다는 뜻이지 위험이 없다는 증명은 아닙니다.

  3. 3
    같은 영역 안의 문항도 구분합니다.

    돌봄 공백(16번), 생활물품 부족(19번), 주거 어려움(20번), 비용 장벽(21번)을 하나의 경제문제로 자동 합치지 않습니다.

  4. 4
    서술과 점수가 다르면 질문을 남깁니다.

    예를 들어 9번 출결이 4점인데 결석 기록이 없다면 실제 상황과 평가 시점을 다시 확인합니다. 시스템이 임의로 점수를 수정하지 않습니다.

서술형을 입력한 경우

가족·학교생활·강점·이용 중인 서비스를 구분하고, 부정·가정·전언·미확인 표현을 점검합니다. 한 문장 안의 의미를 잘못 읽을 수 있으므로 원문과 근거를 반드시 비교해야 합니다.

서술형을 입력하지 않은 경우

점수별로 확인할 상황과 첫 질문을 제시합니다. 실제 결석, 체납, 진단, 폭력, 서비스 제공 등 확인되지 않은 사건은 사실로 생성하지 않습니다.

03 / PROFESSIONAL PRACTICE

교사와 사회복지사가 각자의 역할로 사용합니다

보고서가 제시하는 모든 과제는 협의 전 초안입니다. 학생이 바라는 변화와 정보공유·담당·일정은 실제 면담과 사례회의에서 결정합니다.

교사 · 학교

관찰·보호·수업 조정

출결·교과·또래관계·교실 환경의 직접 근거를 확인하고, 안전한 면담과 학교 내 보호·학습 조정을 진행합니다. 필요하면 학맞통 등 교내 협의 절차를 검토합니다.

사회복지사 · 교육복지사

생활 사정·자원 조정

가족의 실제 돌봄·경제·주거 여건, 기존 지원의 내용과 공백, 지역기관 이용장벽을 확인하고 의뢰·제공·점검을 조정합니다.

같은 사례에서도 실행안은 다르게 제안됩니다

9번 · 출결 4점학교: 출결기록과 등교 어려움의 상황을 확인하고 교내 조정을 협의.
지역: 이동·돌봄·건강과 관련한 학교 밖 장벽을 확인.
16번 · 돌봄 3점학교: 급식·방과후 보호와 안전한 성인 연결 가능성 검토.
지역: 실제 돌봄 공백 시간과 대체 돌봄·식사 제공 지원 확인.
20번 · 주거 4점학교: 휴식·학습·출결에 미치는 영향 파악.
지역: 거주 안전·환경·지원 조건 확인. 실제 보고가 없다면 체납·퇴거로 단정하지 않음.
04 / MODEL ROLES

모델은 서로 대체하지 않고 단계별로 협업합니다

CORE는 결과의 원점수와 안전판정의 단일 기준입니다. SUPPORT-5·ICSI·NCB·OY-CIE·K-CARR·ICMS·Relations는 각각 해석·연계·기록을 보강하며 점수를 다시 채점하지 않습니다.

연결성 검사에 포함한 항목

모델 모듈 로드·메서드 계약, 25문항 점수 불변, 결측/긴급 신호, 지역자원 후보, 사례사정·계획, CIE 응답, 가계도·생태도 및 PC·모바일 브라우저를 검증합니다. 자동검사 성공은 점수의 실증 타당도 또는 실제 서비스 효과 입증과 다릅니다.

05 / SAFETY & TRANSPARENCY

개인정보와 검증 결과

개인정보는 최소한으로

식별 가능한 학생 이름, 전화번호, 상세주소, 불필요한 질병·가족정보를 자유서술에 기재하지 마세요. 기본 상담 입력은 브라우저에서 처리되지만, 파일로 저장하거나 외부 AI로 복사하면 별도 보호가 필요합니다.

전체 ZIP 다운로드는 선택 항목에 따라 서술 원문·실제 기록을 포함할 수 있으므로 공유 전 내용을 확인해야 합니다.

합성검사와 현장 검증은 다릅니다

V8.6 기반 모델 개발 과정에서 상세 서술 2,500건, 간단 서술 2,500건, 서술 없음 10,000건의 합성 시나리오를 검사했습니다. 이는 코드 회귀검사이지 독립된 실제 학생 15,000명의 타당도 평가가 아닙니다.

실제 전문가 일치도·학생의 변화·중재 효과, 위험 예측 정확도는 별도로 검증되지 않았습니다.

문항·판정의 전문적 한계

25문항은 연구용·현장 검토용 비표준화 TEST 척도입니다. 공식 CORE 점수와 규칙 기반 설명 계층은 분리되며, 0~4점의 간격이 임상적으로 등간 검증되었다고 가정하지 않습니다. 자해·자살 위험을 미래 점수나 색상등급으로 예측하지 않습니다.

참고: NICE NG225 자해 평가 원칙 · COSMIN 측정도구 검증 프레임워크

버전별 세부 기술자료

운영 해석 화면 V8.8.7 / 공식 CORE 25문항·100점 계산 불변. 이전 V7~V8.3 변경 이력과 상세 기술 검수는 별도 문서로 관리하며, 본 사용안내에는 반복해 표시하지 않습니다. V8.7의 목표 묶음은 척도 문항별 확인사항을 없애지 않으며, 개인정보 자동 가림은 사람이 확인해야 합니다.

개발 검수자료는 모델 등록부와 이전 근거 분석에서 추가 확인할 수 있습니다. 이후 운영 버전·검수 상태가 변경되면 안내도 함께 갱신합니다.

선택형 AI 지원

AI 연구 작업실 사용 방법

④ AI 연구 작업실은 현재 사례의 척도·서술·종합의견·사정·계획·자원을 선택해 OY-CIE 규칙·검색형 엔진에 질문하고 분석결과를 화면에서 확인·복사·인쇄할 수 있습니다. 외부 AI를 이용하려면 개인정보 가림 및 기관 기준을 확인한 뒤 요청문을 직접 복사·붙여넣어 사용합니다. 외부 AI 답변은 시스템에 자동으로 수신되거나 확정 결정으로 저장되지 않습니다.
