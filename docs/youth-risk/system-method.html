01 · HOW TO USE

학생 지원을 잇는 다섯 단계

화면 위쪽의 단계 버튼으로 이동합니다. 모든 단계는 같은 회차의 25문항 응답과 안전판정을 함께 씁니다. 앞 단계에서 응답을 고치면 다시 완료해야 뒤 단계에 반영됩니다.

02 · WALKTHROUGH

처음부터 끝까지, 한 사례의 흐름

처음 쓰는 교사·교육복지사·사회복지사를 위한 순서입니다. 각 단계는 협의 전 초안을 만들 뿐이며, 결정은 면담과 사례회의에서 합니다.

  1. 안전 신호부터 확인합니다1·2·7·25번은 1점이라도 있으면 점수와 관계없이 오늘 안전을 직접 확인합니다. 4번이 1점 이상이거나 5·12·13번이 3점 이상이면 현재 위험 여부를 추가로 묻습니다.
  2. 25문항을 입력합니다최근 1개월의 관찰·상담을 기준으로, 마음의 어려움은 최근 2주를 중심으로 답합니다. 모르는 내용은 0점이 아니라 ‘미상’을 고릅니다.
  3. 필요하면 서술기록을 적습니다학생 이름·연락처·주소 같은 식별정보는 쓰지 않습니다. 서술은 공식 점수를 바꾸지 않고 ② 서술기록 분석과 ③ 통합 사정의견에만 쓰입니다.
  4. 완료를 누르고 ① 척도 해석을 읽습니다CORE 공식 판정, 레이더와 영역별 응답강도, 해석지(요약 → 영역 해석 → 교차 패턴 → 강점 → 개입 수준 → 계획 → 면담 질문 → 재평가 기준)를 차례로 봅니다.
  5. 면담 질문으로 학생의 이야기를 듣습니다해석지의 첫 질문은 학생에게 바로 쓸 수 있는 문장입니다. 학생이 바라는 도움과 이미 받고 있는 지원을 함께 확인합니다.
  6. 02 지역자원 연계에서 후보를 고릅니다행정동을 선택하면 관할이 맞는 후보가 정리됩니다. 카드의 확인 배지를 보고, 미검증 자원은 기관에 직접 문의한 뒤 연계합니다.
  7. 03에서 계획과 사례회의 안건을 정리합니다주관 기관과 협력 기관, 단계별 개입계획, 사례회의 안건을 실제 상황에 맞게 고칩니다.
  8. 05에서 기록하고, 정한 날짜에 다시 평가합니다재평가 기준에 적힌 목표 수준과 비교해 변화를 확인합니다. 이 사이트는 자동으로 영구 저장하지 않으므로 필요한 자료는 직접 저장합니다.
03 · READ THE RESULT

결과 탭 세 개와 단계 표시 읽기

01 단계의 결과는 세 탭으로 나뉩니다. 서술기록을 입력하지 않았다면 ①만 읽어도 충분합니다.

① 척도 해석

25문항만으로 만든 해석입니다.

  • 통합지원 5단계와 CORE 공식 판정
  • 10개 영역 레이더·영역별 응답강도
  • 보조지표 해석도구(4구간 표, 5개 상위 축, 생태체계 링)
  • 심층 해석지와 개입 수준·계획·면담 질문

② 서술기록 분석

입력한 서술을 문장 단위로 읽습니다.

  • 어떤 생활 영역의 단서인지
  • 부정(“없다고 함”)·추정·전언·과거 언급 구분
  • 척도 응답과 맞는지, 어긋나는지

③ 통합 사정의견

척도와 서술을 함께 읽은 종합 의견입니다.

  • 핵심 지원축과 교차 특성
  • 우선 실행과 권장 진행체계
  • 서술이 없으면 척도만으로 작성

화면에 함께 나오는 세 가지 단계

세 표시는 계산 규칙과 지위가 다릅니다. 공식 판정은 CORE 하나이며, 안전 신호는 세 표시 모두에 앞섭니다.

표시범주무엇으로 정하나지위
CORE 지원검토 단계0~3단계, 미상이 있으면 보류지원집중 영역 수와 3~4점 문항 수공식 판정
통합지원 5단계 (SUPPORT-5)1 안정관찰 ~ 5 최우선 안전대응점수 구간·응답 패턴·안전 기준 중 가장 높은 단계개발형 보조지표
개입 수준 (해석지)관찰·예방 ~ 위기개입 후 집중 사례관리CORE 단계와 안전 신호사례관리 강도 초안

예: 6·9·19번이 각 3점이면 CORE 3단계(다기관 집중지원 필요성 검토), 통합지원 제4단계(고위기개입), 개입 수준 집중 사례관리(다기관)로 표시됩니다. 이름이 달라도 같은 응답을 다른 관점에서 본 것입니다.

점수를 읽을 때 지킬 네 가지

  • 100점은 문항 응답의 합계입니다.25문항 × 0~4점이지만 미래 위험을 예측하거나 지원 자격을 정하는 점수가 아닙니다.
  • ‘미상’과 ‘0점’은 다릅니다.미상은 판단 보류이며 0점으로 바꾸지 않습니다. 0점도 이번 응답에서 보고되지 않았다는 뜻이지 위험이 없다는 증명은 아닙니다.
  • 4구간은 규준이 아닙니다.보조지표의 1~4구간은 척도 범위(문항당 0~4점)를 네 등분한 위치이며, 다른 학생과 비교한 백분위가 아닙니다.
  • 서술과 점수가 다르면 질문으로 남깁니다.시스템은 점수를 임의로 고치지 않습니다. 실제 상황과 평가 시점을 다시 확인합니다.
04 · ASK AI

「AI에 묻기」 사용법

해석지 각 부분의 제목 옆과 보고서 출력 옆에 있습니다. 사이트는 자료를 외부로 자동 전송하지 않으며, 외부 AI 답변은 공식 점수와 안전판정을 바꾸지 않습니다.

1. 해석지에서 바로 찾기

「이번 주에 먼저 할 일은?」, 「면담 첫 질문은?」, 「학교·복지관은 각각 무엇을?」, 「사례회의에서 다룰 안건은?」 같은 자주 묻는 질문은 해석지에 이미 있는 내용으로 바로 답합니다.

2. 외부 AI에 묻기

더 깊은 질문은 짧은 요청문을 복사한 뒤 ChatGPT·Claude·Gemini 중 쓰는 서비스에 붙여 넣습니다. 기본은 척도 결과만 담기고, 서술기록은 직접 선택할 때만 들어갑니다. 복사 전 개인정보 확인 항목에 체크해야 합니다.

3. 답변 검토·저장

받은 답변을 붙여 넣고 사실과 다른 부분을 고친 뒤 「04 자문 모음에 저장」을 누릅니다. 답변은 이 브라우저 탭에만 있고, 탭을 닫으면 사라집니다.

4. 보고서를 AI로 작성·보완

보고서 출력 옆 「AI로 보고서 작성·보완」이나 04 화면의 버튼으로 통합사례보고서·사례회의 안건지 요청문을 만듭니다. 결과물은 실무자 검토본으로만 씁니다.

기관의 외부 AI 이용 기준을 먼저 확인하세요. 안전 확인이 필요한 응답이 있으면 외부 AI에 묻기 전에 학생의 현재 안전부터 직접 확인합니다. 이전의 규칙형 대화 엔진(OY-CIE)은 메인 흐름에서 빠지고 머리글의 「OY-CIE 연구 작업실」에만 남아 있습니다.

모델은 서로 대체하지 않고 역할을 나눕니다

CORE는 원점수와 안전판정의 단일 기준입니다. SUPPORT-5, 문항 지식·교차 패턴(ICSI 계승), 서술기록 분석(NCB·K-CARR), ICMS, Relations, AI에 묻기와 OY-CIE 연구 작업실은 해석·연계·기록을 보강할 뿐 점수를 다시 채점하지 않습니다. 자원연계는 후보와 확인 상태를 보여 줄 뿐 접수·제공을 확정하지 않습니다.
