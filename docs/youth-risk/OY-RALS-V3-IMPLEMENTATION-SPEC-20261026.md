## 2. 레이더 지표

- 차트 축(10개) 바깥에 영역명 직접 표시.
- 중심 0%, 외곽 100%. `영역 응답 합계 / 해당 영역 확인 응답의 가능한 최대치 × 100`으로 비교.
- 점 hover/touch/keyboard를 통한 표시: `영역명 / 응답강도 % / 확인 합계 / 확인 최대 / 미상 수`.
- 미상만 존재하는 영역을 실제 0점으로 해석하지 않는다. 본 지표의 면적은 발생 확률, 전체 점수 또는 공인 진단이 아니다.
- 원점수·안전 게이트·5단계 개발형 지원우선순위는 독립 유지.

## 3. 영역 간 동시응답

- OY-CIE 문항쌍 데이터(`OYCIESemanticV2.scoreCombination`)를 교차영역의 실제 응답번호와 연결.
- 상위 3개 교차유형을 요약하고 3~4점 문항의 집중 구조를 별도 표시.
- 표: 교차유형, 동시응답 강도, 해당 문항 번호와 응답점수, CIE 의미, 학교 개입·지역연계의 역할 구분.
- 교차강도는 두 영역의 정규화된 응답강도 중 낮은 값을 반영하는 **내부 비교지표**이며 인과효과·통계적 상관값·검증된 위험확률이 아니다.
- 모든 교차쌍을 일괄 고위기로 보지 않고 실제 응답 문항과 강점·기존 지원도 함께 살핀다.

## 4. 자유서술 분석

- `YouthCaseContextCore.splitClauses/infer`를 재사용.
- 단락별 원문과 주제, 문장별 출처·시간·부정·문항·영역 연결, 영역별 서술 보강을 각각 표기.
- 학생의 과거사건, 가정적 예시, 제3자의 사건을 현재 학생의 확정 사실로 변환하지 않는다.
- 서술 원문이 없는 경우 추론된 사건을 생성하지 않으며 기존 객관적 척도 계산에 영향을 주지 않는다.

## 5. 종합사정·개입방향

① 핵심 상황 → ② 현재 안전 → ③ 학교·가정 생활기능 → ④ 강점과 학생 희망 → ⑤ 첫 1~2주 실행 → ⑥ 중기 변화목표.

- 5·6단계 과제는 기존 ICMS·K-CARR의 추천계획 중 관련도 높은 과제 3개를 중심으로 표시한다.
- 실행과제·학생의 현재 어려움·생활기능 변화지표를 묶어 실무자 관점의 다음 행동을 강조.
- 기존 장문 분석은 더 읽을 수 있으나 실무자의 첫 화면은 주제형으로 분리.

## 6. 가계도와 생태도

- 원칙: 실무자가 확인한 관계만 확정 표기. 가족관계(법적/혈연)는 서술만으로 단정하지 않음.
- 동거: 실무자 확인 체크 시 **점선 외곽 범주**.
- 관계 상태: 강한 지지(굵은 선), 보통 지지, 약한 지지(점선), 단절·갈등(긴 점선).
- 방향: 학생이 지원받음 / 학생이 돌봄 제공 / 상호지원 — 선택에 맞는 화살표 사용.
- 근거·출처 텍스트를 도식 아래에 유지. 입력한 실명·의료정보가 외부 서버에 자동 전달되지 않도록 기존 구조를 보호.
- 학생의 가족관계와 실제 기관 서비스 제공을 자동으로 확정하지 않는다는 한계는 그대로 표시한다.

## 7. 검수·릴리스 판정

1. 기존 25문항 100점 CORE, 안전신호, 결측치는 불변인지 검사.
2. 10개 축 라벨과 상호작용 포인트 수(각 10개), 정확한 퍼센트·문항근거 표시 여부 확인.
3. CIE 문항쌍 대응, 없는 문항 고점 임의생성 없음.
4. 가상 서술의 부정·과거·희망·가족관계 단서 분리, 실제 문항과 연결 확인.
5. 관계선 강도·동거 점선·지원방향·흑백 인쇄 및 개인정보 최소화 확인.
6. PC 1280px·모바일 390px 브라우저, AI 작업실, PDF, 자원연계 회귀검사를 수행.
7. 자동검사 통과는 실제 실증 타당도·개입효과·임상진단을 의미하지 않는다.
