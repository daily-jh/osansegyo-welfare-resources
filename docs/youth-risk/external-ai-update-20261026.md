# 2026-10-26 외부 AI·보고서 출력 개편

최신 공개 버전의 CORE·SUPPORT-5·9개 모델 게이트웨이와 5단계 화면을 유지하면서 외부 AI 문서 작성 흐름을 추가했다. 이전 로컬 작업본은 Git stash에 보관하고 공개 최신 커밋을 기준으로 통합했다.

- 결과·지원연계·사례사정·계획·기록 화면 하단에서 목적과 실무 관점을 선택해 요청문을 복사한다.
- 요청문은 원응답 25개, 안전 추가확인, 시스템 지원단계·상향 근거, 영역별 결과·응답 패턴·계획 후보를 포함한다. 원문 서술·자유메모·이름·성별·행정동·연락정보는 포함하지 않는다.
- 외부 AI에는 학교·복지관에서 사용하는 구조화된 사정지·사례판정 보고서·서비스계획서·진행/점검 기록을 요구한다. 검색·문서분석 기능을 활용하고 공식 원문의 발행일·URL·적용 근거·한계를 밝히며, 확인하지 못한 출처를 생성하지 않도록 지시한다.
- SUPPORT-5의 안정관찰·초기주의·집중지원·고위기개입·최우선 안전대응을 정의하되 기존 계산·우선순위·안전 규칙은 변경하지 않는다. 지원우선순위와 실제 사례의 접수·판정·계획·실행·점검 상태를 구분한다.
- 연구작업실의 기본 흐름은 요청문 선택·복사 → ChatGPT/Claude/Gemini 열기 → 답변 붙여넣기·검토·수정·출력이다. 기존 OY-CIE 규칙·검색 기능은 별도 선택 항목으로 접었다.
- 외부 AI로 복사·출력하기 전에 민감정보 확인을 요구한다. AI 서비스 홈을 여는 링크에 사례자료를 붙이지 않으며 자료·답변을 자동 전송하거나 수집하지 않는다. 답변은 현재 탭에서만 유지한다.
- 통합보고서 PDF는 핵심요약, 10영역 사정근거, 통합사정·사례협의, 서비스계획, 통합사례 진행·점검을 제목과 표로 구분한다. 실제 기준선·합의 목표·담당·일정과 회의 결과는 미확인란으로 남긴다. 원문·작성 메모 포함 여부는 기존 선택을 따른다.
- 현재 정량 결과 PDF는 점수·안전·지원단계와 기존 시각화를 함께 출력한다. 통합보고서는 큰 대시보드 대신 지원단계 요약만 붙여 불필요한 출력 분량을 줄였다.

검증: 청소년 관련 검사 48개 파일 및 모델 계약 12개·배선 검사 통과. Edge에서 실제 25문항 입력, 단계별 요청문, 복사 전 확인, 통합보고서 PDF, 외부 AI 답변의 안전한 텍스트 출력, 모바일 폭을 확인했다. 가상 응답 PDF를 페이지별로 렌더링해 출력 구성을 확인했다. 외부 AI가 수행할 검색·작성 결과의 정확성은 실무자가 별도로 검토해야 한다.
