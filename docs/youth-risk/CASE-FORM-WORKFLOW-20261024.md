# 초기상담·욕구사정 작성 흐름 후속 보완

2026-10-24. 50가상사례 검수에 이은 사용성·출력 검수이다.

- 초기상담 미리보기는 항목명/내용의 간결한 표로 정리했다. 18개 원래 항목과 경제의 수입→지출→부채→재산→기타 순서를 유지한다.
- 빈칸은 `—`로 표시하고 '미확인 · 면담에서 확인 필요' 안내는 한 번 표시한다. 빈칸을 0점·욕구 없음·확인 완료로 바꾸지 않는다.
- 욕구사정은 10개 영역을 모두 유지한다. 작성한 영역은 펼치고, 나머지는 '면담 단서 있음/미상 확인 필요/추가 면담 전' 상태로 접어 표시한다. 작성현황은 입력 여부이며 정확성·합의 여부 점수가 아니다.
- 학생의 희망·강점 등 공통 기록은 기존 지원계획 입력란을 그대로 사용한다. '공통 기록 입력·수정'으로 해당 입력란으로 바로 이동한다.
- 제시된 욕구 또는 목표가 작성된 경우에만 '지원계획에 가져오기'를 사용한다. 추가·통합 목표에 검토안으로 전달하며 합의·승인·수행 상태를 만들지 않는다.
- 같은 영역의 자동 전달문은 한 개만 유지한다. 자동 전달문이 그대로 있으면 변경내용으로 갱신하고, 사용자가 계획에서 직접 수정한 경우에는 덮어쓰지 않고 확인을 요청한다. 전체 입력 한도를 넘으면 내용을 잘라 넣지 않고 전달을 중단한다.
- 복사는 화면의 접힘 상태와 관계없이 전체 영역·작성내용을 포함한 텍스트를 만든다. 인쇄용 복제본은 접힌 내용을 모두 펼쳐 누락을 방지하며 화면의 접힘 상태는 유지한다.
- 청소년 척도·안전 규칙·행정동 권역·지원 연결지도는 변경하지 않았다. 자유서술의 사실성·합의 여부는 담당자가 확인한다. 자동 저장이나 외부 전송을 추가하지 않았다.

검증: `node tests/youth-case-form-workflow.cjs`, `node tests/youth-scenarios-50.cjs` 및 DOM 통합 검수(단계 이동, 수정 반영, 중복 전달 방지, 직접 수정 보호, 복사·인쇄 전체성, 입력 한도, XSS).
