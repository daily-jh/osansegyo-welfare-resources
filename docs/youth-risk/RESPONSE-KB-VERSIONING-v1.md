# OY-RALS 한국어 해석·교차추론 응답 지식베이스 관리규격 v1.0

- 기준일: 2026-10-23
- 배포 경로: `docs/youth-risk/data/response-knowledge-600-v1.json`
- 적용 모듈: `response-knowledge-integration.js` → `language-response-ui.js` (3단계 사례검토)
- 원본 연구형 원고: **600개 독립 페이지 단위, 실제 600쪽 PDF 및 600레코드 JSONL** (이 대화에서 제공된 외부 편집본). 아래 JSON은 실행 시 필요 정보만 추린 웹용 인덱스이며 원고 전체 600쪽이 GitHub에 올라간 것은 아닙니다.
- 기존 실행계층: `criteria.js`, `support-model.js`, `evidence-matrix.js`, `review-model.js`, `case-examples-model.js` **변경하지 않고 유지**한다.
- 데이터 속성: 시험용 개발 가설, 합성문안. 임상·법적 판정 및 미래 사고 예측은 허용하지 않는다.

## 1. 600개 레코드 구성

| 종류 | 편집 가능한 단위 | 건수 |
|---|---|---:|
| 점수 문항별 | 25문항 × 0·1·2·3·4·미상 × S(학생 진술)·T(교사 관찰)·A(기관 협력) | 450 |
| 교차규칙별 | 24규칙 × 0·1·2·3·미상 검토상태 | 120 |
| 운영·연구 원칙 | 내용타당도, 정보출처, 안전, 편향, 서비스계획 등 | 30 |
| **합계** | | **600** |

각 항목의 `evidenceStatus`는 `untested_hypothesis` 또는 `practice_design`이다. 모두 학술적으로 검증된 예측·인과 규칙이 아니다. 23개 외부 출처는 맥락 및 설계 원칙의 참고문헌이다.

## 2. 답변 생성 순서

1. 기존 시스템이 점수, 미상, 안전 체크를 확정한다. 이 판정값은 수정하지 않는다.
2. 기존 한국어 응답 모델이 질문 의도 및 문항/서술 주제를 탐색한다.
3. 웹용 지식베이스에서 **해당 문항·실제 점수·선택 관점** ID를 검색한다.
4. 기존 교차규칙에서 실제 충족된 ID만 검색하여 교차 가설 문장을 추가한다.
5. 답변에 근거 문항 번호, 문장 검토 질문, 교사/복지사 행동, 관찰지표, 단정 금지, 참고문헌 ID를 붙인다.
6. 필요한 경우 실무자가 편집하고 실제 기관의 문의·의뢰·접수·제공을 확인한다.
7. 지식베이스를 불러오지 못하면 기존 기본 모델만 제공하고 오류를 알린다.

## 3. 연구·운영 분리

- **공식 평가·안전 판단**: 기존 코드만 권한이 있다. 별도 연구가설이 점수·단계·신고의무를 바꾸지 못한다.
- **설명·질의응답**: 연구형 가설의 추가·교체·중지가 가능하다. 관찰 사실과 구분하고 반증·미확인을 표시한다.
- **상담·사례관리**: 학생 희망과 안전, 기존 지원, 주관기관 협의 및 실제 이행을 담당자가 최종 확인한다.
- **개인정보**: 공개 저장소에 실제 사례, 이름, 진술, 지번, 연락처, 주민번호, 상담녹취·보호기록을 넣지 않는다.
- **외부 AI**: 사용자가 명시적으로 선택한 경우에만 별도 기능을 활용하며 현재 엔진의 점수 및 안전결론을 AI가 변경할 수 없다.

## 5. 다음 버전 승인 기준

- 가설의 독립성: 새로운 기록·연구를 통해 기존 설명과 다른 추가사정 가치가 있어야 한다.
- 증거 추적: 논문 제목·연도·연구설계·대상·링크·한계를 함께 기재한다.
- 반례 점검: 누락·부정·간접진술·동일 사건 중복·이상 점수 조합 테스트를 포함한다.
- 안전 게이트: 1·2·7·25번 및 4·5·12·13 추가확인과 충돌하거나 위험 조치를 지연시키면 승인 불가.
- 공정성: 성별, 한부모 여부, 빈곤, 장애, 출결만으로 학대·진단·법정 자격을 단정하지 않는다.
- 실제 효과: 전문가 합의도·연계 접수율·문장 비약률·동일 사건 중복률은 실제 별도 검수로 평가해야 한다. 합성 샘플은 정확도 수치의 근거가 아니다.

## 7. 2026-10-23 원고형 근거집의 범위

600쪽에는 기존 문항별 근거–가설–반증–안전 조치–응답–목표·점검을 교차 구조로 기술했다. 외부 문헌의 내용 전체를 복제하지 않고 독자적 실무 가설과 합성 사례를 집필했다. 문헌 23건은 **기본 원리의 참조 출처**이지 600개 문장을 독립적으로 실증 검증한 문헌 600건이 아니다.

원고와 웹 지식베이스에서 동일 ID (`I07-3-T`, `P09-2`, `M15` 등)를 사용한다. 업데이트할 때 원고→JSONL→웹 축약 데이터→자동검사→전문가검수→배포 순서를 권장한다.
