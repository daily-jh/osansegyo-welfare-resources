# OY-CIE V3.3 한국어 해석 표본 확대 — 개발 설계 및 검수 안내

- 연구형 버전: V3.3 (V3.2 규칙·검색형 응답기 확장)
- 개인정보: 실제 학생·보호자 정보 **사용하지 않음**
- 유지 조건: CORE 25문항 원점수·미상·안전판정 변경 금지
- 원자료: 기존 연구형 응답 DB 600건, 교차가설 300건, 실무용 템플릿 80개. 이 자료들은 새로운 실증정답이 아님.
- 새로운 시드: 12개 주제 × 긍정적 문제 보고/부정 서술/과거 사실 = 36개 사람이 직접 설계한 가상 표현(실증 레이블 아님)
- 교차 확장: 16개 점수·미상·사건형 프로파일, 8개 질문 의도, 3개 실무자 역할, 25문항 점수 배치, 120,000개 합성 분석
- 표본집: 모델이 실제 생성한 고유 응답 중 최대 1,200건을 GitHub Actions artifact로 보관; **서식·참조·안전검사 목적**.
- K-CARR·문항별 의미모델을 분리 호출해 약 1,792개 시점별 비교 관찰. 이견은 실제 위험 판단의 오류율이 아님.
- 중복 제어: 질문 의도·실무자 관점·정규화된 응답 텍스트 해시로 중복 응답 제거하고 대표 샘플 하나만 보관. 원본 600건 DB의 연구 서술은 변경하지 않음.
- 실제 전문가가 단일 사례를 확인하지 않았다면 정확도·민감도·특이도·κ·CVI 수치를 제시하지 말 것.
- 안전 단서가 모호하거나 지난 시점인 경우 보호절차 검토 질문으로 연결하되 실제 위험을 확정하지 말 것.

## 알고리즘 보완
기존 5개 서술형 라우팅 영역에 정서·건강·교육 접근성·가족돌봄·관계·디지털의 6개 해석 표현 유형을 추가하고, 근거 ID의 허용 형식을 동기화한다. 문장 분해·부정·시점·정보원 검토 구조를 유지하고 모든 결과를 "확인 전 가설"로 표시한다.

## 구현상 한계
이번 추가 패턴은 정규표현식 기반으로 한국어의 다의성·이중부정·다중 주체 관계를 완전하게 이해하지 못한다. 120,000개 입력을 생성했다고 해서 학습형 LLM의 파라미터가 증가하지 않으며, 예시를 외부 학습용 데이터로 자동 공유하지 않는다.

## 운영 반영
이 PR은 테스트와 연구 자료의 확장이다. GitHub Pages 메인에 병합되면 6개 유형의 서술 단서 라우팅이 연구 작업실과 읽기 전용 기존 평가 연결패널에서도 활용 가능하다. 운영 반영 여부는 CI 및 코드 리뷰에 따라 구분한다.
