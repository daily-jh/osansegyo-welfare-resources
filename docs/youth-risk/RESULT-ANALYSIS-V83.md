# 결과 해석 8.3 · 적용 및 해석 범위

2026-10-25. CORE 25문항, V8.2.1 개념분류 및 공식 안전 준거는 유지한다. 지원 연결지도는 변경하지 않는다.

- 결과 첫 화면: 기존 척도 위치 아래 생활 어려움 × 지원 범위 4분면. X=가장 높은 영역평균÷4×100, Y=2점 이상 문항이 있는 영역의 비율. 50 기준 분할은 자체 표시 규칙이며 임상 절단점·인구 사분위가 아니다. 미상은 X/Y 가능한 범위로 표시하고 단일 위치를 보류한다.
- 영역표: 10개 영역, 응답 어려움의 상·중·하(최고 3~4/2/0~1점), 의미, 개입목표·실행, 자원 후보, 교사/사회복지사 역할. 미상 포함 시 수준 보류. 미래 위험 예측·진단·서비스 자격이 아니다.
- 교차분석: 학교×접근성, 돌봄×기본생활, 또래×지지체계, 정서×학교·관계 및 안전한 가정연락 조건을 분석한다. 동시 응답은 인과관계로 확정하지 않는다.
- 세부분류·원문 대조·근거는 접고, 공통 사정을 바탕으로 마지막에 보고서형 종합의견을 제시한다. 전체자료 ZIP의 HTML 보고서에도 도식을 포함한다.
- 임의의 담당자·목표 횟수·승인·실제 서비스 제공을 창작하지 않는다. 기존 자원 후보는 접수·이용 확인 전이다.
