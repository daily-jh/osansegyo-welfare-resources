# OY-RALS UI/UX 2차 개편 기록 — 2026-10-26

적용 위치: `docs/youth-risk/` — 기존 25문항 CORE 채점·안전판정은 변경하지 않음.

## 제공 화면의 8개 개선사항

1. **영역별 레이더 확대**: 500×500 SVG 뷰박스, 넓은 레이아웃, 10개 축별 실제 응답강도(0–100%)와 읽는 방법. 외곽에 가까울수록 해당 영역 내 문항들의 평균 응답강도가 높음. 방사형 면적 자체는 진단·발생확률이나 전체 25문항 위기점수가 아님.
2. **교차영역 의미 부여**: 9개 동시응답 조합마다 교사가 시도할 일과 복지관·지역기관이 맡을 역할을 달리 표시. 점수는 두 영역 중 낮은 정규화 응답강도. 교차는 인과·통계적 상관을 의미하지 않음.
3. **원점수·개별응답 접기**: 점수 중심 보기에서 CORE 원점수/25문항 상세를 접은 내용으로 이동. 대시보드에는 응답완료·지원 우선단계·가중/교차 보조지표 제시. 실제 안전 보호 정보는 유지.
4. **외부 AI 요청문 복사**: 25문항 응답, 공식 안전판정, 10영역 정보, 개발형 지원단계, 동시응답 근거를 포함한 비식별 AI 요청문 복사. 사례 서술·이름은 복사하지 않음.
5. **자원연계 화면 간소화**: 원래 자원연계 지도를 보존하고 중복된 대시보드·CIE 질문 패널을 제거. 다음 단계 CTA는 지도 뒤에 둠. iframe 안에서 보였던 중복 이동 카드만 숨기고 별도 지도 단독 페이지의 기능은 보존.
6. **사례 톺아보기 불필요 입력 제거**: 사례판정 사유, 회의 결정, 개입기록 등 실제 수행 전에는 확정할 수 없는 임의 입력란을 3단계에서 제거. 기록·점검 화면에서 실제 수행 내용 작성. 기존 관계도·생태도 편집은 명시적 예외로 유지.
7. **역할별 실행도식**: 자동결과 '근거 | 사정 해석 | 미확인 사항'의 중복표 대신 문항별 과제, 교사·교육복지사의 첫 실행, 사회복지사·기관 조정, 변화 확인기준을 한 표에 배치.
8. **AI 연구 작업실 기능 수정**: 기존 CIE 질문이 화면 외부에 전달되고 결과가 작업실에 표시되지 않던 동선을 수정. `OYCIEFlowV32.ask()`가 실제 응답 반환 후 작업실의 `#oy-ai-answer`에 텍스트 표시. 역할 선택, 샘플 질문, 복사, 응답 내용 PDF 인쇄 포함. 오류시 실제 오류 메시지 노출.

## 분석과 연구의 해석 원칙

- WHO, *Mental health of children and young people: service guidance* (2024) — 학교·가족·지역사회 서비스의 조직 및 다분야 접근을 참고. https://www.who.int/publications/i/item/9789240100374
- COSMIN, *Content validity and interpretability* — 점수의 해석 가능성과 실제 측정 타당도는 분리해서 보아야 함. https://www.cosmin.nl/
- OY-RALS 교차영역 해석은 **내부 설계가설**이며, 학교·복지기관 실행 방향을 구조화한 예시이지 COSMIN이나 WHO가 이 25문항 도구의 계수·절단점을 검증했다는 뜻은 아님.
- OY-CIE는 규칙·검색 기반 한국어 응답 모델로, 서버 LLM을 자체 운영하는 모델이 아님.
- 식별정보의 외부 전송은 하지 않으며 요청문 복사 후 사용자가 스스로 외부 AI에서 붙여넣고 기관의 개인정보 처리 기준을 준수해야 함.
