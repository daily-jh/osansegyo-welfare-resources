# 클로드 실무자 결과 해석 패치 검토·통합

2026-10-26 · 운영 기준 67cd9a2 · 첨부 자료 기준 ae23365

## 적용

- 0001: 서술 해석은 사용자가 포함을 선택한 경우에만 결과 TXT·AI 요청문에 포함. 구조화 PDF 생성 실패 시 텍스트 결과로 복구.
- 추가 수정: 서술 미포함 PDF에서 현재 화면의 서술 포함 시각화 DOM을 복제하지 않음.
- 0002: 응답 중 문항 위치 유지, 부모 화면 자동 스크롤 억제, 탭 대비·인쇄 표시 개선.
- 0003: CORE 판정 제목, 단계 결정 요인, 미상과 확인 분모, 안전 확인 목록, 척도 전용·서술 포함 단계 차이 설명.
- 기존 유형별 공통 해석보고서와 PDF·TXT 출력 연결 보존. index.html과 journey-v88.js 충돌을 수동 통합.

## 채택하지 않은 계산 변경

0004는 미상 응답의 SUPPORT-5 잠정 단계와 은폐 표현의 자동 안전 하한을 바꾸므로 적용하지 않음. CORE 및 기존 SUPPORT-5 계산 모듈은 변경하지 않음. 부정·과거·제3자 서술은 자동 위험 확정 대신 원문·대상·현재 안전 확인 안내로 노출. 이 결정은 계산 변경의 검증 수준과 모듈 간 정합성에 따른 구현 판단임.

## 검수

결과 설명·서술 출력 보호, 기존 2만 건 SUPPORT-5 검사, 1,200건 모델 계약검사, 아키텍처 연결검사, 1,000건 공통 보고서 검사가 통과함. 합성입력 소프트웨어 검사이며 실제 학생 대상 실증 타당도 검증이 아님. 추가 전체 회귀 및 배포 결과는 GitHub Actions 기록으로 확인.
