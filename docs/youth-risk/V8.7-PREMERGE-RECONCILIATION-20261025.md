# V8.7 통합 전 검수 및 브랜치 정합성 기록

작성일: 2026-10-25

## 확인된 사실
- 기존 V8.7 개발 브랜치: `feature/v87-safety-goals-evidence-privacy-20261025`.
- `main` 대비 diverged: V8.7 쪽 36 commits ahead, main 쪽 2 commits behind (비교 당시).
- V8.7에 SafetyState, GoalComposer, PrivacyGuard, 문서 연결 및 합성입력 테스트가 이미 존재함.
- `criteria.js`는 기존 CORE 평가 함수를 유지함.
- V8.7 보고서의 5,000건 합성검사 통과는 보고서 기록으로 확인되며, 이번 검토에서 재실행한 결과는 아님.

## 병합 전 차단 조건
1. `main`에서 새로 추가된 두 커밋의 수정 파일·동작 확인 및 V8.7로 반영.
2. CORE 점수(25문항 0~100), 미상, 공식 긴급판정 불변성 재검사.
3. 안전 상태 `officialCORE`, `reviewRequired`, `reviewPending`의 의미와 화면 문구가 모든 단계에서 동일한지 검사.
4. 서술형 신호는 증거 수준과 시점에 따라 확인 필요·보호절차 검토로 표시하고 사실 확정으로 과장하지 않음.
5. 개인정보 가림은 패턴 기반으로 불완전함을 고지하고, 외부 전송 전 사용자 미리보기·승인을 확인.
6. 모바일 Safari, HTML 인쇄, DOCX/PDF, ZIP, 복원, AI 연계 실제 종단검사.
7. TEST·비표준화 안내 유지, 실제 임상·현장 실증 타당도 주장 금지.

## 기술 점검 추가 사례
- 모든 문항 0점 + 안전문항 미상 1개: reviewRequired=true, urgent=false.
- 안전문항 고점수 + 후속확인 미완료: 공식 CORE 유지, 확인 과제 보존.
- 낮은 점수 + 현재 위해 서술: 안전검토 필요, 원점수 불변.
- 척도와 서술 충돌: 근거·시점·확인 질문 보존.
- 25문항 목표 25개 원본 보존 + 주요 묶음 최대 5개.
- AI 요청문 및 ZIP 내 이름·전화번호·학교·주소·희귀사건 조합 재식별 검토.
