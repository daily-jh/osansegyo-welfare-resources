## 이번 변경

- 4페이지 변화 점검에 T0~T4 평가 고정 기능: 원점수·안전·미상·버전 보존, 같은 학생·시점 확인, 날짜·단계 역전 및 중복 방지.
- 문항별 근거 성격(관찰·학생 진술·전언·문서·부재 확인·기록 없음·미실시), 기록일·발생일을 구분. 현재 자료를 고정할 때 기준일 이후 근거가 있으면 차단.
- 미상 해소, 새 미상, 공통 확인 문항의 점수 차이를 별도 집계. 효과·호전·원인으로 자동 판정하지 않음.
- 브라우저가 지원하면 SHA-256 지문을 표시. 지문은 전자서명·외부 보관 증명·실제 기록의 진실성 보장이 아님. 현재 탭에만 유지하며 자동 저장·서버 전송 없음.
- 검증 현황과 연구절차 페이지 및 빈 CSV 3종 추가. 실제 사례·독립 전문가 결과를 입력하거나 수집한 것으로 표시하지 않음.
- 시스템 안내·구조도·보고서의 실제 모듈 버전을 정리. 일반 온라인 협박과 성적 온라인 피해를 구분하도록 기존 서술 문구 보완.
- casework-v3의 희소 응답 배열 입력 거부 보완.

## 연구와 실무 도구의 경계

50만 합성 입력은 v2.2 기술검사 기록이며 이번 변경을 50만 건으로 다시 검사했다는 뜻이 아니다. 공개 사례 20건은 질적 대조 자료이다. 실제 사례의 민감도·특이도·독립 전문가 일치도·종단 타당도·전향적 효과는 미검증이다. 학생의 실제 기록·연구 데이터는 공개 저장소에 추가하지 않았다.

시점 자료가 실제로 당시에 존재했는지, 같은 학생인지, 보호·연구절차가 적절한지는 담당자의 확인이 필요하다. 현재 도구는 독립 평가자를 눈가림하거나 연구자료의 외부 보관을 수행하지 않는다. 연구용 가명자료는 승인된 별도 환경에서 관리한다.
