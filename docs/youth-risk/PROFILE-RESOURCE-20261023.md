# 학생 기본정보와 공용 자원 데이터 연계 (2026-10-23)

- 학생 이름은 선택 입력이며 평가 화면의 결과 표시에만 사용합니다. 연결지도·참고 보고서·AI 요청문에는 실명을 전달하지 않습니다.
- 성별은 남/여/미확인/응답하지 않음, 주소지는 오산시 8개 행정동/미확인/오산시 외로 선택합니다. 상세주소와 법정동을 수집하거나 추정하지 않습니다.
- 성별·행정동은 위기점수·안전판정·가정계수·교차규칙을 변경하지 않습니다. 성별만으로 피해·진단·서비스 자격을 추정하지 않고 접수 요건 확인에 사용합니다.
- 거주 행정동이 확인되면 경제·주거 등 관련 응답의 공공창구를 해당 행정복지센터로 연결합니다. 미확인 상태에서는 임의의 동·전화·주소를 제시하지 않습니다. 오산시 외 거주자의 공공 관할은 별도로 확인합니다.
- 복지관·학교·전문기관의 관할은 행정동만으로 확정하지 않습니다. 지도 링크는 기관 위치 확인용이며 거리순·최단 이동·실제 접수 가능성을 계산한 결과가 아닙니다.

## 데이터·추천 일치

`data/organizations.csv`·`data/services.csv`·`data/contacts.csv` → `scripts/build_data.py` → `docs/assets/data.js` → `resource-adapter.js` → 평가 결과/연결지도/보고서/AI 요청문.

공용 데이터의 기관·서비스 ID, 대표전화, 사업 연락처, 주소 및 주소 검토 상태·확인일·유의사항을 전달합니다. 주소가 사용자 제공 구글 자료이면 그 상태를 그대로 표시하며 공식 확인으로 변경하지 않습니다. 원본에서 대표전화가 없으면 과거 고정 전화번호로 대체하지 않습니다.

추천은 안전·개별 응답 근거와 기존 공공기관의 역할을 우선합니다. 민간 심리·발달지원은 관련 2점 이상 응답, 정신건강 의료기관은 관련 높은 기능 어려움 또는 안전신호, 해바라기센터는 관련 피해 문항 응답이 있을 때 추가 문의 후보로 표시합니다. 복합 문항만으로 성폭력·진단을 확정하지 않으며 실제 대상·비용·피해유형·진료범위·운영·접수 여부는 문의사항입니다. 일반 기관 예약은 긴급 안전대응을 대체하지 않습니다.

기본정보 변경은 기존 평가결과를 무효화하며 평가를 다시 완료하면 새 관할의 결과와 보고서를 생성합니다. 비식별 평가 JSON은 이름·성별·행정동·자유서술을 포함하지 않으며 불러올 때 연계용 기본정보를 초기화합니다.

## 검증과 한계

8개 동별 창구·주소·전화 일치, 미확인/타지역 처리, 기본정보 변경 후 재계산, 결과·계획·AI 후보 일치, 0점/미상/긴급신호를 자동 검사합니다. 실제 HTML의 스크립트 실행·응답·기본정보 변경·요청문 생성은 DOM 통합검사로 확인했습니다. 기존 종합의견의 가상자료 10만 건 검사에서도 기술 오류 0건이었습니다. 이는 실제 학생 자료의 임상적 타당도·정확도 검증이 아닙니다. 공개 사이트의 실제 브라우저에서도 성별·행정동 입력과 25문항 평가 후 관할 창구·주소·전화가 표시되는 것을 확인했습니다. 휴대폰 실기기별 시각 검수는 별도입니다. 시청 대표전화 경유인 번호는 동 직통전화와 구별해 원본의 창구 설명을 함께 표시합니다.
