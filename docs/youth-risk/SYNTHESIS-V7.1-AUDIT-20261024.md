# V7.1 사례 사정·그래프·실행계획 요약·일괄 내려받기

적용일: 2026-10-24. V7 모델의 점수·문항·안전 준거를 교체하지 않는 표현·연결·내보내기 개선이다.

## 수정한 문제

이전 부분응답 화면은 큰 어려움을 문항 번호로만 설명했고, 미상이 하나라도 있으면 영역 그래프 경로 전체가 빠졌다. V7 자유서술 검토는 하단의 추가 패널에서만 표시되어 기본 리뷰·실행과제로 연결되지 않았다. 영역별 서술은 일반 설명을 나열했으며 서비스계획의 전체 요약표와 통합 저장 경로가 없었다.

`case-synthesis-v71.js`는 번호를 생활상 의미로 해석하고 영역 간 공동 사정 주제를 구성한다. 입력 서술에서 보고된 진단·복용, 수업 참여·행동 지속, 보호자 폭력·연락 조건, 신고 언급과 참여 제한 등을 분리하여 생활 영향·정보 공백·우선 행동에 연결한다. 결과는 입력자의 보고에 근거한 초안이다. 진단·복약 상태·원인·가족 의도·신고 수리·현재 보호조치·서비스 개시를 확인된 사실로 만들지 않는다. 부정·가정 문구는 실제 위해로 자동 격상하지 않는다. 한국어 복합문·다중 사건의 의미 파악에는 한계가 있다.

## 기관 문체와 근거

오산세교 사례관리 스킬의 `references/writing-style.md`를 읽고, 그 문서에 정리된 기존 사례보고서·회의록·서비스계획서의 어투를 적용했다. 원 사례의 개인정보·개별 사실을 공개 코드로 가져오지 않았다. ‘보고됨/진술됨’, ‘확인 필요’, ‘판단·개입 필요’를 구분하고 1) 영역 제목과 짧은 문단으로 구성했다. 기관 16문항 척도로 환산하지 않는다.

의료·교육 협력의 일반 개발 근거는 NICE NG87 Recommendations 1.4/1.5/1.10의 교육환경 조정·보호자 지원·치료 경과 검토를 참고했다: https://www.nice.org.uk/guidance/ng87/chapter/recommendations (2026-10-24 조회; 검색 본문 확인, 직접 페이지 열람은 403으로 제한). 이 문헌은 OY-RALS의 효과성 검증이나 국내 제도·법적 판단 근거가 아니다. 약물 변경·용량 지시를 생성하지 않고 처방 의료진의 검토 역할과 학교 관찰·환경 지원을 구분한다.

## 그래프

가로축은 문항당 0~4점 척도, 세로축은 10개 영역이다. 확인 합계/영역 전체 문항 수의 길이는 파랑, 미상 점수에 따라 남은 수학적 범위는 빗금으로 표시한다. 미상 영역의 관찰 평균은 `null`이며 ‘평균 보류’로 표기한다. 빗금 범위는 신뢰구간·위험확률·예측구간이 아니다. 총점 보류와 안전 우선 규칙은 유지한다. 새로운 X/Y 가중 사분면이나 임상 절단점을 만들지 않았다.

## 문서·가독성

3페이지의 첫 행동과 담당별 실행은 입력 서술에 따라 조정된다. 단·장기 목표와 세부 과제 앞에 간략한 전체 실행계획 표를 둔다. 영역별 제목·첫 행동을 강조하고 본문 기본 크기는 18px, 작은 화면은 17px를 적용했다. 반복 주의문·모델 추적은 접어서 확인한다.

## 전체 자료 ZIP

외부 라이브러리·서버 변환 없이 브라우저에서 CRC32·UTF-8 ZIP을 만든다. 기본 12개 자료: 안내, 복원용 평가 JSON, 종합 사정·그래프 HTML, 리뷰 TXT, 서비스계획 HTML, 사례협의안 HTML, 25문항 CSV, 기관 후보 CSV, 초기상담·욕구사정 TXT, 독립 SVG 그래프, 영역 요약 CSV. 서술 포함 선택 시 원문 TXT와 이를 반영한 사정·계획을 포함한다. 선택 시 현재·이전 작성 기록도 평가 차수별 폴더에 HTML·작성 필드·원 평가 응답·초기상담·욕구사정으로 보관한다. 작성한 기록이 없는 경우 실제 회의·합의 내용은 생성하지 않는다.

기본 평가 JSON은 계속 서술을 제외한다. 기본 리뷰·문서 복사·인쇄 역시 서술을 제외한 자료로 생성한다. 전체 자료 ZIP의 포함 옵션을 선택한 경우에만 서술·직접 기록이 담긴다. 파일 보관·공유 시 기관의 개인정보 기준을 따른다. CSV 수식 실행과 ZIP 경로 이탈을 방지하고 HTML은 입력을 이스케이프한다.

## 검증·범위

- 사용자가 제공한 예시와 서술을 로컬에서 재현했다. 공개 테스트·보고서·로그에는 원 사례의 문장·응답 벡터를 넣지 않았다.
- 문항 의미 표시, 번호별 사정, 서술의 본문 및 실행과제 반영, 미상 유지, 보호자 연락·신고 이후의 확인과제, 계획 요약표를 검사했다.
- 기본 복사/인쇄/AI 요청문/평가 JSON에서 서술 제외, 선택 ZIP에만 서술 포함, 13개 파일의 CRC·UTF-8·표 행수와 SVG를 확인했다.
- `tests/youth-synthesis71.cjs` 및 기존 youth 회귀검사, 사이트 무결성·보안 검사를 수행했다. 실제 학생의 임상 타당도·개입 효과 검증은 아니다.
- 실제 모바일 기기·OS 프린터 출력은 별도 확인이 필요하다. 다운로드 HTML은 브라우저에서 열어 인쇄/PDF 저장하며 DOCX/HWP 자동 변환을 새로 제공하지 않는다.
