## 1. 모든 후속 버전에 적용할 설계 불변 원칙

1. **CORE 보존과 검증 상태의 정직한 표시.** 25문항·각 0~4점·100점 구조, 별도 안전판정, 미상 처리 및 응답 원본을 유지한다. 이를 ‘신뢰도·타당도 확보’와 동일시하지 않는다. 실제 표본 기반 신뢰도·타당도·준거 적합성은 별도 연구로 검증한다. 문항 또는 계산 변경은 명시적인 버전·근거·회귀검사를 요구한다.
2. **점수만 제공하고 끝내지 않는다.** 평가 완료 이후 결과 해석과 지원연계 맵을 기본 실행 경로로 제공한다. 서술자료·AI·기록 작성은 기본 기능의 이용 조건이 아니다. 긴급한 안전대응은 평가 완료나 페이지 진행을 기다리지 않는다.
3. **지원연계 맵을 핵심 기능으로 둔다.** 결과에서 확인한 욕구와 근거 → 기존 지원 → 기관·사업 후보 → 문의할 내용·이용 조건 → 담당과 다음 확인으로 이어진다. 추천·문의·접수·이용·성과는 서로 다른 상태다. 지도 표시만으로 연계 완료라 하지 않는다.
4. **해석은 두 층으로 구분한다.** 필수 해석은 원점수·영역별 응답·개별 높은 응답·미상·안전확인·동시 출현 패턴이다. 선택 심화 해석은 서술의 출처·시점·부정·가정·기존 서비스·학생 희망·강점·척도와의 불일치다. 서술이 원점수를 자동 변경하지 않는다.
5. **상관·가중치의 범위를 명시한다.** 현재 보조계수는 개발 가정이다. 문항 동시 출현은 상관계수나 원인·위험확률이 아니다. 보조계수는 원점수와 안전판정에 혼합하지 않으며, 이용자에게 설명 가능한 근거와 버전을 제공한다.
6. **총점으로 개별 어려움을 숨기지 않는다.** 3~4점 문항, 안전 신호, 당장 필요한 기본생활 지원을 총점과 별개로 표시한다. 특정 점수만으로 긴급지원 자격이나 임상적 중증도를 확정하지 않는다.
7. **사정→협의→계획의 자료 연결을 유지한다.** 각 과제의 입력 근거·해석·첫 행동·기관 역할·생활 변화 지표를 연결한다. 가족·지지체계는 입력 근거가 있는 범위만 제시한다. 미확인 동거·혼인·이용 상태를 생성하지 않는다.
8. **상담기록·계획조정·점검은 선택 기능이다.** 기본 평가·결과·지원연계와 분리하되 필요하면 같은 평가에서 이어 쓴다. 새 평가와 이전 기록은 혼합하지 않는다.
9. **각 단계에서 개인 AI와 출력 도구를 제공한다.** 현재 단계에 맞는 요청문을 생성하고 외부 전달 내용을 미리 보여준다. AI 열기 버튼은 복사와 공식 서비스 열기를 제공한다. 자동 로그인 연동·대화 읽기·자동 답변 회수라고 표현하지 않는다. 원하는 양식은 실제 서식과 요구사항을 AI에 제공하여 재작성하며 기본 출력은 브라우저 PDF 저장이다.
10. **실무자가 이해하고 통제할 수 있게 한다.** 쉬운 한국어, 모바일 대응, 키보드 접근, 명확한 단계·버튼, 사실/해석/미확인 분리를 유지한다. 외부 전달과 다운로드의 서술·메모 포함은 기본 해제한다. 자동 가림만으로 비식별 완료라 하지 않는다.
11. **실제 실행 결과를 만들어내지 않는다.** 담당·동의·회의 개최·지원 승인·이용·성과는 사람이 확인한 기록만 반영한다. 기존 기관 이용이 언급되면 안전대응을 지연하지 않는 범위에서 역할 조정을 우선한다.
12. **검증 용어를 구분한다.** AI 실증 검증(가상 사례 기반 로직 검수)의 시행 여부·사례 수·검사 범위를 실제 로그로 제시한다. 이번 패치의 자동검사는 결정론적 프로그램 회귀검사이며, 실제 학생 표본의 신뢰도·타당도 검증이나 생성형 AI 성능 실험을 실시한 것으로 표현하지 않는다.

## 4. 구현·개인정보·출력 범위

- `journey-model-v88.js`: 기존 CORE·지도·가중치·서술 모듈을 읽기 전용으로 조합하는 결과·계획 모델.
- `journey-v88.js`, `journey-v88.css`: 메인 흐름의 해석/지도 요약/사정·협의·계획 및 단계별 AI·출력 도구.
- `case-context-core.js`: 일반 교우 갈등 단서를 관계 영역과 대조. 원점수 변경 없음.
- `flow.js`: 등록된 내부 평가 프레임의 검증된 완료 자료를 화면 모듈에 전달. 응답 변경 시 새 완료가 필요함.
- AI 요청문은 직접식별정보 패턴을 가린 뒤 검토하도록 제공한다. 서술·메모는 기본 제외하며 선택 시 포함한다.
- 작성 메모는 현재 탭 메모리에 있으며 새로고침·평가 갱신 전 개별 TXT/PDF로 저장해야 한다. 기존 전체 ZIP은 기존 보고서·기록의 내보내기이며 신규 화면 메모는 개별 다운로드를 이용한다.
- PDF는 브라우저의 인쇄·PDF 저장이다. 임의의 기관 DOCX/HWP 서식을 자동 완성하는 기능으로 표현하지 않는다.
- 생성형 AI의 답변은 자동 회수하지 않으며 외부 AI의 실제 파일 생성 기능·이용 권한에 따라 결과가 달라진다.
