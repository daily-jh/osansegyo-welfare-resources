# 화면·응답 중복 정리 · 2026-10-24

## 점검 범위
저장소의 HTML 22개와 평가·리뷰·보고서·기록·AI 응답 렌더링 경로를 대조했다. 지원연결지도(support.html / support.js / support.css / support-model.js)는 수정하지 않았다. 자원 검색·한눈에보기는 검색과 분류 탐색이라는 다른 용도이므로 유지했다. 연구·준거·개인정보·이용조건 문서는 출처 확인을 위해 유지했다.

## 변경
- 결과 상단은 점수·지원 방향·안전 또는 미확인 상태를 요약한다. 같은 어려움을 반복한 요약 카드와 우선영역 재열거를 제거했다.
- 결과 하단에 중복 삽입하던 한국어 서술을 제거하고 종합의견에서 한 번 표시한다. 점수표·그래프는 원자료 확인용으로 유지한다.
- 안전 우선 카드는 노출을 유지한다. 일반 생활지원·문항 간 추가 근거·역할·점검은 목적별 펼침으로 정리한다.
- 종합의견은 긴 텍스트 입력창 대신 주제별 읽기 카드로 표시한다. 같은 완전한 응답 문장은 첫 위치에 한 번 표시한다. 원문은 복사·출력·AI 요청문용으로 유지한다.
- 3페이지는 핵심 요약과 세부 해석을 분리한다. 두 개의 기록 이동 버튼을 한 개로 통합한다.
- 근거 질문 응답의 기본 설명은 본문, v3 자유서술 맥락 보완은 펼침으로 분리한다. 서로 다른 가설·출처·안전 정보는 의미가 비슷하다는 이유로 삭제하지 않는다.
- 관찰 출처와 근거 성격을 '확인 경로·근거 상태'로 통합한다. 단일 입력값을 시점 잠금과 보고서가 함께 사용한다.
- 기록 보고서의 안전 판단축 중복을 제거한다. 회의결정·서비스 이행·시점 비교는 서로 다른 자료이므로 합치지 않는다.
- 응답 저장·복원은 1·2단계에 표시하고, 3·4단계에서는 해당 작업 도구만 표시한다.
- 인쇄는 핵심 결과·응답표·종합의견을 유지하고 중복 해석 카드는 제외한다.

## 강조 규칙
붉은색은 기존 준거의 안전 우선 판단, 황색은 미상·현재 안전 추가확인, 파란색은 지원 행동에 사용한다. 색만으로 의미를 전달하지 않고 텍스트 제목·굵기도 함께 사용한다. 일반 문장의 굵기는 확인 과제·담당·기한·확정 금지 등의 완전한 문장 단위로 적용한다. 부정문을 잘라 위험 발생처럼 강조하지 않는다. HTML은 이스케이프하며, 입력·링크·줄바꿈·원자료는 보존한다.

## 유지한 경계
25문항 원점수, v2.2 가중치, 안전 게이트, 행정동·복지관 권역 추천, AI 전송 동의·수신 경로는 변경하지 않았다. 실제 전문가 검증·개입효과 검증을 새로 완료한 업데이트가 아니다. 현장 판단을 대체하지 않는다.
