# OY-RALS V1.0 통합지원 우선순위 지표 · 최종 코드 일치 명세
2026-10-26 · 실제 구현 기준: `docs/youth-risk/integrated-index-v1.js`

## 지표 목적 및 불변계약
- 기존 25문항 원점수·미상·공식 안전판정은 오직 `YouthCriteria.evaluate`의 기존 결과로 유지한다.
- OYFiveLevelIndex는 지원업무의 실행 **우선순위 등급**을 분류하는 개발형 모델이다. 타당도가 확보된 진단·위험 확률·서비스 선정결과가 아니다.
- 입력 문항, 서술기록, 관찰된 보호문항을 한쪽으로 숨기지 않고 근거로 보여준다.

## FI 0–100 수식: 구현 그대로
- `R = 25문항 CORE 확인 총점`
- `W = 100 × Σ(응답_i × 문항별가중치_i) / Σ(4 × 문항별가중치_i)`
- `C = 9개 교차영역 쌍 각각의 낮은 쪽 영역강도 × 교차가중치의 정규화된 평균`
- `K = Q1·Q2·Q7·Q25의 0–100 강도 중 상위 2개의 평균`
- `N = NCB가 추출한 현재 학생 관련 긍정 단서 유형 개수 × 17 + 현재 안전 단서 있으면 15 (상한 100)`
- **기본 B=(0.40R+0.25W+0.20C+0.10K) / 0.95**.
- 현재 학생 관련 긍정 서술단서가 **없으면 FI=B**.
- 유효한 서술단서가 **있으면 FI=0.95B+0.05×max(B,N)**. 서술을 추가한 일 때문에 기존의 지원 우선순위가 낮아지는 것을 방지한다.
- 모든 지수는 0–100이며 계산되는 전체 단계는 1~5다. 이 가중치·구간은 **연구 검증을 마치지 않은 설계 상수**다.

## 5개 업무 분류
| 구간 | 시스템 업무 단계 | 실행 |
|---|---|---|
| 0~19.9 | 1 안정관찰 | 보편 예방·강점 확인·경과 관찰 |
| 20~39.9 | 2 초기주의 | 개별지원·2주 내 점검 |
| 40~59.9 | 3 집중지원 | 학맞통 협의 및 복합지원 |
| 60~79.9 | 4 고위기개입 | 학교·복지관·전문기관 집중 공동사정 |
| 80~100 | 5 최우선 안전대응 | 안전확보·보호절차 우선 실행 |

## 안전 우선경로는 계산과 분리
- 명시적 긴급 안전표시, 추후 안전응답 yes, Q1·Q2·Q7·Q25의 고강도(3~4점) 보고: 최소 5단계.
- 그 밖의 CORE 안전문항 양성: 최소 4단계. 단독 1점: 최소 2단계.
- 현재 학생 관련 보호위험 서술단서가 추출되면 최소 4단계의 **실무상 보호 우선경로**.
- **전체 문항 중 미상으로 FI를 계산하지 못하는 경우**에도 이미 보고된 안전 단서가 있으면 **안전 우선 실행등급**은 따로 제시한다. 이때 `composite=null`, `complete=false`로 유지하며 전체 정량 결과가 확정됐다고 표시하지 않는다.
- 서술의 부정·과거·가정·제3자 관련 단서는 현재 학생의 확정 위험 사실로 취급하지 않는다.

## 교차영역 지수
정서×가족돌봄 1.30, 출결×정서 1.15, 기본생활×가족돌봄 1.25, 또래×정서 1.15, 디지털×정서 1.00, 건강행동×출결 1.00, 또래×출결 1.00, 기본생활×출결 1.00, 교육접근×출결 0.90. 교차 쌍은 동시응답으로 표현하며 인과라고 주장하지 않는다.

## 시각화 및 출력
- 정량 결과: 서술을 제외한 CORE·가중·교차·핵심문항 기준의 5단계 등급 게이지, 10영역 레이더·막대, 교차 매트릭스, 25문항 히트맵
- 종합의견: 정량 결과와 서술 맥락을 통합한 별도 5단계 지원우선순위 및 근거표
- 지역자원: 기존 지도에 지원 근거→학교·학맞통→지역자원→점검 연결도 추가
- 사례관리: 사례판정·우선과제·역할·서비스계획·재사정 연결도
- AI 연구: CORE/ICSI/NCB/OY-CIE/K-CARR/ICMS 로드 상태와 분석흐름
- 기록·점검: 계획→실행→점검→재사정·종결 단계와 현재 과제표. 미입력 성과율이나 이용실적을 생성하지 않음.
- PDF는 브라우저 인쇄의 “PDF로 저장”을 사용하며 평가 결과 화면의 SVG 도식도 인쇄 영역에 포함된다.

## 검수 및 사용 한계
- 20,000개 합성 시뮬레이션으로 확장하여 점수·안전판정 불변 검증: `tests/youth-five-level-index.cjs`.
- 실제 Chromium 데스크톱/모바일 UI·PDF 검사: `e2e/youth-ui-browser-regression.cjs`.
- 위 테스트는 **기능·논리 검증**이며 실제 청소년 임상·사회복지학적 개입 정확도, 전문가 간 신뢰도, 민감도·특이도를 입증하지 않는다.

## 최신 통합 패치 · 2026-10-26

- 동일 기능의 중복 모듈을 폐기하고 `integrated-index-v1.js` / `stage-insights-v1.js`를 단일 표시·연구 경로로 채택.
- 5단계 지표를 `OYModelGateway`의 독립 모델 계약(`SUPPORT-5`)에 등록, 다른 모델에서 동일 결과를 참조.
- 정량 탭은 자유서술을 **반영하지 않고** 4개 정량 지수만 재정규화해 분류; 종합의견 탭은 서술형 현재 단서에 의한 비감산 보정을 추가.
- 서술형 현재 보호 단서는 공식 CORE 점수에 덧붙이지 않으면서 지원우선순위 최소 4단계의 보호경로를 제시.
- 미상 문항이 있으면 전체 합성점수 `null` 상태 유지; 관측된 안전 플래그의 실행 단계는 독립적으로 표시.
- 운영 출력은 정량 탭과 종합의견 탭의 지표 구분을 그대로 유지하고 SVG 시각자료를 인쇄 레이아웃에 포함.
- 20,000개 합성표본 기술검수는 계산 일관성과 회귀 오류 검출용이며 실제 학생 대상 실증 정확도를 입증하지 않음.
