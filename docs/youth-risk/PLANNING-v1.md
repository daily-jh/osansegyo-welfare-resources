# 사정·사례판정·서비스계획 연결 (2026-10-22)

사용자 제공 심층 리서치 2차 보완본의 Ⅵ·Ⅶ·Ⅷ·ⅩⅫ·ⅩⅩⅢ·ⅩⅩⅩ을 참고한 규칙 기반 실무 보조 구조다. 기관의 공식 확정 기준·검증된 임상도구·자동 사례선정 모델이 아니다. 원래 25문항 척도와 안전·미상 평가 규칙을 유지한다.

- 안전, 복수 영역의 조정 필요, 당사자 희망·접근 여건, 정보 충분성을 별도로 표시한다.
- 25개 문항별 목표·실행과제·점검 근거를 정의하고, 양수인 숫자 응답만 계획 후보의 근거로 사용한다. 미상·0점인 문항에서 다른 욕구를 추정하지 않는다. 또래 가해/피해, 가족 갈등/학생 돌봄, 디지털 과이용/성착취를 구분한다.
- 지역자원 DB와 기존 연계 적합성 규칙으로 기관 후보를 제시한다. 동일 기관은 묶고, 기관별 요청 역할·첫 문의·실제 이용조건·변화 확인을 연결한다. 기관 선택은 실제 의뢰 확정과 구분한다.
- 미상 및 안전 추가확인마다 이유, 담당 역할, 방법, 확인일을 작성한다. 확인된 어려움 지원은 함께 진행한다.
- 사정·유형 제안·서비스계획을 자유기재와 함께 검토 초안으로 생성한다. 진단·회의 결과·자격·학생 희망·강점·동의를 만들어내지 않는다.
- 목표에 기준선·목표값·담당·기관 역할·기간·자료원·점검일을 기록한다. GAS와 5점 평정은 각 5단계 기준을 기록하도록 하며 달성률로 환산하거나 혼합하지 않는다. 의뢰·접수·서비스 시작·변화를 구분한다.
- 한 화면에서 응답 작성 → 결과·연계 확인 → 사례보고서·계획안 → 선택 기록·점검으로 이동한다. 같은 출처와 등록된 내부 화면만 척도 응답을 주고받으며 이름은 전달하지 않는다.
- 자유기재는 탭 메모리에만 존재하며 새로고침 시 없어진다. 평가 비교 JSON에는 기존 점수·미상·안전 응답만 포함하고 계획·상담기록은 제외한다. 출력·복사는 사용자가 직접 선택한다. 외부 AI 호출·기관 자동 의뢰·데이터 서버 저장은 하지 않는다.

## 순차 화면·문서 개선 (2026-10-23)

- 상단 메뉴와 이전·다음 버튼으로 같은 탭에서 이동한다. 미완료·수정 중에는 이전 결과로 다음 단계를 열지 않는다.
- 결과·연계 단계에서 계획에 포함할 영역을 선택한다. 안전 우선 영역은 유지하고 전체 사정 근거는 숨기지 않는다.
- 세 번째 화면은 사례검토 보고서와 서비스계획서로 나눈다. 사례요약, 욕구·사정 근거, 판정 검토, 연계 역할과 계획, 회의 확인 사항을 표로 정리한다.
- 학생 희망·강점·회의 결정·서비스 합의는 척도에서 만들어내지 않는다. 직접 기록은 마지막 선택 단계에서 진행한다.
- 재평가 또는 계획 영역 변경 시 별도의 기록안을 만들고 이전 기록안은 같은 탭 메모리에 보존한다. 새로고침·탭 종료 시 사라진다.
