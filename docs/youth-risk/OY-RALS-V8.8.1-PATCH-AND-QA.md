# OY-RALS V8.8.1 절대명제 반영 후속 패치 및 기술검수

- 적용일: 2026-10-25
- 기준: 25문항 100점 CORE·미상·안전판정 불변
- 범위: 현재 홈페이지 경로 `docs/youth-risk/`. 공개 사이트에 실제 학생 개인 사례정보를 업로드하지 않음.
- 검증 표현: **가상 사례 기반 프로그램 로직 검수**. 실제 학생 표본 신뢰도·타당도나 AI 실증 검증을 실시한 것이 아님.

## 순차 수정 및 사유

1. **서술·가족관계**: 친부·생부·친모·생모·모와 등의 표기 및 쉼표로 구분된 현재 거주 사실 언급 인식. 비동거와 동거 언급을 분리. 사실 확인 전 동거 자동 체크는 금지.
2. **미상·0점**: 19·20·21번 기본생활 문항에서 고득점과 미상이 동시에 나타나도 각 과제를 삭제하지 않음. 미상은 필요 확정이 아닌 확인 과제. 연결지도 기본값은 점수가 보고된 영역 또는 미상 영역만 표시하며 전체 10영역은 선택하여 확인 가능.
3. **결과→연계→사정의 절차**: 종합사정·협의·계획 전 지원연계 후보·접수사항 검토를 명시적으로 선택하게 함. 긴급 보호상황을 방해하지 않도록 '연계 보류 후 계속'을 별도로 제공. **버튼 클릭은 연락·신청·이용 완료가 아니라 후보 검토 상태**.
4. **연계 실행과 목표**: 주요 과제별 기관·사업 후보, 이용 조건, 담당, 진행 상태, 다음 확인일, 부적합 시 대체자원 메모. 서비스계획에 단기·중장기 목표와 활동·생활 변화 지표를 구분. 모든 자동 계획은 확정 전 초안.
5. **전체 자료 ZIP 정합성**: V8.8.1 동일 근거 모델로 `01-summary.html`, `02-review.txt`, `03-service-plan.html`, `04-case-conference.html` 생성. 이전 V8.7 통합사정을 기본 출력으로 혼용하지 않음. 브라우저에서 HTML을 인쇄하여 PDF로 저장하며 ZIP 내부에 PDF 원본 파일을 자동 생성하지 않음.
6. **실무자 작성 정보**: 명시적으로 '서술·작성 메모 포함'에 동의했을 때만 `11-v88-authored-fields.json`과 `12-v88-family-support-diagram.html`을 추가. 기본 ZIP은 비식별 척도 중심으로 유지하며 현재 단계의 서술·작성메모·가족관계 자동 포함 금지.
7. **스크롤 오류와 접근성**: 이전 패치의 입력 중 자동 상단 이동 억제 유지. 단계 이동 시만 상단 이동. 추가 입력란과 진행 상태 선택을 같은 저장·출력 메커니즘으로 처리.

## 합성 기술검수 범위

- 공개 저장소의 `tests/v88-absolute-principles-regression.cjs`에 재현 가능 검증 스크립트 추가.
- 운영 JS를 가져와 별도 V8 실행 환경에서 750건의 가상 응답을 평가했으며 CORE 원점수·안전판정 객체가 공식 함수와 일치함. 가상 가족·비동거·미상 기본생활 과제·가계도 자동 동거 금지 검사.
- V8.8.1 전체 자료 생성기 스모크 검사: 기본 출력의 선택 서술 제외, 선택 포함 시 메모·관계도 추가, 보고서 4종에서 과거 모델 내용 혼용 없음.
- 저장소 CJS 스크립트는 1,200건 반복 CORE 불변검사와 파일 출력·안내 구조를 검증하도록 설계했음. 별도의 실제 Node CLI 실행·종단간 브라우저 수행 여부는 결과를 확인한 후 기록해야 함.
- GitHub Pages 배포 성공 여부는 작업 완료 후 별도로 확인.

## 남은 주요 검증과 배포 후 과제

- 현장 교사·교육복지사·사회복지사가 평가·연계·PDF 및 ZIP을 함께 사용하는 실제 사용자 수용성 시험.
- 모바일 Safari/Android 기종별 입력·스크롤·브라우저 PDF·한글 폰트 검증.
- 공개기관의 사업별 실제 모집·접수 가능·운영시간·접수 담당 창구 전수 검증, 부적합 대체서비스 우선순위 자동화.
- 실제 학생 비식별 표본과 전문가 독립 골드셋을 이용한 신뢰도·타당도·판정 일치율·개입 효과의 별도 연구.
- 전문 가계도(친생·입양·혼인·이혼·재혼)·생태도 편집 및 출력 기능 확대.
- 기관의 DOCX/HWPX 원본 양식 자동 채우기, 서버 없이 브라우저에서 직접 생성되는 PDF의 환경별 품질 검증.

**중요**: 본 패치는 실제 접수 가능성, 상담·의뢰 수행, 신고의무 이행, 실증 정확도 확보를 주장하지 않습니다.
