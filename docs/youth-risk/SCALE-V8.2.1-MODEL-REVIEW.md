# OY-RALS 25문항 척도 해석 모델 V8.2.1

## 이번에 변경하는 것
- `scale-interpretation-v821.js`: 기존 25개 문항을 각기 다른 구성개념과 확인 질문·혼동 주의사항으로 규정
- `app.js`: 25문항 도움말에 평가 초점·혼동 주의·확인 질문 노출. 0점/미상 및 점수 간격에 대한 안내
- `case-formulation-v72.js`/ `case-documents.js`: 척도 하위 개념 비교, 서술·응답 차이와 문항별 우선 확인 내용을 종합사정·계획문서에 연동
- `case-evidence-v82.js`: 주거·경제·돌봄·정서·접근성·디지털 영역에서 첫 행동에 원문을 통째로 반복하던 방식 교체
- 20번 주거 3~4점은 같은 영역의 16번 돌봄 과제에 가려지지 않도록 독립 **근거 확인 과제** 보존. 체납·퇴거 사실 자동 생성 금지
- 9번 고점과 실제 출결 기록의 차이, 학습 서술과 10번 0점의 차이, 식사 공백과 16/19번 개념 차이를 확인 질문으로 도출

## 공식 점수와 안전판정은 변경하지 않음
- `YouthCriteria.evaluate`의 25×0~4점, 10개 영역, 100점 총점, 미상 처리, 긴급 판단은 불변
- 분류·추가 질문·주거 확인 과제는 **점수 외 설명 계층**임. 기존 응답을 자동 수정·가중하지 않음
- 0점은 **이번 응답에서 해당 어려움 보고가 없음**을 뜻하며 실제 위험의 부재를 입증하지 않음
- 1~4점이 임상 등간 척도나 위험확률로 검증됐다고 해석하지 않음
- 자해·학대·온라인 성착취 관련 신호는 총점 순위와 분리해 현재 안전·보호 절차를 직접 확인해야 함

| 9·10·11·14 | 출결 기록, 교과 이해·과제, 학교 소속감, 제공되지 않은 교육환경 조정 |

| 19·20·21 | 필수 물품 부족, 주거 불안정·안전, 비용으로 인한 서비스 접근 제한 |

## V8.2.1 기술 검수
- 기존 홈페이지 모듈을 연결해 합성 회귀검사 5,000건 실행
- 실제 CORE 점수 변경 0건, 안전 게이트 변경 0건, 고점 주거 확인과제 누락 0건, 신규 주거 과제의 부당 추가 0건, 중복 과제 ID 0건, 실행 예외 0건
- **이 검사 자료는 실제 학생 5,000명의 자료가 아니며**, 위험 예측 정확도·판정 타당도·중재 효과의 증거가 아님

## 실증 연구 과제
문항 분할/가중치 변경은 실무자·학생 측면의 **내용타당도**, 평가자 간 일치도, 측정오차·신뢰도, 요인구조, 시점별 반응성, 결측 응답 및 편향, 준거관계, 실제 서비스 결과의 외적 타당도 검토 후 진행한다. 변경하는 경우 버전 분기 및 이전 문항과의 연결표 필요.

## 출처 및 안전상 한계
- NICE NG225 제1.6절: 자해·자살의 미래 위험을 예측하거나 치료 대상을 선정하는 수단으로 위험척도를 이용하지 말고 개별 심리사회적 사정을 수행할 것
- COSMIN Manual V2: 내용타당도·신뢰도·구조타당도·반응성은 별개의 측정 속성이며 각기 검증 필요
