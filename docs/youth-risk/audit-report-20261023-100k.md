# OY-RALS 2026-10-23 — 연구근거 보강 및 합성 사례 100,000건 기술 종합검수

## 문서 성격
- **대상:** 25문항×각 0~4점(최대 100점), 10개 영역, 기존 미상·안전게이트·권역별 자원연계 유지
- **기초자료:** 사용자가 별도 제공한 「2026 종합사회복지관 통합사례관리 최종 심층 리서치(2차본)」을 내부에서 검토. 해당 원문·민감사례 자료를 저장소에 복사·게시하지 않음
- **증거구분:** 2025~2026 국내 사례관리 연구의 공개 서지·초록 및 공식 학맞통 지침과, 개발자가 **새로 설계한 24개 교차사정 규칙**은 다르다
- **검수유형:** 합성 입력에 대한 기술적 불변조건 검사 및 일부 문서 렌더링. 심리측정학적 타당화, 위험 예측력·민감도·특이도 검증 **아님**
- **프로젝트 인용:** [S01] 2025 사례관리 표준실천지침 개정 연구, [S19] 2026 고난도 사례관리, [S20] 2026 재진입, [S21] 이용자중심 실천, [S22] 아동보호의 아동 관점, [S23] 생태체계·강점 모형, [V03] 학생맞춤통합지원 가이드북, [V11] 학생지원 교육복지사 실천 연구, [V19] 공유의사결정, [V20] 트라우마인지 원칙

## 적용된 비AI 해석·문장 엔진
- `docs/youth-risk/evidence-matrix.js`: **24개 문항·영역 교차 확인 가설**. 서로 다른 각 문항집합에서 2점 이상이 보고되어야 활성화
- 출력: 실제 문항 번호·점수 → 함께 보고된 어려움 → **확인할 가설** → 학생 면담 질문 → 교사/사회복지사 역할 → 자원 **기관군 후보** → 합의할 목표 → 이행·생활성과 분리 점검
- 공개 결과에는 최대 5개 중요 교차항목 표시, 사례검토 보고서/서비스계획서에도 최대 5개 가설 표시
- `planning-model.js`: 종전 4개 사정 축에 지속성·복합성, 적법한 정보제공, 접근성, 강점/선호를 **비점수형** 판단축으로 추가
- `referral-guidance.js`: 기존 25문항별 구체적인 학생 질문 및 기관 문의 목적 유지
- **일절 변경하지 않음:** 기존 25문항 원문, 0~4점 점수, 100점 최대, 안전·미상 판정 함수, 자동 사례선정 권한, 법적 행정결정

## 검수 수치
실행: 시드 `20261023`, 10개 의도적 분포 × 10,000건 = **100,000건**.
기준 함수: `YouthCriteria.evaluate`, `YouthPlanning.analyze`, `YouthEvidenceMatrix.evaluate`, `YouthReferralGuide.firstQuestions`. 유효성·안전·점수와 교차가설 추적 및 100번째마다 3종 문서 렌더링 검사.

| 기술검사 항목 | 결과 |
|---|---:|
| 합성 사례 입력 | **100,000** |
| 기술 불변조건 위반·예외 | **0** |
| 문서 렌더: 표본 1,000사례 × (교사 보고서·사회복지사 보고서·사회복지사 계획서) | **3,000** |
| 교차해석 규칙 활성화 | **24/24** |
| 교차해석이 발생한 사례 | **27,854** |
| 총 교차규칙 일치 (사례당 복수 허용) | **158,131** |
| 미상 포함 | **29,557** |
| 핵심 안전 미상 포함 | **18,892** |
| 현재 안전신호 있음 | **56,176** |

| 잘못된 입력 검증케이스 | **4종 통과** |

**오해 방지:** 표본은 25문항 0점만, 0점+긴급신호만, 미상 다수, 안전문항 양성, 복합 고득점, 고른 무작위 점수 등을 각 10,000개씩 인위적으로 설계했다. **긴급 56.176%는 실제 오산시 위기청소년 비율이 아니다.** 점수/모델의 예측력 검증 또는 실제 청소년의 판정 정확도 근거로 사용 금지.

## 통과한 기술 불변조건
1. 미상은 0점 취급 및 점수 비례환산 금지. `knownTotal`은 실제 유효응답의 합계.
2. 미상 시 `incomplete=true`, `level=null`; 0점/미상 구분.
3. 25문항 0점 + 독립 긴급신호 또는 양성 안전문항·현재위험='yes' 시 `urgent=true` 및 안전계획 생성.
4. 일반 서비스계획 후보가 없는 0점·0점+긴급신호 사례에 불필요한 일반 계획 없음.
5. 기본 자동선택 일반 영역 최대 3개 + 안전예외 유지. 복합사례에서 `a.plans`의 전체 후보가 최대 10개인 것은 UI가 자동으로 10개 계획서를 확정한다는 뜻은 아님.
6. 교차 규칙의 인용 문항은 각 2점 이상 응답을 실제 포함해야 함. 출력 상위 5개 제한.
7. 문항별 학생 확인 질문은 실제 양성 응답만 선택.
8. 교사·사회복지사 보고서와 계획서 렌더, 잠정보고서, 안전계획, 교차해석 누락 없음(1,000개 표본).
9. 문항 개수 오류·점수 범위 오류·미상 단독입력 처리 검증.

## 24개 교차 확인 가설
| 묶음 | 개발용 주제 |
|---|---|
| 학교·교우 | 또래 피해×학교참여, 정서×학교참여, 학습×기본생활 |
| 가족·경제 | 가족·돌봄×출결, 가족돌봄×학습, 가구생활×돌봄, 주거×학교 |
| 보호·안전 | 학대/방임×기본생활, 온라인 착취×또래 피해, 온라인 착취×정서·지지, 자해×정서·지지 |
| 정서·관계 | 정서×고립, 가족관계×정서, 학교 소속감×관계 |
| 접근성 | 장애·발달지원 미충족×학습, 비용×교육·발달지원 |
| 건강·행동 | 디지털×일상, 위험행동×정서/건강, 행동×또래 안전, 건강행동×교육 |
| 고차 교차 | 주거×정서, 보호위험×생계×지지, 학교×주거×돌봄, 빈곤×주거×돌봄 |

각 규칙의 **정확한 조건·출력 표현·근거상황**은 `evidence-matrix.js`의 `RULES`를 확인한다. 위 가설은 경험적 논문에서 그대로 검증된 조합이나 임상 척도 요소가 아니다.

## 관점별 출력 원칙
- **교사:** 학생·보호자에게 안전한 면담 질문, 학내 조정·학맞통 협의. 보호자에게 먼저 연락하면 위험해질 수 있는 사례는 신고·보호 절차가 우선.
- **사회복지사:** 판정 전후의 경계 명시, 사정→우선개입→서비스 목표→기관별 의뢰·접수·회신→실제 이용→재사정의 순환.
- **모두:** “관찰됨·보고됨·미확인·검토 필요·합의 전”을 분리하고, 강점·소득·진단·가족구성·보호자 협력을 추정하지 않음.

## 남은 검증·도입 전 조건
- 연구전문 및 기관 내부 규정을 확보한 뒤 **내용적 타당성 전문가 심의**가 필요. 논문 공개초록만으로 가중치를 정하지 않음.
- 실제 비식별·동의가 적절한 사례에 대한 독립 전문가 판정 비교, 실무자 간 일치도 및 위해 예방/과잉개입 균형을 검증해야 함.
- 84개 기관·183개 서비스 원자료의 **실제 접수 가능/관할/연계 수락**은 별도 대조. 본 100,000건에서 사용한 기관 후보는 테스트용 모의 입력임.
- 공개 GitHub Pages에 실명·건강·학대·상담서술을 업로드하지 않으며, 외부 AI로 보내기 전 비식별과 법적 정보제공 근거를 확인.
- 안전 1점이 현재 위해를 뜻하는지 구분하기 위한 면담·전문가 검토가 필요하나, **검증 없이 새로운 절단점으로 낮추지는 않음**.
- 학교·복지관의 법적 권한, 학맞통 선정/서비스 승인, 긴급 보호·신고의무는 시스템 자동 제안과 별개의 인간 의사결정.

## 재현 안내
저장소에서 다음을 실행:
```bash
node scripts/run_youth_risk_100k_audit.cjs 100000 audit-results.json
```
설치 패키지 없이 Node.js로 실행하며 현재 소스 기준 JSON 지표를 작성. 프로그램에서 `process.exitCode=1`이면 불변조건 위반. 공개 데이터만 쓰며 실제 학생정보를 넣지 말 것.
