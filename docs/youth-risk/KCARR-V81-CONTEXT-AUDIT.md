# K-CARR V8.1 연결·가족 맥락·척도 위치 (2026-10-25)

V8.1 기존 병합 코드를 확인하여 평가·실행계획·질문·ZIP 지연 로더에서 동일 모듈을 불러오도록 정리했습니다. 원 합성자료는 사이트에 게시하지 않습니다.

## 변경

- 기존 안전 검토 플래그(urgent), 원점수, 미상 및 보호절차는 유지합니다. 별도 위험표시·현재 위험 추가확인이 없고 안전문항이 모두 1점인 경우에는 생활지원 수준을 먼저 제목에 표시하고 안전 확인을 병기합니다. 점수만으로 실제 학대·현재 긴급도를 확정하지 않습니다. 명시적 위험과 서술의 위해는 여전히 보호 우선입니다.
- 가구 형태·보장구분은 척도 가산점이 아닙니다. 자격·신청·지급을 구분하고 서비스 공백·돌봄·언어 접근·학생 역할의 맥락으로 제공합니다. 자격 자동 판정과 최신 급여 선정기준 계산은 하지 않습니다.
- 가계도는 서술에 언급된 가족관계의 연결 초안입니다. 혼인·친생·성별·전체 가족 수·동거를 추정하지 않습니다. 생태도는 언급된 기관의 이용·의뢰·종료 상태를 구분합니다. 모든 점선은 언급된 관계이며 관계 강도를 뜻하지 않습니다. 출처를 펼쳐 확인할 수 있습니다. 임상 가계도 전체를 자동 완성하는 기능은 아닙니다.
- 총점 0~24 / 25~49 / 50~74 / 75~100의 동일 폭 4구간을 시각화합니다. 통계적 사분위·위험등급·지원 선정기준이 아닙니다. 미상이 있으면 합계 가능한 범위만 제시합니다. 안전 판단은 총점과 독립입니다.
- 개인정보 포함 서술의 도식은 입력을 반영하는 화면에만 구성하고 기본 서술 제외 복사·ZIP의 계약을 유지합니다. 외부 분석 API를 추가하지 않습니다.

## 검수와 한계

`tests/youth-context81.cjs`는 낮은 안전 신호의 생활지원 순서, 안전 플래그 보존, 101개 점수 경계, 미상 범위, 자격·가구 분리, 도식 근거 제한, HTML 이스케이프 및 기본 내보내기를 검사합니다. V8.1 회귀검사와 기존 youth·사이트 무결성 검사도 수행합니다. 실행 결과는 릴리스 시 확인합니다.

첨부 5,000건은 25개 합성 원형의 변형이며 실제 독립 학생 5,000명이나 임상 성능 근거가 아닙니다. 가족·기관 추출은 로컬 패턴 방식으로 누락·부정 범위 오류가 생길 수 있으므로 담당자가 입력 근거와 대조해야 합니다. 소득·가구 형태를 근거로 위험을 추정하지 않습니다.
