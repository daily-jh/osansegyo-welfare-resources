# OY-RALS V8.6 · 웹사이트 통합 및 안내 페이지 개편 (2026-10-25)

## 적용 범위
- 기존 CORE `criteria.js`(25문항, 100점, 미상, 안전판정)를 변경하지 않음
- 오프라인 V8.6 검수 패키지의 **원본 모듈 6개**를 `docs/youth-risk/`에 직접 배치
  - `case-evidence-base-v86.js`, `evidence-v86.js` — 한국어 사건 근거, 강점, 가족, 기존 서비스, 부정·가정·미확인
  - `item-action-router-v86.js` — 25문항의 별개 행동·교사 및 사회복지사 역할·검증 지표
  - `reconciliation-v86.js` — 척도와 서술 간 충돌 확인 및 중복 개념 분리
  - `unified-v86.js` — 단일 CaseState 및 다섯 문서 공통 목표
  - `site-bridge-v86.js` — 기존 `YouthFormulation`에서 V8.6을 우선 사용
- `oy-rals-v86-site.js`는 **화면 표출만** 담당하고 별도 위험 판정이나 케이스 추론을 수행하지 않음
- `case-formulation-v72.js`, `case-documents.js`, `case-form-model.js`를 기존 점수·초안서식과 연결
- `assessment.html`, `case-examples.html`, `workbench.html`, `flow.js`, `index.html`에 V8.6 로딩 및 캐시 경로 반영
- `system-method.html`은 변경 이력 나열 중심에서 4단계 이용 절차·결과해석·역할별 활용·안전/개인정보 중심으로 전면 개편

## 검증
- 독립 V8.6 패키지: 기존 15,000건 합성 검수 및 독립 역검사(실제 학생 아님)
- 새 웹 연동 상태: **5,000건 합성 회귀검사**에서 공식 CORE 점수·안전판정 변경 0, 문서 목표 불일치 0, 3~4점 문항별 과제 누락 0, 중복 목표 ID 0, 실행 예외 0
- 확인 사례: 보호자 폭력 직접 진술 / 자해 진술+현 상태 미확인 / 가족갈등+학대 명시 부정 / 학교폭력 피해 여부 미확인 / 주거 고점+돌봄 / 미술 강점+기존 프로그램 / 서술 없음 및 미상
- 저장소 검수 스크립트: `tests/v86-site-integration.cjs`
- 브라우저 기종별 렌더링, DOCX/PDF/ZIP 실제 다운로드 및 운영 배포 상태는 웹 연동검사와 별도로 확인해야 함

## 안전과 유효성
- 보고된 위험 진술은 공식 척도에 임의 가점하지 않지만 별도 안전확인 과제를 생성함
- 원문에 없는 학대·자해·퇴거·신고·서비스 제공을 자동으로 확정하지 않음
- 미상은 0점이 아니며 전문가의 사정·신고의무 판단·학생 의견 및 동의가 우선함
- 규칙 기반 설명·초안 작성이지 임상 타당도나 실제 학생 지원의 효과성이 입증된 AI가 아님

## 복구 및 개인정보

- 개인정보가 포함된 사례 자료는 공개 GitHub 저장소로 전송하지 않음; 합성 검수자료만 사용
