# 사례 사정·질문·실행계획 통합층 7.2

2026-10-24. 대상: 평가결과·종합 사정·사례협의·질문 화면. 지원 연결지도·지역자원 원본·공식 점수 준거는 변경하지 않음.

## 발견한 실패

- 교육복지사는 선택 가능했으나 V7 응답 뒤 구형 2역할 복사 엔진을 호출해 오류 발생.
- ‘부모의 개입거부’의 ‘개입’을 일반 계획으로 분류하여 질문에 답하지 못함.
- 화면 답변과 기본 복사문이 서로 다른 질문·모델에서 만들어짐.
- 사실별 확인 문구를 많이 보여주었지만 상황·문제 관계·잠정 판단·실행의 연결이 드러나지 않음.
- 전체 응답에서는 그래프가 닫힌 표 내부에 삽입될 수 있었고, 미상 포함 응답에서는 표가 펼쳐짐.
- 서비스계획의 목표·단기·장기·첫 행동·근거가 중복됨.

## 변경한 구조

1. 기존 CORE의 25문항·미상·별도 안전정보를 그대로 읽음.
2. ICSI/K-CARR/ICMS V7.0 통합 기반의 문항 의미와 서술 단서를 사례이해 통합층에서 대조함.
3. 보호, 정서·현재 안전, 또래, 교육환경·학습, 행동·건강, 돌봄·생활, 관계, 온라인 지원을 묶어 관련 과제 구성. 보호자 연락에 따른 위해 우려, 보호와 학습의 동시 어려움, 돌봄과 학교참여, 교육접근과 수행, 정서와 지지관계 등 검토할 관계를 명시함.
4. 상황 문단 → 핵심 상호작용 → 잠정적 사정 → 우선 개입과 점검으로 표현. 원인·진단·사건 사실을 확정하지 않음.
5. 결과와 계획·복사·ZIP이 같은 사례이해 모델 사용. 계획은 선택한 지원 영역을 반영하며 안전 과제는 유지. 화면 기본 우선 과제는 3개이며 기타 과제는 접어서 보존함.
6. 계획의 전체 요약표를 먼저 보여주고 상세에는 사정 이유·직무별 행동·시점만 배치. 실제 담당자·기한·동의·서비스 개시는 자동 창작하지 않음.
7. 질문은 질문 유형을 먼저 분류. 보호자 협력 거부는 일반 계획과 분리. 교사·교육복지사·사회복지사 모두 동일한 응답 경로 사용. 지원 범위 밖의 질문은 답변 범위를 좁혀 달라고 안내.
8. 질문은 사례 사실로 추가하지 않음. 질문 기능은 외부 AI·원격 모델 자료 호출 없이 이 화면의 평가 정보를 읽음.
9. 기본 복사는 같은 질문 유형의 척도 근거 답변으로 명시. 선택 시 서술 반영을 포함한 화면 답변을 복사. 외부 생성형 AI 기능은 별도 접힌 영역에 유지하며 자동 실행하지 않음.
10. 그래프는 표의 상위 접기와 분리하여 항상 표시. 문항별 응답표는 닫힌 상세로 이동.

## 개인정보·검증

- 사용자가 제공한 실제 서술·응답·첨부 화면의 사적 내용은 코드·시험 예제·공개 저장소에 포함하지 않음. 실제 사례 재현은 로컬에서만 수행.
- 재사용 시험은 별도의 합성·단위 예제 사용. 기본 복사·출력·AI 요청문은 사례 서술을 제외하는 기존 원칙 유지.
- 새로운 위험 확률·사분면 가중치·학대 확정·약물 효과 판정은 추가하지 않음.
- 순수 모델 회귀: 질문 분류·3역할·연락 위해 우선·질문/사실 분리·선택 계획·미상·HTML escaping·기본 복사 제외. 200개 합성 응답 × 3역할 × 4유형에서 입력 불변·기존 CORE 일치.
- 기존 전체 youth 회귀검사, 보안·사이트 구조 검사와 DOM 기반 연결·복사·재생성 검사를 별도로 실행.

## 한계

7.2는 사례이해·화면 통합 버전이며 기초 모델 V7.0을 새로 학습한 버전이 아님. 정규식·규칙·관계 조합에 따른 제한된 한국어 문장 구성이며, 생성형 AI나 임상적 타당도가 입증된 전문 사정 엔진으로 주장하지 않음. 새로운 표현·복잡한 주체·시간 관계는 누락되거나 잘못 연결될 수 있으므로 원문·근거를 검토해야 함. 미처리 서술은 자동 이해했다고 주장하지 않음. 화면의 잠정 사정을 실제 사례회의 판정이나 서비스 제공 결정으로 사용하지 않음.
