## 목적과 출력 순서

동일한 응답 범주는 동일한 공통 해석을 제공하고, 실제 문항과 영역·동시응답에 따라 설명을 추가합니다. CORE 25문항의 원점수·안전판정·미상 처리는 변경하지 않습니다. 결과 화면, 현재 결과 PDF, 통합보고서 PDF, 결과 TXT에 같은 보고서 모듈을 사용합니다.

보고서 순서: 결과 요약과 현재 안전 → 유형별 공통 해석 → 먼저 살펴볼 영역 → 동시응답 해석 → 지원·점검 제안 → 근거와 한계.

## 분류 규칙

총점의 새 절단점을 임의로 만들지 않습니다. 같은 총점이라도 안전문항·개별 고점·영역 분포에 따라 유형이 달라집니다. 기존 CORE의 중요영역은 영역 안에 3~4점이 하나 이상이거나 2점 이상 문항이 두 개 이상인 경우입니다. CORE observedLevel은 미상 포함 시 확인된 응답만의 잠정 지원 방향이며 전체 판정으로 표시하지 않습니다.

안전 양성·명시적 현재 위해 → 안전확인 우선. 안전 미상·추가확인 미완료 → 안전확인 미완료. 일반 미상 → 전체 유형 확정 보류. 모두 미상 → 정보확인형. 일반 생활지원 해석이 안전판정을 낮추지 않습니다.

### 관찰·예방형

- 출력 규칙: CORE observedLevel=0: 2점 이상 문항 없음
- 공통 해석: 이번 응답에서는 어려움이 없거나 가볍게 보고된 항목이 중심입니다. 현재 도움이 되는 관계와 활동을 유지하면서 학생이 느끼는 불편과 변화 희망을 확인하는 접근이 적절합니다. 낮은 합계가 안전이나 지원 불필요를 증명하지는 않습니다.
- 지원 제안: 학생이 편하게 도움을 요청할 사람과 방법을 확인하고, 학생과 다음 확인 시점을 정합니다.
- 점검: 학생이 말한 불편의 변화, 도움 요청 경로의 실제 이용 가능성

### 개별영역 지원형

- 출력 규칙: CORE observedLevel=1: 2점 이상 응답이 있고 중요영역 2개 미만
- 공통 해석: 일부 문항에서 반복되는 어려움이나 도움이 필요한 수준으로 응답했습니다. 전체 합계보다 해당 문항의 상황·기간·생활 영향을 구체적으로 확인하는 것이 중요합니다. 한 영역 안에서도 서로 다른 어려움이 있을 수 있으므로 학생이 먼저 바꾸고 싶은 일을 중심으로 지원을 조정합니다.
- 지원 제안: 해당 문항의 구체적 장면과 기존 도움의 효과를 확인하고, 우선과제 1~2개를 학생과 협의합니다.
- 점검: 해당 생활 장면의 어려움, 지원 전후 참여·휴식·생활 유지 변화

### 복합욕구 조정형

- 출력 규칙: CORE observedLevel=2: 중요영역 2개 이상이며 집중검토형 조건 미충족
- 공통 해석: 두 개 이상의 생활영역에서 함께 살펴볼 어려움이 확인된 응답입니다. 영역마다 별도 서비스를 늘리기 전에 무엇이 먼저 해결되어야 다른 지원을 이용할 수 있는지 확인해야 합니다. 함께 나타난 점수만으로 한 어려움이 다른 어려움의 원인이라고 결론 내리지는 않습니다.
- 지원 제안: 학교·복지 담당자가 기존 지원과 미충족 필요를 함께 정리하고, 학생의 우선순위에 맞춰 담당과 순서를 협의합니다.
- 점검: 우선과제 간 연결, 중복·누락 지원, 의뢰 후 실제 이용 여부와 학생의 부담

### 다기관 집중검토형

- 출력 규칙: CORE observedLevel=3: 중요영역 3개 이상 및 3~4점 문항 3개 이상
- 공통 해석: 여러 영역의 어려움과 높은 개별 응답이 동시에 나타났습니다. 한 담당자의 개별 지원만으로 충분한지 공동으로 살펴볼 필요가 있습니다. 학생의 부담을 줄이도록 연락 창구를 정리하고, 안전·기본생활·학교 참여 중 현재 가장 시급한 과제를 우선 협의합니다. 이 유형은 진단이나 서비스 선정 결과가 아닙니다.
- 지원 제안: 관련 담당자가 공동사정을 검토하고, 즉시 확인할 과제와 지속 지원할 과제를 구분해 주관·협력 담당을 정합니다.
- 점검: 현재 안전, 기본생활 유지, 지원 공백, 담당 간 조정과 학생이 경험한 변화

## 10개 영역 공통 해석

### 아동학대·보호

보호자의 위해 가능성과 필요한 보호의 제공 여부를 구분해 살펴봅니다. 가족 형편이나 갈등만으로 학대·방임을 확정하지 않습니다.

추가 사정: 안전한 접촉·보호 환경과 사실 확인 경로

### 학교폭력·또래 안전

또래 피해, 강요·협박, 타인에게 피해를 준 행동을 각각 구분합니다. 같은 사건이라도 학생별 보호 필요와 행동 지원은 다를 수 있습니다.

추가 사정: 현재 접촉 위험, 안전한 학교 참여와 도움 요청 경로

### 자해·정서·정신건강

마음의 고통, 자해 관련 안전신호, 평소와 달라진 수면·활동을 구분합니다. 정서 점수만으로 진단을 추정하지 않습니다.

추가 사정: 현재 안전과 일상 유지, 편하게 도움을 구할 사람

### 학습·출결

출결·수업 참여, 학습 이해, 학교 소속감은 서로 다른 지원과제입니다. 결석만으로 학습능력이나 의지를 판단하지 않습니다.

추가 사정: 참여가 어려운 시간·과목·상황과 가능한 수업 조정

### 행동·건강 안전

위험행동의 전후 상황과 실제 다칠 위험, 물질 사용에 따른 건강 영향을 확인합니다. 행동의 이름만으로 긴급도를 정하지 않습니다.

추가 사정: 현재 위해 여부와 행동이 발생한 맥락

### 장애·발달 및 접근성

학생의 특성보다 필요한 설명 방식·환경 조정·서비스가 제공되는지 살펴봅니다. 응답으로 장애나 발달 진단을 만들지 않습니다.

추가 사정: 제공된 편의의 적합성과 서비스를 막는 장벽

### 가족·돌봄

돌봄을 받지 못하는 상황, 가족관계의 영향, 학생이 가족을 돌보는 부담을 구분합니다. 학생에게 성인의 역할을 일괄 맡기지 않도록 대체 도움을 살펴봅니다.

추가 사정: 실제 돌봄 시간표, 공백과 학생의 휴식·학습 시간

### 경제·주거

필수 물품·식량 부족, 주거환경, 지원 이용 비용을 따로 확인합니다. 주거 점수만으로 체납이나 퇴거를 사실로 쓰지 않습니다.

추가 사정: 현재 부족한 자원과 이용을 막는 비용·환경

### 관계·지지체계

원하는 활동에 참여하기 어려운지, 믿고 도움을 청할 사람이 실제로 있는지 확인합니다. 혼자 있기를 선호하는 성향과 고립을 구분합니다.

추가 사정: 학생이 원하는 참여 방식과 실제 연결 가능한 지지자

### 디지털·온라인 안전

디지털 이용에 따른 일상 영향과 온라인 성적 요구·유포 위협을 구분합니다. 이용 시간만으로 문제를 확정하거나 피해 책임을 학생에게 돌리지 않습니다.

추가 사정: 수면·수업 영향 및 현재 접촉·피해 보호 필요
