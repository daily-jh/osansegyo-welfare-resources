## 적용

1. 결과·종합의견·잠정 결과·보고서/계획·AI 요청문에 공통 v2 문항쌍 해석을 연결한다. 두 문항이 실제 양성일 때만 가설을 제시하고 미상·0점을 양성으로 채우지 않는다. 여러 조합의 동일 템플릿은 한 번만 보여 준다.
2. 문항별 104개 보완 카드에서 관련 문항 카드와 10대 욕구영역 매핑을 검색한다. 24개 기본 교차규칙을 새 원고의 가설만으로 덮어쓰지 않는다. 직접 확인한 응답, 해석 가설, 미확인 내용, 첫 행동, 담당, 계획, 점검을 구분한다.
3. 3페이지는 사례 이해·지원계획·근거 질문·AI 보완의 작업 선택을 제공한다. 핵심 요약을 먼저 제시하고 전체 보고서는 펼쳐 본다. 복사·인쇄에는 전체 참고 문서를 사용한다.
4. 4페이지는 지원계획·실행/회의·관찰기록·변화점검·도움말로 구분한다. 최초 과제는 선택된 영역과 안전 영역을 반영한다. 실제 제공 내용·확인일, 학생의 말·생활변화, 다음 행동·담당·확인일을 추가하고 출력에도 반영한다. 문의 상태를 자동으로 접수나 성과로 승격하지 않는다.
5. 상단 오른쪽 ‘시스템 작동방법’에서 버전·자료 단위·수량·역할과 한계를 확인할 수 있다. 700쪽은 개발 편람 분량이며 논문·실사례 수가 아니다.

## 검증 범위

문항쌍 300개의 완전성, 104개 카드 참조, 미상·안전 우선, 점수·권역 불변, 결과–보고서–요청문의 공통 해석, 화면 전환 시 작성내용 유지, 실제 제공과 생활변화 기록·인쇄, 비동기 응답의 오래된 결과 차단을 회귀검사한다. 프로그램 동작 검사와 임상적 타당도·현장 효과 검증은 구분한다.

원고 자체의 ‘원본 재배포 금지·개인기록 제외’ 원칙을 따라 연구원고 전체·기관 원본·실사례 기록을 사이트에 올리지 않고 일반화한 규칙만 적용했다. 실제 기관 운영 기준과 서비스 제공 여부는 담당자가 확인한다.
