# OY-CIE V3.2 홈페이지 통합 검수 — 2026-10-25

## 적용 범위
사용자가 제공한 V3.2 개발·검수 패키지를 별도 연구 작업실 경로에 반영했습니다. 기존 25문항 CORE, 점수, 안전판정, 운영 평가 흐름과 600건 DB 원본은 변경하지 않았습니다. 홈페이지 상단에 작업실 링크만 추가했습니다.

공개 상태는 **합성사례 시연·개발 검수용 / 실무 적용 보류**입니다. 실제 학생정보 입력, 실제 사례의 자동 판정이나 서비스 확정 용도로 승인된 제품이 아닙니다. 기존 보고서의 ‘미배포’는 첨부 당시 상태이며, 이번 반영 이후에는 별도 시연 페이지가 공개됩니다.

## 통합 보완
- 분석 실패 시 이전 결과·내보내기 버튼을 무효화합니다.
- JSON 다운로드 파일명을 V3.2로 맞췄습니다.
- 기존 사이트 한국어 SUIT 글꼴로 화면·PDF를 표시합니다.
- 실제 입력 원문을 자동으로 홈페이지 평가 화면에 전달하거나 서버에 저장하지 않습니다.

## 재실행한 검사
- 첨부 원본 스냅샷 기준 50,000 합성 입력 및 102개 지정 검사 통과.
- 현재 저장소 CORE를 직접 사용한 50,000 합성 입력 및 102개 지정 검사 통과: 점수·안전·미상 불일치, 안전 게이트 누락, 실행 오류, 근거 ID 형식 오류 0건.
- 첨부 설치·철회 검사 7건 통과(모의 저장소).
- 실제 저장소 파일을 HTTP로 제공한 Chromium: 600건 DB 로딩, 기본 분석, 후속 질의, 0점+결식 서술 확인과제, JSON 다운로드, 입력 변경 무효화, 식별정보 형식 차단, PDF, 390px·1280px 화면 검사 통과. 스크립트 오류 0건.
- PDF 한국어 텍스트 추출 확인. iPhone Safari와 전문가 실무 평정은 미실시.

검사량은 실제 학생 수가 아닙니다. 통계적 신뢰도·타당도나 의미 해석 정확도, 600개 답변의 전문적 정답성을 입증하지 않습니다. 80개 플레이북과 300개 문항쌍은 미검증 개발 초안이며 5,550개 라우팅 키는 독립 연구근거가 아닙니다. 자체 학습 LLM이나 외부 AI API를 실행하지 않습니다.
