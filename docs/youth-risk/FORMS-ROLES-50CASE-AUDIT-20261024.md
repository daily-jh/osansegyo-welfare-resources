## 변경사항
- 상단 네 도구 버튼: 동일한 선 아이콘, 옅은 청색 배경, 테두리·높이·글자 톤. 좁은 화면은 2열 배치.
- 문항 여백·행간 소폭 축소. 0~4·미상 6개 선택지와 최소 44px 터치 영역 유지.
- 평가 iframe은 실제 콘텐츠 높이를 계산한다. 내부 이중 세로 스크롤을 제거하고 바깥 페이지 스크롤을 사용한다. 문항 전체를 한 화면에 억지로 넣거나 페이지 스크롤을 없애지 않는다.
- 3페이지의 '근거 질문'과 'AI로 보완'을 '질문·AI 보완' 한 단계로 통합했다. 로컬 규칙 응답과 선택형 AI의 전송·동의는 별도 유지한다.
- 공통 해석 아래 영역별 교사·사회복지사 역할을 병렬로 제시한다. 교사는 교육 참여·학교 조정·안전한 소통, 사회복지사는 생활 여건·가구 욕구·접근 장벽·기관 접수와 회신을 맡는다. 진단·안전 판정은 역할에 따라 바뀌지 않는다.
- 전체 보고서의 직무 관점 선택은 전체 문서 펼침 안으로 이동했다. 기본 화면에서 같은 점수·사정 내용을 관점별로 다시 탐색할 필요를 줄였다.
- 4페이지 '초기상담·욕구사정'에서 초기상담지와 10대 욕구사정표를 작성·복사·인쇄한다. 학생의 바람·강점·안전조치·기존 지원·접근 여건·실무자 사정·첫 행동은 지원계획의 입력을 함께 사용한다.
- 경제 항목은 수입→지출→부채→재산→기타 순서. 10대 욕구는 안전/건강/일상생활 유지/가족관계/사회적 관계/경제/교육/고용/생활환경/법률 및 권익보장 순서. 확인되지 않은 사실·금액·자격·가족관계·합의를 만들지 않는다.
- 청소년 점수에서 기관 16문항 점수로의 환산은 하지 않는다. 25문항은 추가 면담 단서이며 확정 욕구나 진단이 아니다.

## 가상 50사례 구성과 결과
10개 청소년 영역 각각 5가지 조건(가벼운 어려움/생활 영향 큰 어려움/일부 미확인/다른 영역과 복합/별도 안전신호 동반)으로 총 50건이다. 25개 개별 문항 모두에 양성 점수가 들어가는 사례가 포함된다. 각 사례에서 10개 영역 결과, 교사·사회복지사 사정, 종합의견, 서비스계획, 두 관점의 사례보고서·계획서, 초기상담·욕구사정 연결을 검사했다.

- 50/50: 교사·사회복지사 점수·안전 판정 동일
- 50/50: 원자료 불변, 10대 욕구영역 유지, 양성 근거에 한해 직무별 역할 제시
- 미상 포함 10/10: 전체 판단 보류 유지
- 별도 안전신호 10/10: 안전 우선 유지
- 반복되는 완전 문장은 화면 카드에서 1회 표시; 서로 다른 근거·안전 조치는 의미가 비슷하다는 이유로 삭제하지 않음
- 사례보고서/계획서 2종 × 2관점 × 50건 생성 경로 확인

재현: `node tests/youth-scenarios-50.cjs`. 입력·전체 영역 결과·역할·리뷰·계획 영역은 [가상 50사례 결과 JSON](scenario-audit-50-20261024.json)에 공개했다. 예시는 실제 학생이 없는 합성 자료이다.
