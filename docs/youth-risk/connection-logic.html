기관·사업은 어떤 근거로 연결하나요?

연결지도는 1차 응답을 다시 진단하거나 새 위기점수를 만들지 않습니다. 1차와 동일한 criteria.js의 안전·기능·복합지원 판정을 불러오고, 해당 문항과 등록 사업의 역할이 맞는 문의 후보를 표시합니다.

1. 영역을 먼저 확인하는 순서

  1. 1·2·7·25번 중 양성인 문항이 있는 안전우선 영역을 먼저 표시합니다. 별도 긴급 체크도 지도 상단과 인쇄 그림에 알립니다.
  2. 1차의 보호·건강·필수생활 우선확인 문항(4·5·8·12·13·16·19·20번)이 3~4점인 영역, 그 외 개별 높은 점수, 지원집중 영역 여부, 평균 순으로 확인합니다.
  3. 평균이 낮아도 최고점과 개별 문항을 표시합니다. 총점 100점은 유지하고, 영역·사업 정렬을 위해 원점수에 가산하지 않습니다.

2. 서비스 후보를 고르는 순서

기관명만 일치하는 것으로 끝내지 않고, 해당 영역에서 실제 양성인 문항과 서비스의 명시된 역할을 연결합니다. 아래 순서는 운영 규칙이며 검증된 위험확률·임상 절단점이 아닙니다.

응답·1차 판정우선 확인할 서비스 역할분리하는 사항
1·2번 보호 신호피해아동·가족 보호 사례관리 문의일반 예방교육을 실제 피해 대응의 첫 후보로 제시하지 않음. 신고·보호 절차는 서비스 예약과 별도
6·8번 정서·일상 기능 신호안전신호 없이 1~2점이면 학교·청소년 상담을 먼저 문의하고, 3~4점의 기능 제한이면 해당 전문평가 역할을 먼저 확인경미한 정서 신호만으로 전문기관 의뢰가 필수라고 표현하지 않음
7번 자해·죽음 관련 신호아동청소년 정신건강·해당 전문상담낮은 총점이나 일반상담으로 안전확인을 대체하지 않음. 자살 의도를 점수로 확정하지 않음
25번 온라인 피해 신호청소년안전망·피해 보호 협력예방교육을 피해 보호 대체 서비스로 표시하지 않음
19~21번 생활·주거·의료 접근의 심한 제한실제 위기사유 확인을 포함한 생활지원 상담점수로 긴급복지 자격을 확정하지 않음. 경미한 신호에서는 긴급복지 상담을 선두에 올리지 않음
17번 가족갈등 영향가족상담·관계 지원돌봄 부담이나 가족 형태를 자동 추정하지 않음
16·18번 돌봄 공백·학생 돌봄 부담지역 돌봄·생활·가족지원 가능 범위 문의일반 가사 분담만으로 특정 신분·자격을 확정하지 않음
학습·출결 어려움학교 상담·학습 참여 지원 문의경제 신호가 없으면 장학사업을 자동 추천하지 않음
14·15번 접근성 제한필요 편의·아동청소년 지원 가능 범위 확인진단·장애등록을 추정하지 않음. 성인 평생교육·직업지원 등은 자동 후보에서 제외
1차 복합지원 협의 검토해당 문항과 연결되는 청소년안전망·학교 지역전문기관 협력 후보를 앞쪽에서 검토안전확인과 시급한 기본생활·건강 지원을 뒤로 미루지 않음

같은 역할 안에서는 관련 문항의 강도·일치한 문항·서비스 키워드를 순서대로 비교합니다. 서비스별 역할 우선순위를 먼저 계산한 뒤 같은 기관을 하나로 묶습니다. 동일 영역에서 기관 카드는 한 번만 표시하며, 가장 우선하는 사업을 대표로 보여주고 나머지 적합한 사업은 같은 카드의 ‘관련 사업 더 보기’에 보존합니다. 기관별 묶음은 표시 개수 제한보다 먼저 적용합니다. 안전·직접 지원 사업의 우선순위는 유지하며, 완전히 같은 기관·사업 행은 중복 제거합니다. 후보 수를 채우기 위해 역할이 맞지 않는 서비스를 임의로 만들지 않습니다. 학교 밖 여부·가족구성·진단·연령·지원자격은 응답만으로 추정하지 않습니다.

3. 기관 링크의 확인 범위

기존 공용 CSV는 그대로 유지하고 이 평가 시스템 안에서만 보완 주소를 사용합니다. 기관·사업 안내 페이지로 이동하며 신청이 완료되거나 평가 응답이 자동 전달되는 기능은 없습니다. 주소·연락처 대조일: 2026-10-22.

  • 오산시가족센터 · 지역 센터 홈페이지와 프로그램 목록 확인
  • 오산시아동보호전문기관 사업 안내 · 기관 사이트와 사업 안내 경로 확인
  • 오산장애인종합복지관 아동청소년 사업 · 공식 페이지에서 대상·접수 안내 확인. 개별 신청 자격은 별도 확인
  • 화성오산 Wee센터 이용 안내 · 교육지원청 공식 이용 안내 확인
  • 오산시정신건강복지센터 · 경기도 공식 기관목록의 주소·전화 대조. 기관 사이트 자동 열람 제한으로 세부 접수 페이지는 확인하지 못함
  • 오산시청소년상담복지센터 안내 · 해당 안내에서 홈페이지·상담신청 주소·전화 확인. 직접 상담신청 페이지는 자동 열람 제한이 있어 대체 안내 경로를 함께 제공

나머지 기관은 기존 DB 등록 안내 주소를 제공하며 카드의 ‘링크·정보 확인 범위’에서 확인 수준을 구분합니다. 링크가 확인됐다는 사실은 현재 사업 모집·대상 적합성 확인과 다릅니다.

4. 검사 범위

실제 공개 자원 DB 111개 행을 대상으로 안전·생활·가족갈등·돌봄·학습·접근성·복합 지원의 경계사례, 역할이 맞지 않는 후보 제외, 1차 판정과의 일치, 응답 불변성, 링크 허용 프로토콜을 검사합니다. 화면에서는 기관·사업 링크, 관련 문항, 모바일·그림 생성·인쇄를 확인합니다. 이는 소프트웨어 운영 규칙 검사이며 실제 의뢰 성공률·학생의 위험 예측 정확도를 측정한 것이 아닙니다. 기존 104,902건 시뮬레이션은 1차 점수·판정 검수이며 새 기관 추천 로직의 임상 성능 수치로 사용하지 않습니다.
