사정에서 서비스계획까지 이어지는 근거

안전·보호, 여러 영역의 조정 필요, 학생의 희망·실행 여건, 정보의 충분성을 따로 살펴봅니다. 응답 점수만으로 사례관리 유형이나 기관 선정을 확정하지 않습니다.

결과·연계 화면의 기관 후보에는 응답 근거, 요청할 역할, 첫 연락에서 확인할 일, 연계 후 살펴볼 변화를 표시합니다. 사례보고서·계획안 화면은 척도 응답만으로 교사·사회복지사가 참고할 사정·사례판정·서비스계획 예시를 바로 보여줍니다. 실제 상담 기록·목표 조정·변화 점검은 마지막 선택형 선택형 기록·점검 화면에서 합니다.

계획은 필요·근거 → 변화목표 → 실행과제·담당 → 기관 역할 → 기준선·목표값·확인자료 → 점검일로 연결합니다. 문의·의뢰·접수·시작은 별도 단계이며, 이용량을 생활 변화나 종결과 동일하게 보지 않습니다.

미상 문항과 현재 안전 추가확인에는 확인 담당·방법·기한을 기록합니다. 전체 판단은 보류하면서 확인된 어려움의 지원은 병행합니다. 학생의 말, 강점, 기관 동의·회의 결정은 시스템이 만들어내지 않습니다.

기관·사업은 어떤 근거로 연결하나요?

연결지도는 1차 응답을 다시 진단하거나 새 위기점수를 만들지 않습니다. 평가 결과에서 먼저 살필 안전과 생활의 어려움을 그대로 이어받아, 필요한 도움을 의논할 기관과 사업을 안내합니다.

미상이 있을 때

미상 문항은 0점으로 바꾸지 않으며 해당 영역의 전체 평균을 보류합니다. 미상은 별도 색·점선과 문구로 표시합니다. 확인된 안전신호를 먼저, 안전 관련 미확인 사항을 다음으로 살피며, 기관·사업은 확인된 응답과 맞는 역할만 연결합니다. 미상만 있는 영역에 근거 없이 기관을 추천하지 않습니다.

1. 영역을 먼저 확인하는 순서

  1. 1·2·7·25번 중 1점 이상으로 응답한 문항이 있는 안전우선 영역을 먼저 표시합니다. 별도 긴급 체크도 지도 상단과 인쇄 그림에 알립니다.
  2. 1차의 보호·건강·필수생활 우선확인 문항(4·5·8·12·13·16·19·20번)이 3~4점인 영역, 그 외 개별 높은 점수, 지원집중 영역 여부, 평균 순으로 확인합니다.
  3. 평균이 낮아도 최고점과 개별 문항을 표시합니다. 총점 100점은 유지하고, 영역·사업 정렬을 위해 원점수에 가산하지 않습니다.

2. 서비스 후보를 고르는 순서

기관명만 일치하는 것으로 끝내지 않고, 해당 영역에서 1점 이상으로 응답한 문항과 서비스의 명시된 역할을 연결합니다. 아래 순서는 운영 규칙이며 검증된 위험확률·임상 절단점이 아닙니다.

응답·1차 판정우선 확인할 서비스 역할분리하는 사항
1·2번 보호 신호피해아동·가족 보호 사례관리 문의일반 예방교육을 실제 피해 대응의 첫 후보로 제시하지 않음. 신고·보호 절차는 서비스 예약과 별도
6·8번 정서·일상 기능 신호안전신호 없이 1~2점이면 학교·청소년 상담을 먼저 문의하고, 3~4점의 기능 제한이면 해당 전문평가 역할을 먼저 확인경미한 정서 신호만으로 전문기관 의뢰가 필수라고 표현하지 않음

같은 역할 안에서는 관련 문항의 강도·일치한 문항·서비스 키워드를 순서대로 비교합니다. 학생에게 필요한 도움과 사업의 역할을 살펴본 뒤 같은 기관을 하나로 묶습니다. 동일 영역에서 기관 카드는 한 번만 표시하며, 가장 우선하는 사업을 대표로 보여주고 나머지 적합한 사업은 같은 카드의 ‘관련 사업 더 보기’에 보존합니다. 먼저 같은 기관의 사업을 모은 뒤, 화면에 보여줄 기관 수를 정합니다. 안전·직접 지원 사업의 우선순위는 유지하며, 완전히 같은 기관·사업 행은 중복 제거합니다. 후보 수를 채우기 위해 역할이 맞지 않는 서비스를 임의로 만들지 않습니다. 학교 밖 여부·가족구성·진단·연령·지원자격은 응답만으로 추정하지 않습니다.
