# 사례검토 서술모델 v2.1 적용

적용일: 2026-10-24. 통합사례관리 지원모델 v2.0과 기존 25문항·안전 규칙은 유지합니다.

## 공통 출력 계약

결과·지원연계, 종합의견(리뷰), 사례 이해·지원계획, 근거 질문, 연결지도의 설명은 `professional-response.js`의 같은 응답 자료를 사용합니다. 25문항별 보고 내용·생활 영향·확인 질문·실행 제안·변화 지표와 기존 교차규칙을 연결합니다.

1. 보고된 어려움과 생활상의 의미를 문장으로 정리합니다.
2. 현재 안전과 첫 대응을 별도로 설명합니다.
3. 영역별 생활 영향과 학생에게 확인할 질문을 제시합니다.
4. 동시 응답은 연결 가능성으로만 설명하고 원인·진단을 확정하지 않습니다.
5. 학교와 사례관리자의 역할, 실제 접수·제공, 학생의 생활변화를 구분합니다.

1점 응답은 일시적 불편·반복 여부를 먼저 확인하며 일반 서비스계획으로 확대하지 않습니다. 미상은 0점으로 변환하지 않습니다. 다른 문항의 어려움을 임의로 만들어 넣지 않습니다. 학생의 강점·희망·보호요인·실제 이용 결과를 자동으로 기재하지 않습니다.

계산식·문항쌍·104개 카드·600개 연구형 근거 자료는 삭제하지 않습니다. `technicalText`, `knowledgeEvidence` 및 화면의 상세 근거 펼쳐보기로 분리합니다. 주요 서술은 근거 코드를 반복 나열하지 않습니다.

## 시스템 구조도

`system-method.html`에 `system-architecture.svg`를 연결했습니다. 공통 응답에서 사례관리·언어 해석이 병렬 처리되고, 결과·리뷰·계획에 반영된 뒤 실무자와 학생의 확인·합의 및 실행 점검으로 이어지는 구조입니다. 언어 해석이 점수·안전 판정을 변경하는 경로는 없습니다. 외부 AI는 별도 선택 기능입니다.

## 검수

25문항 × 4점수 개별 검사, 미상·0점·안전 신호, 미보고 욕구의 혼입 방지, 입력 불변성, 역할 차이, 리뷰·보고서 설명 일치, HTML 이스케이프를 검사합니다. 기존 문항쌍·연계·보고서·무작위 응답 검사와 실제 화면 전환도 함께 확인합니다. 이 검사는 임상적·통계적 타당도 검증이 아닙니다.
