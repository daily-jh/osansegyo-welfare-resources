# OY-RALS V8.7 — 안전판정 및 통합사정 개발 명세 (초안)

작성: 2026-10-25. 상태: 개발 브랜치, 운영 미배포.

## 변경 불변조건
1. 기존 25문항 0~100 원점수는 변경하지 않는다.
2. '미상'은 0점 또는 안전함으로 간주하지 않는다. 확인 필요와 확인된 위험을 분리한다.
3. 학대·자해·착취 등 현재 위험의 명시적 신호는 총점보다 우선하며, 신고·보호 절차는 해당 법령과 기관 지침에 따른다.
4. 서술형 입력에서 확인된 사실, 당사자 진술, 실무자 추정, 미확인 정보를 구분한다.
5. 정량·서술 충돌은 점수 임의 변경 대신 재확인 과제를 생성한다.
6. 위험·욕구·강점·자원·목표·담당·기한·완료기준의 추적 가능한 근거를 보존한다.
7. 개인정보 포함 입력을 외부 AI로 자동 전송하지 않는다.

## 판정 우선순위
- P0: 현재 위험을 뒷받침하는 명시적 정보 → 즉시 안전확인 및 보호절차 검토.
- P1: 안전 핵심정보 미상·상충 → 안전확인 필요, 안전하다는 결론 금지.
- P2: 긴급 생활위기 → 기초생활·돌봄·주거 등 병행 지원 검토.
- P3: 그 밖의 욕구 → 학생 참여 기반 계획 수립.

P1만으로 P0 위험이 확인되었다고 단정하지 않는다. 위험 여부와 정보확인 상태를 별도 필드로 출력한다.

## 회귀검사 최소 시나리오
- 전 문항 0점 / 안전 관련 서술 미상: 안전 확인 필요와 무위험 확정 금지.
- 낮은 총점 + 현재 자해 위험 진술: P0 우선.
- 높은 총점 + 안전문항 미상: P1 유지, 일반 지원 병행.
- 척도 0점 + 서술형 학대 의심: 충돌 표시, 안전확인 및 신고의무 검토.
- 척도 위험 + 서술형 부인: 위험 신호 삭제 금지, 근거·시점 확인.
- 주거·돌봄·출결 동시 위기: 중복 서비스가 아닌 통합 목표로 묶기.
- 동일 입력 반복: 동일 판정과 동일 우선순위.
- 개인정보 포함 서술: 출력 비식별 및 외부 전송 없음.

## 배포 게이트
기존 기준 로직 파일과 연결 구조를 파악한 뒤 구현한다. 단위·통합·브라우저·모바일·출력 테스트를 수행하고, 기존 판정과 차이가 나는 사례를 전수 검토한다. 실제 학생 자료로 검증하기 전까지 민감도·특이도 또는 실증 타당도를 주장하지 않는다.
