# K-CARR V8.2 · 근거 공유와 사례 사정 재구성

2026-10-25. 이 공개 기록에는 실제 사례의 원문·점수 조합·프로그램명·가족 구성을 넣지 않습니다.

## 발견한 구조적 문제

V8.1은 척도와 키워드를 서로 다른 문장·계획기로 처리해 입력 정보가 사라지거나 출력별 우선과제가 달라질 수 있었습니다. 가족 호칭·관심·프로그램 참여의 누락과, 서술에 없는 사건을 점수에서 확대하는 문제를 수정합니다.

## 공통 처리

1. 원문을 출처·시점·보고/미확인/가정 상태가 있는 단서로 유지합니다. 가족 호칭, 관심, 실제 참여·의뢰·중단 상태를 구분합니다. 파싱하지 못한 원문도 접힌 근거에 보존합니다.
2. 출결 고점의 실제 근거 미제시, 학습 어려움 서술과 학습 0점의 차이 등을 확인 과제로 만듭니다. 점수는 자동으로 바꾸지 않습니다.
3. 현재 위해는 보호 우선, 직접 보고된 일상 공백은 구체적 생활지원, 학교 관련 차이는 근거 대조, 관심·기존 자원은 참여·역할 조정으로 연결합니다. 낮은 주거점수만으로 체납·퇴거를 만들어내지 않습니다.
4. 같은 사정 객체가 질문·종합 사정·계획·사례회의·초기상담·욕구사정·ZIP으로 연결됩니다. 선택 영역은 계획 범위를 바꾸지만 같은 입력의 기본 우선순위를 역할별로 다시 계산하지 않습니다. 교사와 사회복지사의 수행 내용은 다릅니다.
5. 자동 서식 초안은 실제 작성·동의·합의 완료로 집계하지 않습니다. 직접 작성한 값이 우선하고 자동 목표를 학생이 제시한 욕구로 변환하지 않습니다.

## 합성자료의 실제 연결과 한계

첨부 V8.0의 gzip JSONL 6개, 54,000레코드를 읽었습니다. 평가 plan의 `(task, done)`을 중복 제거한 고유 행동·점검 조합은 **37종**입니다. 입력 54,000명의 독립 실제 사례, 54,000개의 독립 개입방법, 신경망 학습량 또는 임상 성능을 뜻하지 않습니다.

`case-patterns-v82.js`는 이 37종의 문구·출처 레코드 ID·사용 빈도·원 파일 해시를 포함한 실제 런타임 인덱스입니다. 조건 일치와 필수 맥락을 확인해 참고 계획 패턴을 표시합니다. 매칭 개수·빈도는 위험확률이나 정확도 점수가 아닙니다. 서술과 척도에서 구성한 현재 사례의 근거를 대체하지 않습니다. 대형 SQLite를 웹에 복제하거나 실제 사례를 공개 검색 색인에 넣지 않습니다.

## 검증

- 새 `tests/youth-evidence82.cjs`: 문장·가족·관심·서비스 보존, 서술-척도 차이, 동일 입력의 역할·문서 우선순위, 보고되지 않은 주거·전학·통역 제외, 원점수·미상 불변성, 37패턴 실제 조회, 직접 기록 우선, 기본 내보내기 서술 제외, XSS, 72개 영역·역할·미상 조합.
- 기존 youth 회귀·사이트 보안·로컬 연결·브라우저 DOM과 ZIP을 함께 검증합니다.
- 실제 첨부 출력의 재현 검수는 로컬에서만 실행합니다. 원문과 재현용 원자료는 이 저장소에 게시하지 않습니다.

## 남은 한계

한국어 모든 표현을 이해하는 생성형 모델이 아닙니다. 부정 범위·인물·시점·주체 분리는 오인식할 수 있으며 원문 대조가 필요합니다. 실제 진단·학대·자격·인과·서비스 수락은 자동 확정하지 않습니다. 비교집단·독립 전문가 평정·추적 효과를 검증한 임상도구가 아닙니다. 맥락이 부족하면 실행의 수치·일정을 창작하지 않고 첫 면담의 기준선 확인으로 남깁니다.
