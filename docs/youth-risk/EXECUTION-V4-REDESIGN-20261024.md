# 반복 서술 제거와 사례협의·실행계획 v4.0

## 확인한 원인
사용자 제공 IMG_9606~9609 화면의 반복을 렌더러와 모델에 대조했다. 전문 서술 모델은 각 영역에 같은 3~4점 설명과 '학생의 말과 관찰 자료' 문구를 붙였고, 연결가설마다 동일한 인과확정 금지 문장을 덧붙였다. 3페이지는 요약·전문 서술·문항쌍 해석·기존 보고서를 다시 출력했다. 교사/사회복지사 문서는 공통 목표·서비스를 재사용하면서 일반적인 관점 설명만 바꾸는 부분이 많았다. 단순히 접는 방식으로는 생성 원인의 반복을 해결하지 못했다.

## 생성 계층의 역할

| case-documents | 실행계획서 또는 회의 전 사례협의안 | 긴 분석 보고서 중첩 제거, 하단 근거 1곳 |
| 질문응답 / 맥락 v3 / 사례계획 v3 | 사용자가 선택한 질문·자유서술 보완 | 주 실행계획 문서에 자동 중첩하지 않음 |
| 4페이지 기록 도구 | 실제 학생 의견·합의·수행·변화 | 자동 제안과 실제 기록을 구분해 유지 |

## 화면과 문서
3페이지를 '사례협의·실행계획'으로 바꾸고 '실행계획서 / 사례협의안 / 질문·AI 보완'으로 구성했다. 교사/사회복지사 관점 전환을 없앴다. 동일 목표 아래 교사는 학교 내 안전·면담·수업·출결 조정을, 사회복지사는 생활욕구·접근장벽·지역기관 접수·회신 조정을 별도 칸에 표시한다. 행별 첫 행동은 원래 양성 문항에 연결된 구체적 과제를 사용하고, 목표·시점·확인할 변화·문의 후보와 대표 연락처를 함께 제시한다.

사례협의안은 회의 안건·선택할 실행과제·직무별 담당 제안·아직 미확정인 회의결과를 구분한다. 실제 참석자·승인·서명·확정일은 만들지 않는다. 25문항 원자료, 교차해석, 판단 한계는 하단 근거 묶음에 한 번 표시한다. 모바일에서는 역할별 칸을 세로로 배치하며, 넓은 표로 인한 가로 넘침을 줄인다. 복사·인쇄는 선택한 문서와 근거를 함께 유지한다.

## 결과·리뷰
같은 경고문을 문장마다 붙이는 생성 규칙을 제거했다. 가벼움/3~4점 해석은 문서 공통 안내로 한 번, 인과확정 금지 설명은 연결가설 전체에 한 번 제공한다. 결과 화면의 일반적인 개입 경로 설명과 중복 가설 카드를 제거하고 그래프는 필요할 때 확인하도록 했다. 리뷰의 구체적 영역 해석·질문은 하단 근거로 모았다. 안전 및 현재 첫 대응은 앞에 유지한다.

## 검증과 경계
`tests/youth-execution-v4.cjs`에서 기존 가상 50사례를 다시 적용했다. 두 직무의 계획서는 하나의 동일한 문서 안에 서로 다른 역할을 표시한다. 문서당 하단 근거 1곳·25응답 유지·공통 주의문 1회·미상 및 안전 우선·선택하지 않은 일반 목표 제외·원자료 불변을 검사한다. 기존 점수·직무·영역·연계·문서·폼 회귀검사를 함께 수행한다. 첨부 화면과 유사한 복합·미상 가상사례로 DOM 단계 전환과 새 문서 생성도 점검한다. 실제 학생 임상정확도·개입효과 검증을 새로 완료한 것은 아니다.
