# K-CARR V8.1 릴리스 및 적용 검수

- 대상: 오산 청소년 위기징후 평가연계 시스템 사례사정 / 사례협의 / 보고서
- 버전: K-CARR 8.1.0 / 기존 CORE 25문항 100점, ICSI·ICMS와 복지자원 DB 불변
- 전환 전: V8.0 관련 스크립트 `k-carr-narrative-v8.js`
- 적용 후: `k-carr-narrative-v81.js`, `oy-rals-v8-integration.js`, `kcarr-site-v8.js`

## 수정된 기능
1. 부정 사실(폭력·방임 없음, 진단·약물 복용 없음)을 긍정 위험으로 판단하지 않도록 절 단위 판별
2. 예방교육·가상 예시는 실제 피해 신호로 처리하지 않음
3. '단톡방 조롱 / 복도에서 밀침' 등의 또래피해 표현을 식별하고 결석과의 시간적 연관을 검토
4. 보호자 연락과 가정폭력의 관계는 단정하지 않고 안전한 연락의 확인 과제로 남김
5. 기본생활·주거 지원과 가족돌봄 지원을 구분
6. 사례협의 계획과 보고서의 교사·사회복지사 주 담당 실행 내용을 역할에 맞춰 표시
7. 문항 점수, 신고 여부, 접수·승인·실제 지원을 임의로 확정하지 않음

## 검사와 제한
- 고정 원형 25종 × 서술 변형 200개 = 5,000개 합성 회귀사례를 적용. 동일 원형의 반복변형은 독립 현장사례가 아님.
- 안전 오인식, 확인된 안전 신호 누락, 명시적으로 부정된 의료정보의 양성 판정, 또래피해 문맥 누락을 검사
- 임상 정확도, 실제 학생 지원 효과, 전문가 평정 일치도는 아직 검증되지 않음
- 공식 점수·위기 단계와 서술형 추론은 분리하고, 사람의 실무 판단·안전조치를 우선함

## 차기 개정
- 1·3·4·7·13·20·21·25번은 100점 점수 변경 대신 비채점 후속 확인 질문으로 세분화하는 방향을 우선 검토
- 척도 문항 변경 및 가중치 재보정은 실무자 내용타당도·평가자 간 일치도 검증 이후 실시
- 5,000건 이외의 독립된 새 서술형 사례와 전문가 판정으로 오류 재검토 필요
