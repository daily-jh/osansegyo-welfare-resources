# OY-RALS 통합지원 5단계 지표 V1 · 공식 CORE와 분리된 개발형 지원우선순위

작성일: 2026-10-26 · 기획·개발: 김지훈(오산세교종합사회복지관)

## 기본 계약

- **원형 보호:** CORE 25문항 × 0~4점 = 100점. 원점수·미상·안전 추가확인·신고 판단 안내는 `YouthCriteria.evaluate`만 결정하며 다른 모듈이 변경하지 않는다.
- **개발 보조지표:** `integrated-index-v1.js`의 `OYFiveLevelIndex.analyze(payload)`가 5단계 *지원우선순위 분류*를 생성한다. 이 지표는 실제 청소년 자료로 절단점·예측타당도·관찰자 일치도를 검증하지 않았다.
- **언어 규칙:** 화면에는 “시스템 분류: 제N단계 / 주요 결정요인 / 권장 개입”을 분명하게 표기한다. 확인하지 않은 사건·진단·실제 서비스 이용·신고 완료를 단정하지 않는다.
- **미상 응답:** 전체 25문항 중 미상이 있으면 통합지표 단계를 계산하지 않는다. 확인된 문항 점수, 안전 대응, 미상 개수는 별도 표시한다.

## 0–100 지표 계산

| 지수 | 산식·데이터 | 기본 비중 |
|---|---|---:|
| R · CORE 원점수 | 25문항의 기존 합계. 수정하지 않음 | 40% |
| W · 문항 가중위험 | `YouthWeightModel.audit`의 문항별 개발 가중치 `w_i`; `100 × Σ(응답_i × w_i)/Σ(4 × w_i)` | 25% |
| C · 영역 교차 | 9개 교차영역 쌍. 각 쌍은 두 영역의 정규화된 응답 강도 중 작은 값에 설정된 교차 가중치를 적용, 전체 가중평균으로 0–100 재정규화 | 20% |
| K · 핵심문항 | Q1·Q2·Q7·Q25 응답의 0–100 환산치 중 가장 높은 2개의 평균 | 10% |
| N · 서술 맥락 | NCB가 분석한 현재 학생 관련 긍정 단서 종류 × 17, 현재 안전단서 시 +15, 최대 100 (단순 개발 계수) | 5% |

**FI = (0.40R + 0.25W + 0.20C + 0.10K + 0.05N)**. 서술이 없는 경우 N=0을 대입하지 않고 **실제 포함 비중 0.95로 나누어 재정규화**한다. 모든 값은 0–100 구간으로 제한한다.

서술이 *미입력*인 경우와 서술을 *입력했으나 위험 단서가 추출되지 않은 경우*는 서로 다른 데이터 상태다.

### 운영상 분류 구간

| 지표 점수 | 단계 | 의미·첫 개입 |
|---:|---|---|
| 0–19.9 | 1 · 안정관찰 | 보편 예방, 강점 및 변화 관찰 |
| 20–39.9 | 2 · 초기주의 | 개별지원 및 2주 내 경과 점검 |
| 40–59.9 | 3 · 집중지원 | 학교 내 학맞통 협의와 복합욕구별 집중지원 |
| 60–79.9 | 4 · 고위기개입 | 학교·복지관·전문기관 공동사정 및 집중 사례개입 |
| 80–100 | 5 · 최우선 안전대응 | 현재 안전·보호 절차를 우선하고 관계기관 협의 병행 |

**안전 우선 상향 규칙:** CORE의 명시적 긴급 신호, 추가 안전문항의 `yes`, 또는 Q1·Q2·Q7·Q25 중 3~4점이 있다면 분류 최소 5단계. 안전문항이 2점 이상이면 최소 4단계. 단독 1점 안전문항은 최소 2단계. **모든 경우 CORE 공식 안전판정을 별도로 유지**한다. 이 5단계는 *지원 작업 순서*이며 임상적 응급 정도나 통계적 위험확률이 아니다.
