# OY-RALS 맥락적 추론 기반 공개사례 정량 정합성·민감도 검수 (2026-10-24)

> **결론:** 공개 수상사례 20개를 이용한 **개발자 코딩 기반 후향적 기술검사**는 수행했으나, 독립된 실제 개입결과를 준거로 한 **실증적 준거타당도, 임상적 예측타당도, 민감도/특이도는 아직 추정할 수 없음**. 아래 일치율은 '시나리오/연구자 추론과 현재 코드 출력의 적합도'이며 검증된 위험평가 정확도가 아닙니다.

## 1. 명제 및 분석 범위
- **P1: 안전 우선 명제** — 실제 위해와 보호 필요 신호는 원점수·가중치·복합영역 판정보다 우선 표시된다.
- **P2: 맥락적 우선순위 명제** — 사례의 초기 서술이 지목하는 주된 생활문제는 시스템 상위 3개 활성영역에 포함된다.
- **P3: 단계적 개입 명제** — 긴급성이 불분명하거나 약하게 관찰된 문제라도 관찰·초기지원 경로를 누락하지 않아야 하며, 과도한 정식 사례관리 확정도 피해야 한다.
- **P4: 불완전 정보 명제** — 공개 문헌의 미기술 문항은 0점이 아닌 `unknown`으로 처리되어 전체 위기수준 확정이 보류된다.
- **P5: 맥락적 추론의 안전성 명제** — 온라인 위협·성적 착취, 가정폭력 노출·직접 피해, 공격행동·피해 경험 등 서로 다른 개념을 임의로 합치지 않는다.
- **P6: 제한된 가중 명제** — 현행 가정 가중계수는 의견·정렬 보조값이며 위기등급을 직접 산출하지 않는다. 유효성이 입증되지 않은 계수로 최종 보호 등급을 결정하지 않는다.

- 최초 서술코딩: [20건 증거등록부](public-case-20-evidence-register-20261024.md). 사례별 **후보 문항**은 예비 해석이며 실제 0~4점 관찰치가 아님. 초기 주된 영역 기준도 **연구자가 수작업 부여**했으므로 독립 블라인드 준거가 아님.
- 실제 실행 모듈: `docs/youth-risk/criteria.js`, `support-model.js`, `planning-model.js` (2026-10-24 메인 기준).
- 전제: 대상자·보호자·교사의 개인정보, 원문 사례의 연락처·학교·실명 등을 외부 모델/스크립트에 입력하지 않는다.

**해석:** 점수 가정 1→2→3만으로 지원수준·계획 수와 우선순위가 크게 달라진다. high의 Level 3 19/20은 '실제 사례 중 95%가 고위기'가 아니라 **임의로 3점을 준 입력의 기계적 귀결**. 미상 포함 시 위기수준은 모두 `observedLevel`이라는 참고값이고, 확정 `level`은 20건 모두 null이다.

**안전 참조의 독립성 한계:** 연구자가 자해/학대 서술을 보고 안전 참조 12건을 코딩하고 같은 단서가 들어간 시스템 문항을 선택했다. 따라서 TP=12, TN=8, FP=0, FN=0 같은 표면 혼동행렬은 독립 실증 표본에서 얻은 민감도·특이도 자료가 아니고, **코딩-로직 자체 정합성**을 보여줄 뿐이다.

## 4. 점수 변동 20,000회 민감도 검수
- 각 사례의 보수적 문항집합을 고정하고, 각 문항의 **1·2·3점 중 한 값을 균등난수**로 선택. 사례당 1,000회 × 20개 = 20,000회, 시드 20261024.
- 실제 `planning.analyze` 실행. 균등분포는 계산 재현만을 위한 개발상 가정으로, 청소년 위험 점수의 현실 확률분포가 아니다.
- **주요영역 상위 3개 포함: 18,498/20,000 = 92.49%**.
- **주요영역 정식 서비스계획 포함: 17,663/20,000 = 88.315%**.
- 최종 위기등급 확정 보류: 20,000/20,000 = 100%.
- 반복된 20,000개 출력은 **새로운 20,000명의 관찰값이 아니다.** 표본크기는 여전히 공개 수상사례 20개이며, 사례 간 독립성도 충분하지 않다.

## 5. 맥락 추론에 따른 코드 보완 실험 (미배포 제안)
**실험 목적:** 4·5·12·13번 문항의 추가 안전확인이 미완료인 경우, 관련 영역을 최상단 가시성에서 누락하지 않도록 조정하되 '긴급'으로 임의 격상하지 않는다.

현행 `support-model.js`에서 영역별 `safetyCheckPending` 속성을 추가하고, 랭킹 순서를 `safety > safetyUnknown > safetyCheckPending > critical > ...`로 바꾼 **비영속 비교실험**을 수행.

| 지표 | 기존 코드 | 제안 코드 | 차이 |
|---|---:|---:|---:|
| 2만회 주요영역 상위 3개 포함 | 18,498 (92.490%) | 19,119 (95.595%) | +621건 (+3.105%p) |
| 기존 적중이 누락으로 바뀐 경우 | — | 0건 | 지정 검수자료 내 후퇴 없음 |
| 개선된 사례 | R11 | R11 | R11 상위 3개 379→1,000/1,000 |

단, **20개 사례와 임의로 설계한 점수변동만을 기준으로 한 개발 성능 비교**이므로 실제 학생 안전·학맞통 의뢰 성공률 또는 임상적 타당도 개선의 증거가 아니다. 새 랭킹은 안전확인 완료/보류 및 개입 담당 구분을 별도로 표시하고, 기존 50만 합성 입력 회귀검사를 다시 실행한 후 배포하도록 권고한다.

## 6. 독립 실증 타당도는 현재 산출할 수 없는 이유
- **준거오염 및 자기검증:** 연구자가 공개 서술에서 문항을 뽑고 같은 서술에서 '맞는 영역'을 지정하면 95%라는 수치는 구성상의 내적 합치다.
- **불충분한 증거:** 우수사례 발표의 사후 개입·성과와 초기평가 시점을 분리한 모든 25문항의 점수, 실제 기관 의뢰/서비스 이용 이력이 없다.
- **선정편향:** 같은 수상사례집 20건은 무작위 실제 의뢰학생 표본이 아니다.
- **반사실 부재:** 개입을 받은 집단의 경과만으로 권고하지 않았을 때의 결과와 비교하는 효과성을 평가할 수 없다.
- **본 도구의 성격:** 신고·위기대응 보조도구이지 독립적인 진단·위험확률 추정기가 아니다.

### 검증 가능한 연구 설계
1. 실제 사례 100~200건 이상을 **평가 시점의 익명화·근거표시 25문항 응답**과 사전 정의된 별도 우선 개입 준거로 확보. 실증 표본 수는 연구목적·최소 허용오차·유병률 등을 근거로 확정한다.
2. 서로의 판정을 모르는 학교전문상담인력/사회복지사 등 **독립 평가자 2인 이상**이 (a) 현재 안전확인 (b) 첫 개입 (c) 주요 문제영역 (d) 서비스계획·연계 우선순위를 코딩하고 불일치를 제3자가 조정.
3. 항목별 비가중/가중 κ 및 95% 신뢰구간, 주된 문제영역 top-k 적중, 다중라벨 정밀도·재현율·F1, 안전신호 누락률, 의뢰실행률·3개월 후 계획 이행 등을 분리 검증.
4. 실제 급박한 안전위험과 과거 피해 경험을 구분하고, **민감도/특이도는 독립된 참조 평가가 성립한 항목에서만** 제시.
5. 성별·장애·가구형태·경제여건에 따른 불공정 판정과 불필요한 위험 낙인을 별도 검토. 현장 프로토콜 및 개인정보보호·연구윤리를 우선한다.

## 7. 최종 결론 및 구현 상태
- **실시:** 현행 실제 JS 모듈에서 공개 수상사례 20개에 대한 개발자 코딩 정합성 비교(3조건), 20,000회 점수 가정변경 실험, 미배포 우선순위 보완안 비교 20,000회.
- **계량 결과:** 95%(19/20, 중심 점수), 92.49%(18,498/20,000, 변동 점수)는 **맥락적 문제 영역의 코드 정렬 정합도**이다. 연구자가 구성한 준거 기준이며 실증 타당도나 진단적 정확도라고 부르지 않는다.
- **미확정:** 독립 준거와의 일치율, 실제 안전조치 이행, 상담/연계 효과성, 위험 예측성, 문항별 실증 가중치.
- **권고:** 기록된 초기 안전조치는 법·기관규정에 따른 사람의 판단으로 유지한다. 서비스계획이 0건으로 나오는 저강도 입력에서도 `관찰/초기면담·경과확인`을 안내하고, 추가안전확인 보류 영역의 결과 가시성을 높이는 안을 현장 검토 후 반영한다.
- 재실행: `node scripts/youth_risk_20_case_concordance_20261024.cjs`
- 기존 기술검수: [50만 사례와 80 가상 사례](audit-report-20261024-500k.md).

**연구 분류:** 실증 타당도 '입증'이 아니라 **실제 공개 문헌에 기반한 맥락적 내용대응·사전 타당화 및 반사실 입력 민감도 연구**. 학술 발표 시 제한점을 본문과 요약에 함께 명시해야 한다.
