## 범위와 한계

1. 서술 분석은 규칙 기반 단서 추출이다. 복합적인 부정·대명사·시점·인용을 완벽히 이해하지 못하므로 원문과 확인 질문을 함께 검토한다.
2. AI 열기는 공식 웹페이지 열기와 요청문 복사이다. 개인 계정의 대화·답변을 자동 회수하지 않는다. 실제 계정에 민감 사례를 전송하는 시험은 하지 않았다.
3. 기관별 현재 모집·운영시간·수용 가능 여부를 이번 패치에서 전수 재조사하지 않았다. 기존 자원 DB의 문의 후보로 표시하며 실제 접수 가능 여부는 별도 확인한다.
4. PDF는 브라우저 인쇄이며 임의 기관 양식으로 자동 변환하는 기능은 아니다. 실제 서식에 맞춘 AI 재작성에는 양식 제공과 실무자 검토가 필요하다.
5. 새로운 사정·협의·계획 메모는 해당 화면의 TXT/PDF로 저장한다. 기존 전체 ZIP은 신규 메모까지 자동 포함하지 않는다. 새로고침·평가 갱신 전 저장해야 한다.
6. 기술검사는 실제 신뢰도·타당도, 예측정확도, 개입 효과를 입증하지 않는다. ‘AI 실증 검증’ 표현을 사용할 때도 가상사례 검수와 실제 표본 연구를 구분한다.
