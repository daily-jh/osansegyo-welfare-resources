# K-CARR V8.0 site integration — 2026-10-24

기준 배포: 621dfc84e73b803763b748d6a00c6eceed539a26. 사용자 제공 FULL-54000 패키지의 배포지침과 코드를 검토하여 브라우저용 엔진·어댑터만 반영했다. 합성 JSONL·SQLite·실사례 원문은 공개 사이트에 포함하지 않는다.

## 실제 연결

- `case-formulation-v72.js`의 기존 점수 기반 사정을 먼저 산출한 뒤 `kcarr-site-v8.js`가 유효한 서술이 있는 경우 V8의 상황·통합 판단·첫 행동·실행과제를 결합한다.
- CORE 결과 객체는 참조만 전달한다. 미상 총점은 null로 전달하며 새로운 공식 안전 등급을 생성하지 않는다.
- 서술이 없거나 전부 부정·가정인 경우 기존 결과로 복귀한다. 기존 안전·지원 과제가 서술에 없다는 이유로 누락되지 않도록 유지한다.
- 교사·교육복지사·사회복지사 질문은 동일한 공통 사정을 사용한다. 면담은 V8 추가 질문, 계획은 우선 실행을 재사용한다. 기본 복사는 서술 없는 평가를 다시 사용하며 명시적 선택에만 서술 사정을 포함한다.
- 서비스계획·사례협의안·리뷰·선택 ZIP 모두 공통 모델을 사용한다. 수동 입력 기록을 모델로 덮어쓰지 않는다. 지역자원 DB와 연결지도는 변경하지 않는다.
- 비활성화 방법: `YouthKCARRV8Enabled=false` 또는 브리지 등록 제거 시 기존 7.2 사정 경로로 복귀한다.

## 원 패키지에서 수정한 결함

1. `understanding(flags,domains,linked)`에서 빈 배열도 참이 되어 위해가 없는 사례에 ‘보호자 연락 이후 위해’ 문장을 생성했다. `flags.contactViolence`가 참일 때만 생성하도록 수정했다.
2. 미상 평가의 부분 합계를 공식 총점으로 전달했다. `core.incomplete`이면 null로 전달한다.
3. ‘연락 시’라는 조건 표현과 결석만 있는 경우 수업 방해를 가정하는 실행 문구를 보완했다.
4. 교사/사회복지사 실행이 같은 문구로 반복되지 않도록 기존 직무별 실행과 결합했다.

## 검사와 해석 한계
