## 1. 기본 평가와 보조 검토값 분리

**기존 공식 평가:** 25문항(0~4점), 총점 최대 100점. 문항 미상은 0점이 아니며 전체 최종판정을 보류함. 안전 핵심문항 1·2·7·25, 별도 긴급 안전신호, 조건부 4·5·12·13 현재위험 추가확인은 총점과 독립 처리합니다. 교차계수로 기존 점수와 긴급안전 판단을 변경하지 않습니다.

**실무 정렬 보조식(검증되지 않은 가정):**

```
s_i = i번 문항 실제 응답 점수(0~4)
w_i = 문항별 개발 가정계수(아래 표)
B_i = (s_i / 4) × w_i              // 미상은 계산하지 않음
m = Σ(s_i × w_i) / Σ(w_i)           // 교차규칙에 실제 일치한 문항 집합
u = min(s_i)                         // 같은 집합의 최저 확인 점수
c = 교차규칙별 개발 가정계수
R = min(4, 0.85 × m + 0.15 × c × u)
```

B와 R은 **현재 확인한 응답을 설명할 때 보여주는 보조정렬값**일 뿐 위험 확률·점수환산·표준점수·효과크기·임상 중증도 등급이 아닙니다. 계수 0.85/0.15와 w, c는 학술자료에서 추정한 통계적 계수가 아닌 개발용 정책 가정입니다. 소수점 둘째 자리까지 표시하더라도 예측 정확도가 증가한다는 뜻은 아닙니다.

## 2. 질적 문장 생성 데이터
`review-model.js`에 **25문항 × 5개 텍스트 필드**(해석 질문·학교 접근·사회복지사 개입·변화 확인·단정 금지) 총 125개 근거-언어 단위를 등록했습니다. 기존 24개 교차규칙의 확인 질문·지원·목표·지표 자료와 조합합니다. 자해·학대·디지털 착취 등은 타 문항의 점수로 위해를 예측하거나 신고여부를 배제하지 않습니다.

출력은 8개 구획: ① 종합 사정 및 판단 근거 ② 독립된 현재 안전 판단 ③ 주요 어려움과 영향경로(보고한 사실/해석 가설/미확인/담당별 첫 질문/관찰지표) ④ 문항 간 교차사정 ⑤ 강점·보호자·환경·서비스 접근 장벽 ⑥ 단계별 목표·담당/역할 ⑦ 재사정·계획변경 판단 ⑧ 계산근거·검수 한계.

**교사 관점:** 학생의 말·학교생활·보호자 접촉 안전성·학내 조정. **사회복지사 관점:** 판정 검토 후 서비스 신청·의뢰·접수·실제 제공·재사정. 역할별로 다른 질문과 조정 문구를 사용합니다.

## 3. 사실–가설–행동–성과의 분리
- **사실:** 몇 번 문항에 몇 점을 표시했는지, 출처·기간·당사자 진술이 확인됐는지.
- **가설:** 두 응답이 왜 함께 나타나는지 확인할 질문. 단정이나 인과 추론 금지.
- **미확인:** 강점, 실제 환경, 가구 상태, 기존 서비스, 보호자 연락 가능 여부, 기관 수용능력.
- **행동:** 안전·학습참여·생활지원 등의 담당 기관과 첫 구체적 확인 행동.
- **이행:** 문의→의뢰→접수→제공 시작→실제 생활변화는 서로 다른 성과·진행 상태.
- **재사정:** 안전 변화는 즉시, 그 밖에는 학생과 합의한 목표·기준선·시점을 중심으로.

## 4. 출처와 근거의 한계

## 5. 미해결 검증 과제

현재는 문장 생성의 기술적 재현성만 평가할 수 있습니다. 실제 적용 전 전문가 간 사례판정 일치도, 상호작용 가정계수의 민감도·공정성, 동일 사건 중복입력, 사례별 문장 비약·차별·낙인, 모바일 가독성, 학교와 복지기관의 실제 접수 가능 여부를 별도 검토해야 합니다. 소수점이 있다고 해서 예측모형이 검증되었다고 주장하지 않습니다.
