# OY-RALS V8.6 홈페이지 연결 및 시스템 작동방법 개편

적용 목표일: 2026-10-25  
운영 저장소: daily-jh/osansegyo-welfare-resources  
변경 전 기준: 182b4487ce6dec6b49bf9fad7ab54f4e76c623e6 (V8.3 결과분석 포함)  
적용 범위: docs/youth-risk/

## 적용 내용
1. **공식 CORE 변경 없음.** 기존 criteria.js의 25문항·10영역·원점수 100점, 안전 게이트와 미상 로직을 유지한다.
2. **OY-RALS V8.6 웹 통합 어댑터**: oy-rals-v86-site.js. 실제 페이지에서 ICSI(문항별 대조), K-CARR(서술 근거·극성 분석), ICMS(25문항별 서로 다른 교사·사회복지사 행동)과 공통 CaseState(목표 ID·문서 연결)를 실행한다. 평가·사례협의·기록 3개 HTML에 연결한다.
3. **보고서**: case-formulation-v72.js의 V8.6을 우선 사용하며 V8.3 영역별 지원표는 보존한다. 교차분석은 접기 영역으로 옮겨 중복을 줄인다.
4. **초기상담·욕구사정 양식**: case-form-model.js가 공통 목표와 서술 근거를 자동 검토안으로 사용한다. 직접 작성한 값이 우선하며 합의·이행을 확정하지 않는다.
5. **사례회의·서비스계획**: case-documents.js가 V8.6의 공통 목표 ID를 사용하고 중복된 과거 V8.2 근거표는 제거한다.
6. **시스템 작동방법 페이지**: system-method.html을 새 반응형 이용자 안내로 전면 교체했다. V7~V8.3의 누적 변경 이력은 본문에서 제거하고 사용 절차·안전·직무·개인정보·검증 한계를 전면에 배치했다.
7. **캐시 키**: 첫 화면 iframe, flow.js가 만드는 보고서·기록 iframe, 주요 모델 스크립트를 V8.6으로 갱신했다.

## 원본 패키지와의 관계 (중요)
이 저장소의 **웹 V8.6은 이전에 제작한 독립 V8.6 ZIP을 파일별로 그대로 복사한 소스 트리가 아니라**, 정적 GitHub Pages에 맞게 기능을 통합한 웹 어댑터다. 전체 15,000건의 합성입력·출력 JSONL, 개발 중간 산출물 및 테스트 참조 파일은 홈페이지에서 직접 사용하지 않아 공개 사이트에 탑재하지 않았다. 독립 원본 ZIP에서 약속한 **CORE 불변·문항별 실행안·서술 근거 분리·통일된 목표 ID**를 현재 사이트 구조에 연결한다. 원본 독립 모듈과 웹 어댑터의 모든 문장·패턴이 완전히 동등하다고 주장하지 않는다.

## 기술검수
- 현재 운영 코드+V8.6 웹 어댑터 합성 회귀 **5,000건 실행**: 예외 0, 원점수 변경 0, CORE 긴급 게이트 변경 0, Q20 고점 과제 누락 0, 목표 ID 중복 0, 5종 문서 목표 ID 불일치 0.
- 부정문·예방교육·미확인·명시적 안전 진술의 개별 사례를 수동 시험.
- Node 재현 스크립트: tests/youth-v86-site-regression.cjs.
- 사례회의·서비스계획 HTML 및 초기상담·10영역 욕구사정 문서의 주요 필드 생성 확인.
- **해당 검증은 합성 회귀검사이며 실제 현장 타당도, 사례관리 효과, 민감도·특이도, PDF/DOCX 브라우저 호환성의 증명이 아니다.**
- 실제 GitHub Pages 퍼블리싱·iOS/Android 시각 확인은 배포 후 브라우저에서 별도 확인.

## 한계와 안전
- 생성형 언어모델이 아니라 로컬 규칙 기반이다. 자유로운 한국어 문장, 중첩 부정, 전언·과거 사건을 완벽하게 이해하지 못한다.
- 현재 위해 가능성이 있는 경우 총점과 별도로 직접 안전을 확인하고 법정 신고·보호절차를 따른다.
- 학생 이름·상세주소·진단명 등 불필요한 민감정보를 공개 저장소·테스트 기록에 올리지 않는다.
- 지역자원 추천은 접수·승인·제공을 자동 확정하지 않는다.
- 학생 자기결정·강점 관점과 실무자 책임을 우선한다.

## 되돌리기
기존 branch point를 기준으로 되돌리거나 아래 변경만 제거할 수 있다.
1. 부모 index.html과 flow.js의 V8.6 캐시 키, 하위 3개 HTML에서 oy-rals-v86-site.js 로드를 제거한다.
2. case-formulation-v72.js를 직전 V8.3 연결 함수로 복원한다.
3. case-form-model.js와 case-documents.js에서 v8.6 우선 경로를 제거한다.
4. system-method.html을 이전 파일로 복원할 수 있지만 원한다면 사용자 안내만 유지해도 된다.
기존 criteria.js는 변경하지 않았으므로 25문항 점수 데이터 변환이나 이전 평가 기록의 점수 마이그레이션은 요구되지 않는다.
