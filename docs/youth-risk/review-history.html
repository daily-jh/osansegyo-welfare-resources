100점 방식과 한계

25문항 × 각 0~4점 = 원점수 0~100점. 가중치·환산·반올림 없이 정수 합산합니다. 30문항을 100/120으로 환산하면 중복과 응답 부담은 남고 소수점 해석이 필요하므로 채택하지 않았습니다. 10개 실무 영역은 유지하고 중복되는 5개 독립 문항을 통합했습니다. 영역이 독립된 잠재요인이라는 검증은 없습니다.

영역별 2~3문항으로 최대 8점 또는 12점입니다. 총점에서 3문항 영역의 최대 기여가 더 크다는 불균형이 남습니다. 영역 우선 확인 순서는 문항 평균(영역합÷문항 수)으로 비교하며, 화면의 평균 소수 첫째 자리는 표시용입니다. 실제 정렬은 반올림 전 값입니다. 합계는 임상적 위중도나 자살 확률을 뜻하지 않습니다.

0~19 / 20~39 / 40~59 / 60~100은 임의로 정한 업무 검토 구간입니다. 연구에서 도출한 절단점이 아니며 지원 자격·진단·서비스 배제에 사용하지 않습니다. 낮은 총점도 개별 지원을 막지 않으며, 모든 점수가 있는 영역의 기관 후보를 보여줍니다.

종합 리뷰는 점수·문헌 나열을 줄이고 문항의 의미, 함께 나타나는 어려움, 생활상 영향의 가능성, 지원·확인 필요를 짧게 설명하도록 개편했습니다. 근거 문항·점수는 접기 항목에서 확인합니다. 2026 오산세교 사례관리의 당사자 중심·강점관점·사실/해석 구분 원칙만 참고했으며, 별도 16문항 위기도 척도를 청소년 25문항에 환산하거나 혼용하지 않습니다.

현재 기본 리뷰는 외부 AI가 아닌 브라우저 내 해석 규칙입니다. 현재 GPT·Gemini 자동 연결은 사용하지 않으며 사이트에서 외부 AI를 호출하지 않습니다. 기본 리뷰는 문항 응답의 결합 양상과 기능상 어려움, 판단 근거·추가 확인사항을 해석하는 규칙으로 보완했습니다. 안전신호에는 해당 문항 번호·원문·점수를 표시합니다. 외부 AI의 추가 분석이 필요한 경우 이용자가 직접 전체 복사 내용을 검토해 붙여넣습니다. 복사·분석 안내를 확인하세요.
