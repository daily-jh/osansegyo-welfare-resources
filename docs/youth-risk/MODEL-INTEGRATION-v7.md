# OY-RALS V7.0 통합·검수 기록

적용일: 2026-10-24. ICSI / K-CARR / ICMS의 V7.0은 소프트웨어 버전이다. 실제 학생 대상 임상·효과성 검증을 뜻하지 않는다.

## 적용 구조

원 배포 커밋 `c815dc9c3e3886b1f4476f77250da2241a5150f9`에서 `backup/pre-v7-20261024`, `integration/models-v7-20261024` 작업 브랜치를 만들었다. 사용자가 올린 ZIP은 수정하지 않았다. 선택 4개 패키지의 SHA-256은 `research/v7/package-verification.json`에 기록했다. 배포지침의 자동 설치기는 과거 HTML에 대한 문자열 치환과 별도 패널을 추가하므로 현재 화면에 그대로 실행하지 않고 변경을 대조해 수동 통합했다.

| 모델 | 운영 연결 | 권한 |
|---|---|---|
| CORE | 기존 criteria.js | 원점수·안전·미상·지원단계의 유일한 원본 |
| NCB V4.5 기반 | case-context-core / form, narrative-engine-v45, app snapshot → flow → 보고서·기록 | 선택 사례정보 문자열 1칸, 최대 5천 자 |

공통 배포 파일 9개는 두 V7 ZIP 사이에서 바이트가 같음을 확인해 한 번만 채택했다. 모든 HTML에서 JS/CSS를 각각 한 번만 로드한다. 제공된 `oy-panel-*`, `casework-v7-ui`의 독립 보고서 패널은 운영에 등록하지 않았다. 결과의 선택 사례정보 검토는 리뷰 한곳, 3페이지에서는 기존 하단 근거 안 한곳에 표시하며 주 실행계획서·사례협의안을 중복 출력하지 않는다. 세 모델의 결과를 묶는 `model-integration-v7.js`는 매번 ICMS 판단과 CORE의 제목·긴급 여부·확정 가능 총점을 대조한다.

## 자료 규모와 설치 범위

운영은 25개 주제, 25개 문항 규격, 24개 교차규칙, 450개 문항·점수·역할 카드와 72개 교차·역할 카드를 필요할 때 로드한다. ICMS는 10영역·15단계·3직무 지식표를 사용한다. 원 패키지의 34,200개 조건 인덱스 + 450개 행동 카드, V4.5의 37,500개 문항쌍 맥락과 18,720개 응답 변형은 파생 레코드이며 독립 실제 사례 수가 아니다. 전체 90MB 선행 데이터와 대형 JSONL은 첫 화면 또는 운영 모듈에 중복 설치하지 않았다. V4.5는 입력·전달·기초 사전만 사용하고 주 해석은 V7의 압축 규칙·역할 카드로 수행한다. 이전 V4~V6 ZIP은 연구 이력이며 운영에 중첩하지 않았다.

## 개인정보·상태 계약

- 자유서술은 메모리의 `caseContext` 문자열로만 전달한다. 수정하면 이전 결과·후속 보고서를 무효화하고 다시 완료해야 한다. 초기화·평가 백업 불러오기는 서술도 지운다.
- 자유서술은 기본 평가 백업·기본 외부 AI 요청·기본 복사·인쇄에 자동 포함하지 않는다. 서술 기반 화면은 `data-local-context`로 표시하고 복사·인쇄 복제본에서 제거한다. 질문 응답의 복사도 서술 없는 척도 응답만 제공한다.
- 기존 외부 AI 기능은 별도로 사용자가 적고 승인한 자유서술만 전달한다. 입력한 선택 사례정보를 자동으로 외부 AI란에 복제하지 않는다.
- 모델의 형식 마스킹은 완전한 비식별화를 보장하지 않는다. 실명·연락처·상세주소를 쓰지 않는다.
- 단·장기 목표는 제안이다. 학생 동의·기한·기준선·목표치·접수·서비스 시작·회의 승인·종결은 담당자가 기록한다. 서술의 과거·부정·전언·미상을 확인 사실로 승격하지 않는다.

## 검증

첨부 패키지 재실행: 문맥 반례 300건, v5 합성 3,000건, v6 합성 3,500건, v7 합성 5,000건, ICMS 합성 50,000건 및 수기 검사 19개, 가상 사례 180건, 조건 인덱스 34,200개·행동 카드 450개 무결성 검사 통과. 중복·파생 자료가 포함되므로 검사 횟수를 실제 사례 수 또는 통합 정확도로 합산하지 않는다.

저장소 통합: 400개 가상 입력 × 3개 직무(1,200개 조건)를 `tests/youth-model-integration-v7.cjs`에서 실행했다. CORE 불변·세 직무·부정/과거/전언·미상·서술 충돌·안전·선택된 계획과 기본 공유 제외를 검사해 통과했다. `tests/youth-*.cjs`, 사이트 무결성·보안, 가상 50사례, 실브라우저 단계 전환과 복사·인쇄용 DOM, 모바일 CSS를 점검했다. 실제 모바일 기기·OS 프린터 실행은 별도 확인이 필요하다. 통합 DOM 검사에서는 단일 입력 전달·재계산 무효화·질문 역할 전환·기본 클립보드/인쇄/AI 요청문/양식에서 서술 제외를 확인했다. 검사 실패와 미실시 항목을 실증 통과로 표시하지 않는다. DOCX 직접 다운로드 기능은 이 정적 화면에서 새로 제공하지 않으며 기존 인쇄/PDF 저장 흐름을 유지한다. 운영체제의 실제 프린터 출력은 검사 범위 밖이다.

## 변경 파일과 롤백

신규: V7 모듈·공통 JSON, NCB 입력·기초 사전, 통합 어댑터·UI·CSS, 모델 등록부·검수 기록·원 패키지 출처, 통합 테스트. 수정: 평가 snapshot·무효화·초기화, 부모/자식 화면 버전, 사례문서·복사·인쇄, 질문 응답·직무 선택, 실행계획 단/장기목표, 기록 화면의 사정 근거 연결, 시스템 작동방법·구조도·README. 점수 준거와 자원 DB·지원 연결지도 파일은 변경하지 않았다. 별도 작업 중이던 usage-config.js는 제외한다.

롤백은 이 릴리스 커밋을 `git revert`하여 이전 코드와 모델 등록 상태로 되돌리고 Pages 검사를 거친다. 전체 main을 강제 이동하지 않는다. 비교용 원 기준은 위 커밋이며, 후속 다른 작업이 없을 때만 그 트리와 동일한 파일 집합을 복원한다. 학생 기록은 서버 저장 대상이 아니므로 코드 롤백으로 복구되지 않는다.
