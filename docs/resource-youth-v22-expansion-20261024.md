# OY-RALS v2.2 청소년 평가 대응 복지자원 확장

기준일: 2026-10-24. 기존 청소년 위험판정과 원점수·미상·안전 게이트는 변경하지 않음.

## 변경
- 기존 107개 기관·206개 서비스 → 110개 기관·220개 서비스.
- 추가: 화성오산교육지원청 특수교육지원센터, 경기도교육청, 국립중앙청소년디딤센터.
- 기관명 중복 없이 Wee, 마주봄센터, 경기도청에 각종 세부 지원사업 추가.
- 교육접근성, 학업중단, 정서·치료, 학교폭력, 성착취, 가정 밖 청소년, 2026 교복지원 관련 안내 및 공식 근거 보완.
- 원본 정규화 CSV·14개 열 호환 CSV·검색용 data.js·기관별 연락처·검증이력·접수회차 동기화.
- **공식 안내 확인은 현재 실제 신청가능·적격성 확정을 뜻하지 않음.** 홈페이지의 이용일시 및 실제 상담 가능은 별도 확인.
- 신설 기관은 복지자원 검색에 표시됨. 청소년 평가 결과의 자동추천 경로는 안전·적격성 회귀검사 전까지 변경하지 않음.
