# 두 사이트 연계·보안·안정화 점검 — 2026-10-23

대상: 복지자원 찾기와 청소년 위기징후 평가연계 시스템의 정적 웹 코드, 공용 데이터, 화면 간 전달, 선택형 AI 및 익명 집계 서버의 소스 회귀검사.

## 반영한 수정

- 모든 HTML 진입점에 CSP와 no-referrer 정책 적용. 스크립트는 같은 출처의 파일만 허용하고 인라인 이벤트·플러그인 객체·외부 iframe·폼의 직접 전송을 제한함. 인쇄 양식의 인라인 클릭 코드는 별도 파일로 분리함.
- 외부 URL은 HTTP(S) 구문을 검증하고 자격증명이 포함된 URL·제어문자·실행 스킴을 거부함. 선택형 외부 AI 창은 noopener/noreferrer로 열며 자원 링크에는 학생 정보를 포함하지 않음.
- 기관 홈페이지·근거 링크·연락처는 공용 DB를 우선함. 홈페이지 출처가 바뀌면 과거 도메인의 고정 세부 링크를 붙이지 않음. 위기평가 결과와 연결지도에서 기관 ID로 복지자원 상세정보를 바로 확인함.
- 응답 변경 시 이전 연결지도·자동 보고서 창을 제거하고 비식별 JSON 저장 버튼을 비활성화함. 준비되지 않은 평가와 이전 평가 버전의 데이터 요청에는 자료를 다시 보내지 않음. 의도적으로 보존한 기록·점검 화면은 기존 버전 표시를 유지함.
- 결과와 리뷰를 실제 생성한 뒤에만 상위 화면에 완료를 알림. 부분 응답도 동일한 완료·미상 규칙을 적용함.
- 복지자원 원본 누락은 오류 안내로 표시함. 사업 목록 요청에는 시간 제한을 적용하며 집계 기능·기기의 난수 생성 기능이 작동하지 않아도 평가를 유지함. 즐겨찾기는 현재 등록된 기관 ID만 복원함.
- 신규 보안 검사와 선택형 AI 서버·익명 집계 서버의 자동 회귀검사를 CI에 추가함.

## 검증

정규화 데이터 빌드 일치, 복지자원 검색·사업·연결지도, 청소년 전체 회귀검사, 8개 동·3개 종복 권역, HTML 정책·스크립트 경로, URL 거부, 서버 인증·출처·요청 제한·개인정보 필드 거부를 검사함. DOM 통합검사에서 검색, 악성 문자열 표시, 평가→권역별 추천→기관 상세 링크, 미상, 잘못된 출처의 메시지 거부, 응답 변경 후 이전 프레임·저장 차단을 확인함.

## 적용 범위와 운영 한계

이 작업은 소스 검사와 기능 회귀검사이며 전체 침투시험이나 무결점 보증이 아님. 기존 25문항·100점, 안전 우선과 미상 처리, 주소·연락처 및 3개 종복 권역은 변경하지 않음.

GitHub Pages의 HTML 메타 정책은 HTTP 응답헤더 전체를 설정하는 기능이 아님. frame-ancestors, HSTS, X-Content-Type-Options, Permissions-Policy 등 호스팅 응답헤더의 추가 제어는 별도 프록시·호스팅 구성이 필요하며 이번 작업에서 설정했다고 주장하지 않음. 메타 CSP에는 지원되지 않는 frame-ancestors를 넣지 않음.

청소년 페이지의 연결 정책은 선택형 HTTPS AI 서버와 지정된 로컬 AI 주소(127.0.0.1:8765)를 보존함. 외부 AI 전송은 동의·직접 실행 절차를 유지함. 외부 AI 서비스의 보관 정책이나 이용자 기기·클립보드는 이 사이트가 통제하지 않음.

외부 Cloudflare 서버는 소스 및 모의 요청으로 검사했으며 이번 GitHub Pages 배포가 외부 서버 설정·WAF·레이트리밋·보관정책까지 새로 배포하는 것은 아님. 익명 방문·평가 횟수는 접근통제·인증 자료로 사용하지 않음. 외부 기관의 최신 사업 수락·운영·연락처 사실확인과 이 기술검사는 구분함.
