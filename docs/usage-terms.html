1. 권리 표시와 보호 범위

기획·편집·웹사이트 제작: 오산세교종합사회복지관 김지훈 팀장. © 2026 김지훈.

김지훈이 직접 창작하고 적법하게 권리를 보유한 UI 디자인의 구체적 표현, 소스코드, 창작적인 정보 선택·배열·편집 및 안내 문구에 적용합니다. 소속 표시는 기관 명칭·로고의 개인 소유를 뜻하지 않습니다. 이 자료실은 독자적인 위기평가 척도의 권리를 주장하는 서비스가 아닙니다.

2. 무료 이용 범위

공익 및 사회복리 증진을 위한 비영리 목적의 사이트 사용, 제공된 검색·즐겨찾기·연계 시트 인쇄·CSV 다운로드 기능의 이용, 출처와 권리 표시를 유지한 원형 그대로의 교육·업무용 자료 공유는 무료입니다. 기관명·사업명·연락처 등의 사실정보를 활용한 별도 연계 문서 작성과 보완도 허용합니다.

3. 사전 서면 허락이 필요한 이용

저작권으로 보호되는 고유 창작물의 수정·변형·2차적 저작물 제작, 별도 복제 사이트 운영, 상업적 재사용 및 허용된 공유물의 권리 표시 제거에는 사전 서면 허락이 필요합니다. 문의는 사이트의 공개 오류 제보 창구를 이용해 주세요. 개인정보는 게시하지 마세요.

4. 아이디어·제3자 자료·법정 허용 이용

일반적인 디자인 아이디어, 기능적 발상, 검색·분류 방법 자체, 복지제도·법령·사실관계, 독립적으로 창작한 디자인과 코드에는 독점적 권리를 주장하지 않습니다. 외부 기관의 사업공고·명칭·상표·로고·원자료는 각 권리자에게 귀속되며 해당 이용조건을 따릅니다. 법령상 허용되는 인용과 GitHub 약관에 따른 열람·Fork를 제한하지 않습니다.

5. 외부 정보 연결 및 이용 확인

오산 복지정보 홈페이지와 기관별 사업 안내는 외부 링크로 연결됩니다. 제휴·공동운영 또는 실시간 데이터 제공을 의미하지 않습니다. 모집 상태는 등록된 접수기간에 따른 보조정보이며 조기마감·예산 소진·자격 변경은 반영되지 않을 수 있습니다. ‘상시’는 운영형태이며 즉시 이용 가능을 보장하지 않습니다. 대상·관할·기간·담당창구를 확인한 후 연계해 주세요.
