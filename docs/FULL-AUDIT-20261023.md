# 전체 사이트·공개 사례 대입 검수 (2026-10-23)

## 범위

복지자원 검색·분야별 기관 연결도·청소년 평가·연결지도·보고서/계획·상담기록·AI 자료 전달 및 선택적 서버 코드. 정적 사이트 소스와 데이터·회귀검사를 점검했다. 실제 이용자의 개인정보는 사용하지 않았다. 외부 기관의 실시간 접수·운영, 비활성 AI의 실제 유료 호출, 배포되지 않은 서버 설정은 검증 대상이 아니다.

## 공개 자료

- 성평등가족부의 공개 우수사례 A·B: https://www.mogef.go.kr/nw/enw/nw_enw_s001d.do?bbtSn=713024&mid=mda703
- 인천광역시교육청 게시 「학생맞춤통합지원 가이드북」 책자 30·33·57쪽(실제 PDF 34·37·61쪽): https://www.ice.go.kr/upload/ice/na/bbs_2067/2023/12/a7e0b5dfbe1d91d70ea67337349e2448.pdf

공개 우수사례는 원기관 발표를 참고했으며 가이드북 사례의 개별 실사례 여부·현재 경과는 독립 검증하지 않았다. 원문·이미지·구체 신상을 복제하지 않고 지원 원칙과 출처만 제시한다. 사이트 `youth-risk/public-case-review.html`에서 확인할 수 있다.

## 대입 방식과 한계

공개 자료의 지원 주제 5개를 참고한 독립 합성 입력과 대조 입력 2개를 작성해 8개 행정동×4개 성별 선택, 총 224개 조합을 검사한다. 실제 사례의 원점수나 정답 라벨을 만든 것이 아니다. 이 테스트의 기본 0은 의도적으로 정한 대조 조건이며, 원자료에 없는 사실을 0으로 환산한 것이 아니다. 실제 사례 입력에서 누락된 내용은 미상으로 유지한다. 미상 24개와 안전 양성 1개인 추가 대조도 판단 보류와 안전 우선이 함께 유지되는지 검사한다.

검사는 추천 근거·권역·계획 일관성 및 금지 추론을 확인할 뿐 임상적 타당도, 예측 성능, 실제 서비스 효과를 검증하지 않는다. 사례에 맞춰 25문항 점수·자체 가중계수·판정 문턱을 재학습하지 않았다. 자격·접수·현재 안전·당사자의 희망은 반드시 별도 확인한다.

## 재현

기존 데이터·검색·프로그램·연결도·청소년 회귀검사, `node tests/site-security.cjs`, `node tests/site-integrity.cjs`, `node tests/youth-public-cases.cjs`, `node --test server/youth-risk-ai/server.test.mjs`, `node server/youth-risk-usage/worker.test.mjs`를 실행한다. `python scripts/build_data.py --check`로 원본과 생성물의 일치를 확인한다. 보안 헤더·기관 운영까지 무조건 안전하다는 의미는 아니다.
