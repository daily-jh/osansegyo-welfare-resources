자료 갱신·오류 제보

공식 링크·근거 점검은 매주 월요일 한국시간 오전 9시, 전체 자료 점검은 매월 1일 예약 실행합니다(실행 지연 가능). 자동 점검은 링크·출처·확인 필요 목록을 만드는 작업이며, 사업 모집 현황의 자동 실시간 수집이나 공식 확인을 의미하지 않습니다. 실제 운영정보 수정은 개별 공식 근거 확인 후 반영합니다.
